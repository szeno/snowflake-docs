# 9.38 Release Notes: Dec 03, 2025-Dec 05, 2025

Attention

This release has completed. For differences between the in-advance and final versions of these release notes, see [Release notes change log](#label-rel-notes-change-log-9-38).

## SQL updates

### Query insights: Support for queries that benefit from the query acceleration service

[Query insights](/user-guide/query-insights) are now produced for queries that are accelerated by the
[query acceleration service](/user-guide/query-acceleration-service).

Note

Snowflake does not produce the [“filter not selective” insight](/user-guide/query-insights#label-query-insight-unselective-filter) for these queries.
