## Extensibility updates

### Support for public custom Git repository URLs (*General availability*)

With this release, we are pleased to announce the general availability of support for custom URLs for connecting with a Git repository.
For example, you can specify a custom URL to a public corporate Git server within your own domain.

For more information, see the ORIGIN parameter of [CREATE GIT REPOSITORY](/sql-reference/sql/create-git-repository).

## Data lake updates

### Apache Iceberg™ tables: Automated refresh table names now appear in the ACCOUNT\_USAGE.PIPE\_USAGE\_HISTORY view

With this release, you can now see the table name in the ACCOUNT\_USAGE.PIPE\_USAGE\_HISTORY view
for Iceberg tables that use automated refresh. The view displays information to help you estimate charges incurred when you use [automated refresh](/user-guide/tables-iceberg-auto-refresh).

For more information, see [Automatically refresh Apache Iceberg™ tables](/user-guide/tables-iceberg-auto-refresh) and [PIPE\_USAGE\_HISTORY view](/sql-reference/account-usage/pipe_usage_history).

## Privacy updates

### Synthetic data generation (*General availability*)

With this release, synthetic data generation is now generally available. This feature enables you to generate synthetic data with
characteristics of the source data that can be used for testing or public release without risking exposure of the source data. For more
information, read [Using synthetic data in Snowflake](/user-guide/synthetic-data).
