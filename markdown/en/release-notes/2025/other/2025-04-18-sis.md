# Apr 18, 2025: Support for `st.query_params` (General availability)

[st.query\_params](https://docs.streamlit.io/develop/api-reference/caching-and-state/st.query_params)
is now generally available in Streamlit in Snowflake, with some considerations. For more information, see [Query parameters](/developer-guide/streamlit/limitations#label-streamlit-query-params).
