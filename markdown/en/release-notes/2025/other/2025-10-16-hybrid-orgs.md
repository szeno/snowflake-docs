# Oct 16, 2025: Organization account in a hybrid organization

A hybrid organization contains accounts in both regulated regions and non-regulated regions. For example, a hybrid organization can have one
account in a [U.S. SnowGov Region](/user-guide/intro-regions#label-intro-regions-snowgov-regions) and another in a
[commercial region](/user-guide/intro-regions#label-na-general-regions).

You can now create an [organization account](/user-guide/organization-accounts) in a hybrid organization, which lets you leverage
organization-level features like [organization users](/user-guide/organization-users) and
[organization profiles](/user-guide/collaboration/organization-profiles/org-profiles-create-manage). The organization account also
contains [premium views](/user-guide/organization-accounts-premium-views) that contain organization-level usage data.

For more information about creating the organization account for a hybrid organization, see
[Compliance considerations for hybrid organizations](/user-guide/organization-accounts#label-orgs-hybrid-considerations).
