# Dec 01, 2025: CORTEX\_AISQL\_USAGE\_HISTORY Account Usage view (*General availability*)

The CORTEX\_AISQL\_USAGE\_HISTORY view in the SNOWFLAKE.ACCOUNT\_USAGE schema is now generally available. This view provides
detailed information about the usage of Cortex AI Functions in your SQL queries, providing finer-grained insights into
how AI features are being used in your account. For more information, see
[CORTEX\_AISQL\_USAGE\_HISTORY view](/sql-reference/account-usage/cortex_aisql_usage_history).
