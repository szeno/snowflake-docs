# Mar 27, 2025: Git integration and multi-file editing in Streamlit in Snowflake (Preview)

You can now create multipage Streamlit apps in [Snowsight](/user-guide/ui-snowsight-gs#label-snowsight-getting-started-sign-in) and sync your Streamlit apps with a Git repository.

For more information about multipage Streamlit apps, see [Multipage apps](/developer-guide/streamlit/app-development/file-organization#label-streamlit-multipage-apps).

For more information about Git integration, see [Sync Streamlit in Snowflake apps with a Git repository](/developer-guide/streamlit/features/git-integration).
