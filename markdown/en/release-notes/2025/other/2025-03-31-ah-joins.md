# Mar 31, 2025: Data Governance release notes

## Access history: Support for joins

Access history now tracks the joins that are explicitly mentioned in a query. If a query contains a join, the ACCESS\_HISTORY view includes
an array containing the joined objects and type of join.

For an example of how a join shows up in the access history, see [Join](/user-guide/access-history#label-access-history-joins).
