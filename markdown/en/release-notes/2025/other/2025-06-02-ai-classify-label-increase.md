# Jun 02, 2025: AI\_CLASSIFY supports up to 500 labels and multi-label classification

Use AI\_CLASSIFY to classify text into multiple categories and define up to 500 labels.

Instead of using the SNOWFLAKE.CORTEX.CLASSIFY\_TEXT function, which is limited to a single label and 100 categories, you can use AI\_CLASSIFY instead.

For more information about AI\_CLASSIFY, see [AI\_CLASSIFY](/sql-reference/functions/ai_classify).
