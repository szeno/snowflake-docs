# Sep 19, 2025: Read consistency mode for sessions with near-concurrent changes

You can set the [READ\_CONSISTENCY\_MODE](/sql-reference/parameters#label-read-consistency-mode) account-level parameter to define the level of consistency guarantees
that are required for sessions with near-concurrent changes.

For more information, see [Read consistency across sessions](/sql-reference/transactions#label-read-consistency-across-sessions) and [ALTER ACCOUNT](/sql-reference/sql/alter-account).
