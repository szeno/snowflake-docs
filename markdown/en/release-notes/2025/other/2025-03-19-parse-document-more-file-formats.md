# Mar 19, 2025: Additional file format support for Cortex AI Parse Document

Snowflake announces that the Cortex AI PARSE\_DOCUMENT function now supports an expanded range of file formats to deliver
more comprehensive document analysis. The new file formats are image formats and include TIFF, TIF, JPEG, JPG, and PNG.
PARSE\_DOCUMENT already supported PDF, DOCX, and PPTX file formats.

Customers can now use Cortex AI PARSE\_DOCUMENT to streamline document parsing and extract insights from all enterprise documents.

For details, see [Cortex PARSE\_DOCUMENT](/user-guide/snowflake-cortex/parse-document).
