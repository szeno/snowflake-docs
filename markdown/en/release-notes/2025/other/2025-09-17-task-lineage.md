# Sep 17, 2025: Data lineage for tasks

You can now use data lineage to determine that data moved from a source object to a downstream
object as the result of a [task](/user-guide/tasks-intro). Selecting the arrow that connects the source object and the downstream
object displays information about the task.

For more information about using data lineage, see [Data Lineage](/user-guide/ui-snowsight-lineage).
