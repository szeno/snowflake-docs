# 2026\_03 Bundle (Generally enabled)

## Bundle history

Attention

To determine the current status of bundles in your account,
see [SYSTEM$SHOW\_ACTIVE\_BEHAVIOR\_CHANGE\_BUNDLES](/sql-reference/functions/system_show_active_behavior_change_bundles).

For more information, see
[Behavior change management](/release-notes/bcr-bundles/managing-behavior-change-releases).

1. Introduced in the 10.12 release (April 2026) as **Disabled by Default**; account admins can enable for testing.
2. Status changed in the 10.17 release (May 8-14, 2026) to **Enabled by Default**; account admins can disable for opt-out.
3. Status changed in the 10.21 release (June 12-18, 2026) to **Generally Enabled**; account admins can no longer enable or disable this bundle.
