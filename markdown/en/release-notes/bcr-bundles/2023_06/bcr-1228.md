# Native Apps: GET\_DDL error message updated on APPLICATION PACKAGE

Attention

This behavior change is in the 2023\_06 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_06_bundle#label-behavior-change-bundle-2023-06-status).

In the current Snowflake release, the error message returned when running the GET\_DDL system function on
an APPLICATION PACKAGE database has changed.

Previously:
:   Running the GET\_DDL system function on an APPLICATION PACKAGE returns the following error message:

    ```
    SQL compilation error: Invalid object type: '{0}'
    ```

Currently:
:   Running the GET\_DDL system function on an APPLICATION PACKAGE will return the following updated error message:

    ```
    SQL compilation error: This operation is not supported on APPLICATION PACKAGE 'app pkg'
    ```

Ref: 1228
