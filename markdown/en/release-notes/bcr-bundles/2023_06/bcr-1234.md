# BLOCK\_NON\_READLIST\_OPERATIONS\_ON\_STAGES\_IN\_SECONDARY: Parameter set to TRUE by default

Attention

This behavior change is in the 2023\_06 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_06_bundle#label-behavior-change-bundle-2023-06-status).

Previously:
:   The BLOCK\_NON\_READLIST\_OPERATIONS\_ON\_STAGES\_IN\_SECONDARY parameter has a default value of `FALSE`.
    This means that the following write operations are allowed on stages in read-only database replicas by default:

    - [PUT](/sql-reference/sql/put)
    - [REMOVE](/sql-reference/sql/remove)
    - [ALTER STAGE … REFRESH](/sql-reference/sql/alter-stage)

Currently:
:   To be consistent with replication semantics where there is one primary (writeable)
    and one or more secondary replicas (readable), the BLOCK\_NON\_READLIST\_OPERATIONS\_ON\_STAGES\_IN\_SECONDARY
    parameter will have a default value of `TRUE`.

    Write operations on replicated stages will fail unless you set the value of the parameter to `FALSE`.
