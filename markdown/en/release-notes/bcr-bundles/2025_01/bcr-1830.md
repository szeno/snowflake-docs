# SYSTEM$GET\_COMPUTE\_POOL\_STATUS function: Deprecated

Attention

This behavior change is in the 2025\_01 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_01_bundle#label-behavior-change-bundle-2025-01-status).

The system\_get\_compute\_pool\_status function is being deprecated.

Before the change:
:   The SYSTEM$GET\_COMPUTE\_POOL\_STATUS function works and provides compute pool status information.

After the change:
:   The SYSTEM$GET\_COMPUTE\_POOL\_STATUS function is deprecated and will no longer work. Use the [DESCRIBE COMPUTE POOL](/sql-reference/sql/desc-compute-pool) command instead to get the same information.
