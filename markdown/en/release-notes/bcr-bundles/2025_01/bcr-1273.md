# Replication Groups: New column in output of SHOW command and Information Schema view

Attention

This behavior change is in the 2025\_01 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_01_bundle#label-behavior-change-bundle-2025-01-status).

When this behavior change bundle is enabled, the output of the
[SHOW REPLICATION GROUPS](/sql-reference/sql/show-replication-groups) command and
Information Schema [REPLICATION\_GROUPS view](/sql-reference/info-schema/replication_groups) include the following new column:

| Column name | Description |
| --- | --- |
| ERROR\_INTEGRATION | The name of the notification integration for the replication group or failover group to which the error notification is sent in cases of refresh failures. |
