# Mandatory multi-factor authentication on Snowsight login (Replaced)

Important

This behavior change has been replaced by a behavior change in the 2025\_06 bundle: [Multi-factor authentication: MFA\_ENROLLMENT parameter values change](/release-notes/bcr-bundles/2025_06/bcr-2097).

The new behavior change accomplishes the same thing: human users must authenticate with a second factor when using a password to access Snowsight.

This change is part of the planned deprecation of single-factor password sign-ins.

For information on the rollout of MFA, see [Planning for the deprecation of single-factor password sign-ins](/user-guide/security-mfa-rollout).

For Snowflake support of MFA, see [Configuring a second factor of authentication](/user-guide/security-mfa-second-factor).
