# Completed rollout of BYTES\_BILLED column in history views (Pending)

In the [2025\_05 bundle](/release-notes/bcr-bundles/2025_05/bcr-2045), Snowflake introduced the `BYTES_BILLED` column to provide visibility into Snowpipe costs. This rollout is now being completed to ensure that all remaining accounts have access to this billing metadata.

## Details of the change

The following views now consistently include the `BYTES_BILLED` column across all accounts:

- [ACCOUNT\_USAGE.PIPE\_USAGE\_HISTORY](/sql-reference/account-usage/pipe_usage_history)
- [ORGANIZATION\_USAGE.PIPE\_USAGE\_HISTORY](/sql-reference/organization-usage/pipe_usage_history)
- [INFORMATION\_SCHEMA.PIPE\_USAGE\_HISTORY](/sql-reference/functions/pipe_usage_history)
- [ACCOUNT\_USAGE.COPY\_HISTORY](/sql-reference/account-usage/copy_history)
- [ORGANIZATION\_USAGE.COPY\_HISTORY](/sql-reference/organization-usage/copy_history)
- [INFORMATION\_SCHEMA.COPY\_HISTORY](/sql-reference/functions/copy_history)

| Column name | Data type | Description |
| --- | --- | --- |
| `BYTES_BILLED` | NUMBER | The number of bytes Snowpipe uses for billing purposes. This provides visibility into Snowpipe’s cost implications within these history views. |

## Impact

The `BYTES_BILLED` column provides a direct metric for the data volume that is considered for billing, making it easier to monitor and manage Snowpipe-related expenses.
