# Interactive warehouses: Default and minimum AUTO\_SUSPEND reduced to 1 hour

Note

This behavior change was released on November 17, 2026. It isn’t part of a behavior change bundle, so it can’t be disabled.

As of November 17, 2026, the default and minimum values of the `AUTO_SUSPEND` property for [interactive warehouses](/user-guide/interactive) are 1 hour, reduced from 24 hours.

Before the change:
:   The default and minimum `AUTO_SUSPEND` value for an interactive warehouse was 86400 seconds (24 hours). Specifying a lower value returned an error.

After the change:
:   The default and minimum `AUTO_SUSPEND` value for an interactive warehouse is 3600 seconds (1 hour). Specifying a lower value returns an error.

    Existing interactive warehouses keep their current `AUTO_SUSPEND` value, including warehouses that were created without an explicit value. To use a shorter interval, set `AUTO_SUSPEND` with [ALTER WAREHOUSE](/sql-reference/sql/alter-warehouse).

    If you recreate an interactive warehouse with `CREATE OR REPLACE` without specifying `AUTO_SUSPEND`, the new default of 1 hour applies. To keep the 24-hour interval, set `AUTO_SUSPEND = 86400` explicitly.
