# Interactive warehouses: Default and minimum AUTO\_SUSPEND reduced to 1 hour (Pending)

Important

This change isn’t part of a behavior change bundle. It is planned for **November 17, 2026**. Dates are subject to change.

The default and minimum values of the AUTO\_SUSPEND property for [interactive warehouses](/user-guide/interactive) will be reduced from 24 hours to 1 hour.

Before the change:
:   The default and minimum AUTO\_SUSPEND value for an interactive warehouse is 86400 seconds (24 hours). Specifying a lower value returns an error.

After the change:
:   The default and minimum AUTO\_SUSPEND value for an interactive warehouse is 3600 seconds (1 hour). Specifying a lower value returns an error.

    Existing interactive warehouses keep their current AUTO\_SUSPEND value, including warehouses that were created without an explicit value. To use a shorter interval, set AUTO\_SUSPEND with [ALTER WAREHOUSE](/sql-reference/sql/alter-warehouse).

    If you recreate an interactive warehouse with CREATE OR REPLACE without specifying AUTO\_SUSPEND, the new default of 1 hour applies. To keep the 24-hour interval, set `AUTO_SUSPEND = 86400` explicitly.
