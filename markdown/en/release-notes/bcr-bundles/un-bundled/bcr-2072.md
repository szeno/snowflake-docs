# Snowflake Native Apps: Deprecation of Python versions 3.8 and 3.9

Note

This behavior change is not applicable if you are not a Snowflake Native App Provider and
you have not installed or intend to install a Snowflake Native App in your account.

Note

Snowflake released this behavior change on October 5, 2025. It isn’t part of a behavior
change bundle, so it can’t be disabled.

Snowflake deprecates and eventually decommissions versions of the Python runtime that are
no longer actively maintained. Starting October 5, 2025, Snowflake Native Apps no longer support
any decommissioned versions of Python. For more information on Snowflake’s Python runtime
support policy, see [Snowflake Python Runtime Support](/developer-guide/python-runtime-support-policy).

Before the change:
:   Snowflake Native Apps can create functions using decommissioned versions of the Python runtime.

After the change:
:   Snowflake Native Apps no longer supports decommissioned versions of the Python runtime. For more
    information, see [Considerations for Snowflake Native App providers](#label-native-apps-python-deprecation-providers) and
    [Considerations for Snowflake Native App consumers](#label-native-apps-python-deprecation-consumers).

## Considerations for Snowflake Native App providers

After this change, apps cannot create functions that use decommissioned versions of Python.
Providers cannot create or publish new versions of an app that attempt to create functions
that use decommissioned versions of Python. Existing published versions of an app that use
decommissioned versions of Python cannot be installed.

If an existing app uses a decommissioned version of the Python runtime, but does not create
new functions that use the decommissioned version, the app will continue to function.

## Considerations for Snowflake Native App consumers

After this change, consumers cannot install versions of an app that use decommissioned
versions of Python. Existing installations of an app that create new functions that use
decommissioned versions of Python will fail. If an existing app uses a decommissioned
version of the Python runtime, but does not create new functions that use the decommissioned
version, the app will continue to function.
