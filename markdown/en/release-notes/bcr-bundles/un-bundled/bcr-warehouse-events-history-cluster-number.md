# WAREHOUSE\_EVENTS\_HISTORY view: Change to the CLUSTER\_NUMBER column output

The output of the [WAREHOUSE\_EVENTS\_HISTORY](/sql-reference/account-usage/warehouse_events_history) view behaves as follows:

Before the change:
:   The default value of the CLUSTER\_NUMBER column is `0`.

After the change:
:   The default value of the CLUSTER\_NUMBER column is `1`.
