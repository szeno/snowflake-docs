# Deprecation of Legacy Worksheets and Dashboards

Snowflake has retired two legacy surfaces in Snowsight: **Legacy Worksheets** and
**Legacy Dashboards**.

- **Legacy Worksheets** are replaced by [Workspaces](/user-guide/ui-snowsight/workspaces), the modern SQL
  editing experience that supports file-and-folder organization, sharing, and Git integration.
- **Legacy Dashboards** are retired, with migration paths to Streamlit apps or third-party BI tools.

Important

Legacy Worksheets and the full Legacy Dashboards experience have been removed from Snowsight,
including in reader accounts. Workspaces is the replacement SQL editor. You can’t disable Workspaces or
switch back to Legacy Worksheets.

The removal rollout began on **June 22, 2026**. Remaining legacy worksheets were automatically migrated
to Workspaces files. For dashboards, the Dashboards list remains available for download and conversion
to Streamlit apps. See [Dashboard migration options](#dashboard-migration-options).

Note

[Reader accounts](/user-guide/data-sharing-intro#label-about-reader-accounts) were upgraded to Workspaces
in a rollout beginning **September 20, 2026**. Their worksheets were migrated automatically, and Legacy
Worksheets and the full Legacy Dashboards experience were removed. No worksheet migration action is
required from reader account administrators.

## Legacy Worksheets

Legacy Worksheets are replaced by [Workspaces](/user-guide/ui-snowsight/workspaces), a modern SQL editing
experience that supports file-and-folder organization, sharing, and Git integration. Workspaces is the default
SQL editor, including in reader accounts.

For the previous behavior change that defaulted accounts to Workspaces, see
[Defaulting accounts from Worksheets to Workspaces](/release-notes/bcr-bundles/un-bundled/bcr-2117).

Before the change:
:   Legacy Worksheets is available as a SQL editing experience in Snowsight. Account administrators and
    individual users can revert from Workspaces to Legacy Worksheets as the default editor using the
    `USE_WORKSPACES_FOR_SQL` parameter or the corresponding controls in the Snowsight settings.

After the change:
:   The Legacy Worksheets standalone UI is removed from Snowsight.

    - **April 20, 2026**: Workspaces could no longer be disabled with `ENABLE_PERSONAL_DATABASE`.
      Remaining accounts, except reader accounts, were defaulted to Workspaces as the SQL editor.
      Account administrators could temporarily revert the default editor to Legacy Worksheets until June 22, 2026.
    - **June 22, 2026**: Rollout to remove the Legacy Worksheets standalone UI began. Entry points to the
      Legacy Worksheets UI were removed from Snowsight. Setting `USE_WORKSPACES_FOR_SQL` to
      `'never'` is no longer supported. Remaining legacy worksheets were automatically migrated to Workspaces files.
    - **September 20, 2026**: The reader account upgrade began. Reader accounts now use Workspaces,
      and their remaining legacy worksheets were automatically migrated to Workspaces files.

### Bulk migration tool

During the transition, a self-service bulk migration tool let users convert Legacy Worksheets to
Workspaces files before automatic migration. Snowflake automatically migrated remaining worksheets after
the Legacy Worksheets UI was removed. You don’t need to run the bulk migration tool now.

### Python worksheets

Legacy Python worksheets were included in automatic migration so they remain executable after the
Legacy Worksheets UI was removed.

The bulk migration tool converted Python worksheets to Workspaces files named `worksheet_name.py.sql`.
These files contain the same stored procedure logic that Legacy Python worksheets used, so
migrated Python worksheets remain executable in Workspaces without relying on native Python support in
Workspaces. Snowflake recommends adopting native Python support in Workspaces over time, but it is not
required to continue running migrated Legacy Python worksheets.

### Shared worksheets

When shared worksheets were migrated to Workspaces files, a copy was created for each user who had
access. The shared status wasn’t preserved. The same copy behavior applied to both the bulk migration
tool and automatic migration.

For ongoing collaboration, use [shared workspaces](/user-guide/ui-snowsight/workspaces-shared), which
allow teams to collaborate in dedicated spaces with role-based access control and a wiki-style draft and
publish model. Shared workspaces are the recommended replacement for shared worksheets.

## Legacy Dashboards

Snowsight Dashboards are retired. Snowflake provides a Dashboard-to-Streamlit conversion tool to migrate
existing dashboards to Streamlit apps running natively on Snowflake. You can also migrate to any
third-party BI or visualization tool.

Before the change:
:   Snowsight Dashboards are available in Snowsight for creating and viewing dashboards.

After the change:
:   Snowsight Dashboards are removed from Snowsight.

    - **April 20, 2026**: Creation of new dashboards is disabled across all accounts. Any action that would
      create a new dashboard is blocked.
    - **June 22, 2026**: Rollout to remove dashboards from Snowsight begins and completes over a few
      weeks. The full dashboard viewing and editing experience is removed. A dashboards list remains
      accessible after removal so you can still download dashboards as JSON and convert dashboards to Streamlit apps.
    - **September 20, 2026**: Dashboards are removed from reader accounts.

### Dashboard migration options

- **Streamlit**: From the Dashboards list, select **Generate Streamlit app** to convert a dashboard to a
  Streamlit app running natively on Snowflake. The conversion wizard pre-selects the execution role and
  warehouse from the original dashboard, and the default system compute pool when one is available. You
  can change the role, warehouse, or compute pool in the wizard before completing the conversion. For
  cases that need adjustment, use
  [Cortex Code in Snowsight](/user-guide/cortex-code/cortex-code-snowsight) to fix issues or make
  further edits to the generated code. Select **Run** to test the app, and when you’re satisfied,
  select **Deploy** to publish it and share it with your team, replacing the original dashboard.
- **Download dashboard as JSON**: From the Dashboards list, click **Download** next to any dashboard to
  download it as a JSON file containing the dashboard’s queries, filters, name, and the names of the
  owner and shared users. Use this to manually migrate to Workspaces or another tool without going
  through the Streamlit conversion.
- **Third-party BI tools**: Migrate to any BI or visualization tool of your choice.

### Admin view

Account administrators can access a dashboard admin view that shows usage metrics across all dashboards in
the account. Use this to identify which dashboards are actively used and prioritize migration accordingly.
The admin view supports per-dashboard download and batch download. Batch download downloads all dashboards
on the current page (up to 100 at a time) as JSON files. Dashboards are displayed in pages of 100, so you
can repeat the batch download for each page to download all dashboards in the account.

Usage metrics are all-time unless a specific time range is noted. To identify dashboards that are actively
in use, Snowflake recommends filtering by runs in the last 30 days.

Important

The full Legacy Dashboards experience has been removed. The Dashboards list and admin view remain
accessible for dashboard download, Streamlit conversion, and monitoring.

## Actions required

### For Legacy Worksheets

1. **Verify Workspaces access**: Ensure your users can access
   [Workspaces](/user-guide/ui-snowsight/workspaces) and that it functions as expected for
   your workflows.
2. **Review migrated files**: Open Workspaces and verify that your migrated worksheet files are accessible.
3. **Restore collaboration where needed**: Previously shared worksheets were migrated as separate copies.
   Use [shared workspaces](/user-guide/ui-snowsight/workspaces-shared) for ongoing collaboration.
4. **Update automation or bookmarks**: If you have bookmarks, automation, or documentation that
   references Legacy Worksheets URLs or entry points, update them to use Workspaces.
5. **Reader accounts**: Worksheets were migrated automatically. No manual worksheet migration is required.

### For Snowsight Dashboards

1. **Migrate remaining dashboards**: The full dashboard experience has been removed, but the Dashboards list
   remains accessible for dashboard download and Streamlit conversion.
2. **Use the conversion tool**: From the Dashboards list, select **Generate Streamlit app** to convert a
   dashboard to a Streamlit app. For cases that need adjustment, use
   [Cortex Code in Snowsight](/user-guide/cortex-code/cortex-code-snowsight) to fix issues or make
   further edits to the generated code. Select **Run** to test the app, and when you’re satisfied,
   select **Deploy** to publish it and share it with your team, replacing the original dashboard.
3. **Download as a fallback**: If you prefer not to use Streamlit, click **Download** from the
   Dashboards list to save the dashboard as a JSON file containing its queries, filters, name, and
   the names of the owner and shared users.
4. **Consider alternative tools such as Snowflake CoWork**: You can also migrate to third-party BI or visualization tools.

## Additional notes

- **Reader accounts**: The earlier April and June milestones didn’t apply to reader accounts. Their upgrade
  began on **September 20, 2026** and is now complete. Workspaces is available, and no manual worksheet
  migration is required.
- **Legacy notebooks**: Legacy Notebooks are not affected by this deprecation and remain functional.
  Snowflake will address Legacy Notebooks through a separate BCR.
- **Temporary revert controls**: During the transition, account administrators and individual users could
  temporarily revert the default editor to Legacy Worksheets. The `USE_WORKSPACES_FOR_SQL` parameter
  and corresponding UI controls no longer provide a way to return to Legacy Worksheets. For the original announcement, see
  [Defaulting accounts from Worksheets to Workspaces](/release-notes/bcr-bundles/un-bundled/bcr-2117).
