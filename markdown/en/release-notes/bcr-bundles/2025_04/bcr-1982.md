# MODEL MONITOR METRIC functions: New columns in output

Attention

This behavior change is in the 2025\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_04_bundle#label-behavior-change-bundle-2025-04-status).

When this behavior change bundle is enabled, the output of the [MODEL\_MONITOR\_DRIFT\_METRIC](/sql-reference/functions/model-monitor-drift-metric), [MODEL\_MONITOR\_PERFORMANCE\_METRIC](/sql-reference/functions/model-monitor-performance-metric), and [MODEL\_MONITOR\_STAT\_METRIC](/sql-reference/functions/model-monitor-stat-metric) table functions includes the following new columns:

| Column name | Data type | Description |
| --- | --- | --- |
| SEGMENT\_COLUMN | STRING | Name of the segment column used in the metric calculation. |
| SEGMENT\_VALUE | STRING | Value of the segment for which the metric is calculated. |

To minimize potential impact, update your queries to explicitly select only the necessary columns instead of using a wildcard (`*`).
