# LOGIN\_HISTORY view and table function (Account Usage / Information Schema): New columns in output

Attention

This behavior change is in the 2025\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_04_bundle#label-behavior-change-bundle-2025-04-status).

When this behavior change bundle is enabled, the
[ACCOUNT\_USAGE LOGIN\_HISTORY view](/sql-reference/account-usage/login_history) and the output of the
[INFORMATION\_SCHEMA LOGIN\_HISTORY table function](/sql-reference/functions/login_history)
include the following new columns:

| Column name | Data type | Description |
| --- | --- | --- |
| `first_authentication_factor_id` | VARCHAR | ID of the credential used to authenticate the user (the first factor, if using [multi-factor authentication](/user-guide/security-mfa)). |
| `second_authentication_factor_id` | VARCHAR | ID of the credential used for the [second factor](/user-guide/security-mfa-second-factor), if using multi-factor authentication. If the user did not use multi-factor authentication, this value is NULL. |
