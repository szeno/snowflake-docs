# SHOW USERS and DESCRIBE USER commands: Changes to output

Attention

This behavior change is in the 2025\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_04_bundle#label-behavior-change-bundle-2025-04-status).

When this behavior change bundle is enabled, the output of the SHOW USERS and DESCRIBE USER commands includes column name changes related to
workload identity federation.

Note

This column was introduced into the [SHOW USERS](/sql-reference/sql/show-users) and [DESCRIBE USER](/sql-reference/sql/desc-user) commands in [BCR-1951](/release-notes/bcr-bundles/2025_03/bcr-1951) in the
[2025\_03 bundle](/release-notes/bcr-bundles/2025_03_bundle).

## SHOW USERS: Changes to column name

When this behavior change bundle is enabled, the output of the [SHOW USERS](/sql-reference/sql/show-users) command includes the
following column name change(s):

Before the change:
:   The column is named HAS\_FEDERATED\_WORKLOAD\_AUTHENTCATION

After the change:
:   The column is named HAS\_WORKLOAD\_IDENTITY

This column also appears in the output of SHOW TERSE USERS.

## DESCRIBE USER: Changes to column name

When this behavior change bundle is enabled, the output of the [DESCRIBE USER](/sql-reference/sql/desc-user) command includes the
following column name change(s):

Before the change:
:   The column is named HAS\_FEDERATED\_WORKLOAD\_AUTHENTCATION

After the change:
:   The column is named HAS\_WORKLOAD\_IDENTITY

This column is listed after the HAS\_PAT property and before the MINS\_TO\_BYPASS\_MFA property.
