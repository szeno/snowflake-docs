# Snowflake Native App Framework: New application packages enable release channels by default

Attention

This behavior change is in the 2025\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_04_bundle#label-behavior-change-bundle-2025-04-status).

When this behavior change bundle is enabled, new application packages will have
[release channels](/developer-guide/native-apps/release-channels) enabled by default.

| Before the change | Release channels are not enabled by default for an application package. The ENABLE\_RELEASE\_CHANNELS property of an application package is set to `FALSE`. |
| --- | --- |
| After the change | Release channels are enabled by default for an application package. The ENABLE\_RELEASE\_CHANNELS property of an application package is set to `TRUE`. |

After release channels are enabled for an application package, they cannot be disabled. To create an application package without release channels you must use the following syntax:

Copy code

```
CREATE APPLICATION PACKAGE <pkg_name> ENABLE_RELEASE_CHANNELS=FALSE;
```
