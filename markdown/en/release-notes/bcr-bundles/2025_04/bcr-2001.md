# SHOW DYNAMIC TABLES command: New columns added to output

Attention

This behavior change is in the 2025\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_04_bundle#label-behavior-change-bundle-2025-04-status).

When this behavior change bundle is enabled, the output of the [SHOW DYNAMIC TABLES](/sql-reference/sql/show-dynamic-tables) command includes
the following new columns:

| Column name | Description |
| --- | --- |
| INSERT ONLY INPUTS | Reserved for future use |
| IMMUTABLE WHERE | Reserved for future use |

These columns were added to support future functionality. Currently, these columns return an empty string.
