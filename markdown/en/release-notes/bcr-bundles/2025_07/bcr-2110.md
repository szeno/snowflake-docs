# SHOW WAREHOUSES command: New column in output

Attention

This behavior change is in the 2025\_07 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_07_bundle#label-behavior-change-bundle-2025-07-status).

When this behavior change bundle is enabled, the [SHOW WAREHOUSES](/sql-reference/sql/show-warehouses) command
output includes the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| `generation` | VARCHAR | A positive integer, currently either `1` or `2`. The VARCHAR type enables keyword values to be used in the future. |

This new column lets you check which of your standard warehouses are Gen1 or
[Gen2](/user-guide/warehouses-gen2).
