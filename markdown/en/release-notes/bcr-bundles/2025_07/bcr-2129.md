# DATABASE\_STORAGE\_USAGE\_HISTORY\_VIEW (ACCOUNT\_USAGE, ORGANIZATION\_USAGE): New columns

Attention

This behavior change is in the 2025\_07 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_07_bundle#label-behavior-change-bundle-2025-07-status).

When this behavior change bundle is enabled, the [DATABASE\_STORAGE\_USAGE\_HISTORY view](/sql-reference/account-usage/database_storage_usage_history) in the [ACCOUNT\_USAGE](/sql-reference/account-usage) schema and the [DATABASE\_STORAGE\_USAGE\_HISTORY view](/sql-reference/organization-usage/database_storage_usage_history) in the [ORGANIZATION\_USAGE](/sql-reference/organization-usage) schema include the following new columns:

| Column name | Data type | Description |
| --- | --- | --- |
| AVERAGE\_ARCHIVE\_STORAGE\_COOL\_BYTES | FLOAT | Reserved for future use. |
| AVERAGE\_ARCHIVE\_STORAGE\_COLD\_BYTES | FLOAT | Reserved for future use. |
| AVERAGE\_ARCHIVE\_STORAGE\_COOL\_FAILSAFE\_BYTES | FLOAT | Reserved for future use. |
| AVERAGE\_ARCHIVE\_STORAGE\_COLD\_FAILSAFE\_BYTES | FLOAT | Reserved for future use. |
