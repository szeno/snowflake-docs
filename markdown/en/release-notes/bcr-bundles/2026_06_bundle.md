# 2026\_06 Bundle (Enabled by default)

## Bundle history

1. Introduced in the 10.26 release (July 24-31, 2026) as **Disabled by Default**; account admins can enable for testing.
2. Status changed in the 10.32 release (September 5-9, 2026) to **Enabled by Default**; account admins can disable for opt-out.
3. Status planned to change in a subsequent release to **Generally Enabled**; however, this schedule is subject to change.
