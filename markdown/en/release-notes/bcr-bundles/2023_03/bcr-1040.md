# GRANT\_TO\_ROLES View (Account Usage): Privileges Added to View

Attention

This behavior change is in the 2023\_03 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_03_bundle#label-behavior-change-bundle-2023-03-status).

The behavior of the GRANTS\_TO\_ROLES Account Usage view in the shared SNOWFLAKE database behaves as follows:

Previously:
:   Grants to a role that include the account-level APPLY MASKING POLICY or APPLY ROW ACCESS policy privilege are not recorded in this view.

Currently:
:   Grants to a role that include the account-level APPLY MASKING POLICY or APPLY ROW ACCESS policy privilege are recorded in this view.

Ref: 1040
