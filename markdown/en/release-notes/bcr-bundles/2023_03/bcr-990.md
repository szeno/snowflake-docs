# TASK\_HISTORY Table Function (Information Schema): Consistent Values for Failed and Auto-suspended Tasks in ERROR\_ONLY Output

Attention

This behavior change is in the 2023\_03 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_03_bundle#label-behavior-change-bundle-2023-03-status).

Auto suspended tasks which fail will be in state FAILED\_AND\_AUTO\_SUSPENDED across all calls of the INFORMATION\_SCHEMA.TASK\_HISTORY table function:

Previously:
:   Calling TASK\_HISTORY with ERROR\_ONLY = true with auto-suspended tasks returns state = FAILED.

Currently:
:   Calling TASK\_HISTORY with ERROR\_ONLY = true with auto-suspended tasks returns state = FAILED\_AND\_AUTO\_SUSPENDED.

Ref: 990
