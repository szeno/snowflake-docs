# Account Usage Views: New INSTANCE\_ID Column in Select Views

Attention

This behavior change is in the 2023\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_04_bundle#label-behavior-change-bundle-2023-04-status).

The following views in the ACCOUNT\_USAGE schema include the column INSTANCE\_ID:

- AUTOMATIC\_CLUSTERING\_HISTORY
- SERVERLESS\_TASK\_HISTORY
- STAGES
- TABLES
- TASK\_HISTORY
- VIEWS

The INSTANCE\_ID column was added to support future functionality.
