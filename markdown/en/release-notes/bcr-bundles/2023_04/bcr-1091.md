# Account Usage Views: New OPTIONS Column in Select Views

Attention

This behavior change is in the 2023\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_04_bundle#label-behavior-change-bundle-2023-04-status).

The following ACCOUNT\_USAGE views include the OPTIONS column:

- MASKING\_POLICIES
- ROW\_ACCESS\_POLICIES

The OPTIONS column indicates whether a policy has the EXEMPT\_OTHER\_POLICIES property set to TRUE or FALSE:

- If the property is set to TRUE, the OPTIONS column returns {“EXEMPT\_OTHER\_POLICIES”: “TRUE”}.
- If the property is set to FALSE or the property is not specified in the policy, the OPTIONS column returns NULL.

Ref: 1091
