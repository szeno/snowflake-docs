# Data Sharing Usage Views: New CONSUMER\_NAME Column in Select Views

Attention

This behavior change is in the 2023\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_04_bundle#label-behavior-change-bundle-2023-04-status).

The following views in the DATA\_SHARING\_USAGE schema include the CONSUMER\_NAME column:

- LISTING\_ACCESS\_HISTORY
- LISTING\_CONSUMPTION\_DAILY
- LISTING\_EVENTS\_DAILY

Added column:

| Column Name | Data Type | Description |
| --- | --- | --- |
| CONSUMER\_NAME | VARCHAR | Contains the name of the consumer account that accessed, used, or requested a listing. If no name is available, such as for trial accounts, the value is NULL. |
