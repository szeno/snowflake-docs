# DATABASE\_STORAGE\_USAGE\_HISTORY View (Organization Usage): New Columns in View

Attention

This behavior change is in the 2023\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_04_bundle#label-behavior-change-bundle-2023-04-status).

The following columns were added as the last columns of the DATABASE\_STORAGE\_USAGE\_HISTORY view in the ORGANIZATION\_USAGE
schema:

| Column Name | Data Type | Description |
| --- | --- | --- |
| DATABASE\_ID | NUMBER | Internal/system-generated identifier for the database. |
| DELETED | TIMESTAMP\_LTZ | Date and time when the database was dropped; NULL for active databases. |
