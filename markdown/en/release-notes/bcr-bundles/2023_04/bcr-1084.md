# LISTING\_TELEMETRY\_DAILY View (Data Sharing Usage): New Value for EVENT\_TYPE Column

Attention

This behavior change is in the 2023\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_04_bundle#label-behavior-change-bundle-2023-04-status).

The LISTING\_TELEMETRY\_DAILY View in the DATA\_SHARING\_USAGE schema includes a value for the EVENT\_TYPE column.

Previously:
:   EVENT\_TYPE column contains a value for the event that occurred for the listing. One of: GET, REQUEST, or LISTING CLICK.

Currently:
:   EVENT\_TYPE column adds a new value of LISTING VIEW, recorded when a consumer visits a specific listing detail page.

Ref: 1084
