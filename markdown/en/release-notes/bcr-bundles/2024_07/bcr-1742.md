# NOTIFICATION\_HISTORY table function: Removal of the `message` column from the output

Attention

This behavior change is in the 2024\_07 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_07_bundle#label-behavior-change-bundle-2024-07-status).

In the output of the [NOTIFICATION\_HISTORY](/sql-reference/functions/notification_history) table function, the `message` column is being removed.
It was previously announced that [this column was deprecated](/release-notes/bcr-bundles/2024_04/bcr-1593#label-bcr-1593-column-deprecation).

If you need context around a notification (for example, which task sent the notification), you can use the information in the
`message_source_info` column of the output.

If you have queries that rely on data from the message column, you should rewrite these queries.

Ref: 1742
