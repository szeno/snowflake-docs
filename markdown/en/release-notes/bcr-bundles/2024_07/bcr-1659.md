# SHOW/DESC PIPE[S] commands: New column in output

Attention

This behavior change is in the 2024\_07 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_07_bundle#label-behavior-change-bundle-2024-07-status).

When this behavior change bundle is enabled, the output of the [SHOW PIPES](/sql-reference/sql/show-pipes)
and [DESCRIBE PIPE](/sql-reference/sql/desc-pipe) commands will include the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| KIND | VARCHAR | The kind of the pipe, either KAFKA or STAGE. |
