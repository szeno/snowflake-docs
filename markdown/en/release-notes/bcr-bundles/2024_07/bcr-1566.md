# LISTING\_EVENTS\_DAILY: new columns in output

Attention

This behavior change is in the 2024\_07 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_07_bundle#label-behavior-change-bundle-2024-07-status).

When this behavior change bundle is enabled, two new columns appear in
[LISTING\_EVENTS\_DAILY view](/sql-reference/data-sharing-usage/listing-events-daily) in the
[Data Sharing Usage](/sql-reference/data-sharing-usage) schema.

| Column name | Data type | Description |
| --- | --- | --- |
| ACCESS\_TYPE | VARCHAR | The access type of the listing. The access type is also called the monetization type. |
| EVENT\_TIMESTAMP | DATETIME | The date and time that a listing-related event occurred. |
