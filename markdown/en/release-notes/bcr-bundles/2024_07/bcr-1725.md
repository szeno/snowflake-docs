# SHOW WAREHOUSES command: New column in output

Attention

This behavior change is in the 2024\_07 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_07_bundle#label-behavior-change-bundle-2024-07-status).

When this behavior change bundle is enabled, the output of the [SHOW WAREHOUSES](/sql-reference/sql/show-warehouses)
command will include the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| `resource_constraint` | VARCHAR | Reserved for future use. |
