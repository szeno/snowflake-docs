# NOTIFICATION\_HISTORY table function: New column in output

Attention

This behavior change is in the 2024\_01 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_01_bundle#label-behavior-change-bundle-2024-01-status).

The output of the [NOTIFICATION\_HISTORY](/sql-reference/functions/notification_history) table function changes as follows:

Before the change:
:   The output of the table function does not include an ERROR\_MESSAGE column.

After the change:
:   The output of the table function includes an ERROR\_MESSAGE column that contains details about why a notification failed.

    | Column name | Data type | Description |
    | --- | --- | --- |
    | ERROR\_MESSAGE | VARCHAR | Details about why the notification failed. |
