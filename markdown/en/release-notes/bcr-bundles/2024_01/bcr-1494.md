# DESC SECRET command: Add INTEGRATION\_NAME column

Attention

This behavior change is in the 2024\_01 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_01_bundle#label-behavior-change-bundle-2024-01-status).

The behavior of the [DESCRIBE SECRET](/sql-reference/sql/desc-secret) command is as follows:

Before the change:
:   The output of the command did not include the `integration_name` column

After the change:
:   The output of the command includes the `integration_name` column as the last column in the output.

    | Column name | Data type | Description |
    | --- | --- | --- |
    | `integration_name` | VARCHAR | Specifies the name of the External API Authentication integration that references the secret or NULL if the integration does not specify a secret. |
