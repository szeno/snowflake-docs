# SHOW USERS and DESCRIBE USER commands: Changes to output

Attention

This behavior change is in the 2025\_03 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_03_bundle#label-behavior-change-bundle-2025-03-status).

When this behavior change bundle is enabled, the output of the [SHOW USERS](/sql-reference/sql/show-users) and
[DESCRIBE USER](/sql-reference/sql/desc-user) commands includes additional information about different authentication methods:

- [SHOW USERS: New columns in output](#label-bcr-1951-show-users)
- [DESCRIBE USER: New properties in output](#label-bcr-1951-desc-user)

## SHOW USERS: New columns in output

When this behavior change bundle is enabled, the output of the SHOW USERS command includes the following new columns:

| Column name | Description |
| --- | --- |
| `has_pat` | If `true`, the user has one or more programmatic access tokens. |
| `has_federated_workload_authentication` | Reserved for future use. |

These columns also appear in the output of SHOW TERSE USERS.

## DESCRIBE USER: New properties in output

When this behavior change bundle is enabled, the output of the DESCRIBE USER command includes the following new properties:

| Property name | Description |
| --- | --- |
| HAS\_PAT | If `true`, the user has one or more programmatic access tokens. |
| HAS\_FEDERATED\_WORKLOAD\_AUTHENTICATION | Reserved for future use. |

These properties are listed after the HAS\_MFA property and before the MINS\_TO\_BYPASS\_MFA property.
