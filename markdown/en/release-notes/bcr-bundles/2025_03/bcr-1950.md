# SHOW CHANNELS command: New columns in output

Attention

This behavior change is in the 2025\_03 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_03_bundle#label-behavior-change-bundle-2025-03-status).

When this behavior change bundle is enabled, the output of the [SHOW CHANNELS](/sql-reference/sql/show-channels) command includes the following new columns.

| Column name | Description |
| --- | --- |
| `parent_domain` | Indicates the type of the target domain of the channel. Possible values are TABLE or PIPE. |
| `parent_name` | Displays the name of the specific table or pipe that is the target of the channel. |
