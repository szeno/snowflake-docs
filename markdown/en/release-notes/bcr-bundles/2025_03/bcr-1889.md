# SHOW WAREHOUSES command: New columns in output

Attention

This behavior change is in the 2025\_03 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_03_bundle#label-behavior-change-bundle-2025-03-status).

When this behavior change bundle is enabled, the output of the
[SHOW WAREHOUSES](/sql-reference/sql/show-warehouses) command
includes the following new columns:

| Column name | Description |
| --- | --- |
| warehouse\_credit\_limit | Reserved for future use |
| target\_statement\_size | Reserved for future use |
| disabled\_reasons | Reserved for future use |
