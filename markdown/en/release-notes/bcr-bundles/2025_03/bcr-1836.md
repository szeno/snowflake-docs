# SHOW SNAPSHOTS and DESCRIBE SNAPSHOT commands: New column in output

Attention

This behavior change is in the 2025\_03 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_03_bundle#label-behavior-change-bundle-2025-03-status).

When this behavior change bundle is enabled, the output of the [DESCRIBE SNAPSHOT](/sql-reference/sql/desc-snapshot) and [SHOW SNAPSHOTS](/sql-reference/sql/show-snapshots) commands include the following new column:

| Column name | Description |
| --- | --- |
| ENCRYPTION | Encryption type configured for the volume, from which the snapshot was created. The value can be SNOWFLAKE\_SSE or SNOWFLAKE\_FULL. |
