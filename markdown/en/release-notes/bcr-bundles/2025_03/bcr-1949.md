# SHOW GIT REPOSITORIES and DESC GIT REPOSITORY commands: LAST\_OPERATION\_STATUS column removed from output

Attention

This behavior change is in the 2025\_03 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_03_bundle#label-behavior-change-bundle-2025-03-status).

When this behavior change bundle is enabled, the output of the [SHOW GIT REPOSITORIES](/sql-reference/sql/show-git-repositories) and
[DESCRIBE GIT REPOSITORY](/sql-reference/sql/desc-git-repository) commands no longer includes the following column:

| Column name | Data type | Description |
| --- | --- | --- |
| LAST\_OPERATION\_STATUS | None. | Column will be removed. Its value was always NULL. |
