# SHOW ORGANIZATION ACCOUNTS command / ACCOUNTS view (Organization Usage): New Column

Attention

This behavior change is in the 2023\_08 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_08_bundle#label-behavior-change-bundle-2023-08-status).

The behavior of the [SHOW ORGANIZATION ACCOUNTS](/sql-reference/sql/show-organization-accounts) command and the [ACCOUNTS view](/sql-reference/organization-usage/accounts) in the Organization Usage schema is as follows:

Before the change:
:   The command output and view do not contain the IS\_EVENTS\_ACCOUNT column.

After the change:
:   The command output and view contain the IS\_EVENTS\_ACCOUNT column.

Which is defined as follows:

| Column Name | Data Type | Description |
| --- | --- | --- |
| IS\_EVENTS\_ACCOUNT | BOOLEAN | Indicates whether an account is an events account.  The [Snowflake Native Apps Framework](/developer-guide/native-apps/native-apps-about) uses an events account to set up logging and event sharing to help troubleshoot installed applications. |
