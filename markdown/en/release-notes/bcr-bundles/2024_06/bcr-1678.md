# SHOW FUNCTIONS IN MODEL Command: New column in output

Attention

This behavior change is in the 2024\_06 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_06_bundle#label-behavior-change-bundle-2024-06-status).

When this behavior change bundle is enabled, the output of the
[SHOW FUNCTIONS IN MODEL](/sql-reference/sql/show-functions-in-model) command includes the following new column:

| Column Name | Description |
| --- | --- |
| `is_table_function` | Whether the function is a [table function](/sql-reference/functions-table), a function that returns tabular data rather than a single value. Possible values are:   - TRUE: The function is a table function (UDTF) - FALSE: The function is a regular function (UDF) |
