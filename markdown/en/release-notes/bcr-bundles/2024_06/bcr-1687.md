# NOTIFICATION\_HISTORY function: New source type BUDGET in MESSAGE\_SOURCE column

Attention

This behavior change is in the 2024\_06 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_06_bundle#label-behavior-change-bundle-2024-06-status).

When this behavior change bundle is enabled, the output of the
[NOTIFICATION\_HISTORY](/sql-reference/functions/notification_history) function behaves as follows:

Before the change:
:   If you are using the Budgets feature, the output of the NOTIFICATION\_HISTORY function is as follows for the message source and
    information columns:

    - MESSAGE\_SOURCE: STORED\_PROCEDURE
    - MESSAGE\_SOURCE\_INFO: NULL

After the change:
:   If you are using the Budgets feature, the output of the NOTIFICATION\_HISTORY function is as follows for the message source and
    information columns:

    - MESSAGE\_SOURCE: BUDGET
    - MESSAGE\_SOURCE\_INFO: Budget ID and name

Ref: 1687
