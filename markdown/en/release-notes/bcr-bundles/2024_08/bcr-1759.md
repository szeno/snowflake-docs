# DATABASES and SCHEMATA views, and SHOW DATABASES and SHOW SCHEMAS commands: New column in output

Attention

This behavior change is in the 2024\_08 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_08_bundle#label-behavior-change-bundle-2024-08-status).

When this behavior change bundle is enabled, a new column, OBJECT\_VISIBILITY, will be added to the following
[ACCOUNT\_USAGE](/sql-reference/account-usage) views:

- [DATABASES](/sql-reference/account-usage/databases)
- [SCHEMATA](/sql-reference/account-usage/schemata)

OBJECT\_VISIBILITY will also be available in the output of the [SHOW DATABASES](/sql-reference/sql/show-databases) and
[SHOW SCHEMAS](/sql-reference/sql/show-schemas) commands.

| Column Name | Data Type | Description |
| --- | --- | --- |
| OBJECT\_VISIBILITY | OBJECT | The new column is appended to the existing views and is reserved for future use. |
