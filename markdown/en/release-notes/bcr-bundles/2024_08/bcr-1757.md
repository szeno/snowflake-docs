# SHOW SCHEMAS command: New columns in output

Attention

This behavior change is in the 2024\_08 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_08_bundle#label-behavior-change-bundle-2024-08-status).

When this behavior change bundle is enabled, the output of the [SHOW SCHEMAS](/sql-reference/sql/show-schemas) command includes the following new
columns at the end:

| Column name | Description |
| --- | --- |
| CLASSIFICATION\_PROFILE\_DATABASE | Reserved for future use. |
| CLASSIFICATION\_PROFILE\_SCHEMA | Reserved for future use. |
| CLASSIFICATION\_PROFILE | Reserved for future use. |
