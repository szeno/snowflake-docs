# Stronger Default Password Policies

Attention

This behavior change is in the 2024\_08 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_08_bundle#label-behavior-change-bundle-2024-08-status).

When this behavior change bundle is enabled, the default values for the PASSWORD\_MIN\_LENGTH and PASSWORD\_HISTORY parameters in password
policies behaves as follows:

Before the change:
:   Default value for PASSWORD\_MIN\_LENGTH is 8

    Default value for PASSWORD\_HISTORY is 0

After the change:
:   Default value for PASSWORD\_MIN\_LENGTH is 14

    Default value for PASSWORD\_HISTORY is 5

Ref: 1776
