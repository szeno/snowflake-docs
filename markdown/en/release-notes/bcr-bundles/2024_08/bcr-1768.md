# Default value for the SYNC\_PASSWORD parameter on SCIM security integrations has changed

Attention

This behavior change is in the 2024\_08 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_08_bundle#label-behavior-change-bundle-2024-08-status).

When this behavior change bundle is enabled, the default value of the SYNC\_PASSWORD parameter on SCIM security integrations behaves as
follows:

Before the change:
:   If not set, SYNC\_PASSWORD is set to TRUE.

After the change:
:   If not set, SYNC\_PASSWORD is set to FALSE.

Ref: 1768
