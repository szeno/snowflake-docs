# SHOW DYNAMIC TABLES command and DYNAMIC\_TABLES function: New changes to output

Attention

This behavior change is in the 2024\_08 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_08_bundle#label-behavior-change-bundle-2024-08-status).

The [SHOW DYNAMIC TABLES](/sql-reference/sql/show-dynamic-tables) and [DYNAMIC\_TABLES](/sql-reference/functions/dynamic_tables) output behaves as follows:

Before the change:
:   The output of the SHOW DYNAMIC TABLES command and the DYNAMIC\_TABLES function does not include the `is_iceberg` column.

After the change:
:   The output of the SHOW DYNAMIC TABLES command and the DYNAMIC\_TABLES function includes the `is_iceberg` column, which is defined as
    follows:

    | Column Name | `is_iceberg` |
    | --- | --- |
    | Data Type | Text |
    | Description | Y if the table is an Apache Iceberg™ dynamic table; otherwise, N. |
