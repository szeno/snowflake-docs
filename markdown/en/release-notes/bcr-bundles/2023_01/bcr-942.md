# SHOW ORGANIZATION ACCOUNTS Command: New Column in Output

Attention

This behavior change is in the 2023\_01 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_01_bundle#label-behavior-change-bundle-2023-01-status).

The following column has been added to the output of the [SHOW ORGANIZATION ACCOUNTS](/sql-reference/sql/show-organization-accounts) command:

| Column Name | Data Type | Description |
| --- | --- | --- |
| IS\_ORG\_ADMIN | BOOLEAN | Indicates whether the ORGADMIN role is enabled in an account. An account with the ORGADMIN role enabled is called the ORGADMIN account. |

Show lessSee more

To help minimize the impact of this addition, the column has been added as the last column in the output.
