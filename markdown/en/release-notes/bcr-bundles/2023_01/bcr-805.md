# System Functions: MONITOR SECURITY Privilege Required to Execute Certain System Functions

Attention

This behavior change is in the 2023\_01 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_01_bundle#label-behavior-change-bundle-2023-01-status).

The behavior of these system functions has changed as follows:

- SYSTEM$GET\_CMK\_KMS\_KEY\_POLICY
- SYSTEM$GET\_CMK\_AKV\_CONSENT\_URL
- SYSTEM$GET\_GCP\_KMS\_CMK\_GRANT\_ACCESS\_CMD

Previously:
:   These functions were not guarded by any specific privilege.

Currently:
:   To call these functions, the active role or a role in the active role hierarchy must have the MONITOR SECURITY privilege.

Ref: 805
