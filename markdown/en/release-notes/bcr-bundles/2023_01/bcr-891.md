# TABLES, VIEWS, and EXTERNAL\_TABLES Views (Account Usage, Information Schema): New Columns Added

Attention

This behavior change is in the 2023\_01 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_01_bundle#label-behavior-change-bundle-2023-01-status).

New columns for tracking DDL operations have been added to the following Account Usage and Information Schema views:

- ACCOUNT\_USAGE:

  - [TABLES](/sql-reference/account-usage/tables)
  - [VIEWS](/sql-reference/account-usage/views)
- INFORMATION\_SCHEMA:

  - [TABLES](/sql-reference/info-schema/tables) and [EXTERNAL\_TABLES](/sql-reference/info-schema/external_tables)
  - [VIEWS](/sql-reference/info-schema/views)

New columns:

| Column Name | Data Type | Description |
| --- | --- | --- |
| LAST\_DDL | TIMESTAMP | Specifies the timestamp of the last DDL operation performed on the table or view. |
| LAST\_DDL\_BY | TEXT | Specifies the username of the user who performed the last DDL operation on the table or view. |
