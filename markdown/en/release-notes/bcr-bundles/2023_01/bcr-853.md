# TABLES View (Account Usage): Changes to the RETENTION\_TIME Column

Attention

This behavior change is in the 2023\_01 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_01_bundle#label-behavior-change-bundle-2023-01-status).

The RETENTION\_TIME column value in the Account Usage [TABLES](/sql-reference/account-usage/tables) view has changed
as follows:

Previously:
:   In the following cases, the RETENTION\_TIME column might have displayed an incorrect data retention time for tables:

    - If the DATA\_RETENTION\_TIME\_IN\_DAYS was not explicitly set for a transient table, the RETENTION\_TIME column displayed the value
      inherited from a parent object. This value might have been incorrect. The maximum data retention time for transient tables
      is 1 day.
    - If the MIN\_DATA\_RETENTION\_TIME\_IN\_DAYS parameter was set for an account, the RETENTION\_TIME column ignored this minimum
      retention time and might have displayed an incorrect value for a table.

Currently:
:   The RETENTION\_TIME column now displays the correct data retention time for tables.
