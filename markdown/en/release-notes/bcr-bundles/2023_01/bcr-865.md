# SHOW Commands: New Column Added to Output for Certain Commands

Attention

This behavior change is in the 2023\_01 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_01_bundle#label-behavior-change-bundle-2023-01-status).

The output of these SHOW commands now includes a new OPTIONS column:

- [SHOW MASKING POLICIES](/sql-reference/sql/show-masking-policies)
- SHOW ACCESS POLICIES
- [SHOW SESSION POLICIES](/sql-reference/sql/show-session-policies)
- [SHOW PASSWORD POLICIES](/sql-reference/sql/show-password-policies)

The column was added to support future functionality. Currently, this column returns an empty string.

Ref: 865
