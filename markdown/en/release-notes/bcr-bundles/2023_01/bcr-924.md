# GET\_DDL Function: Tags Set on Streams, Tasks, and Pipes Included in Output

Attention

This behavior change is in the 2023\_01 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_01_bundle#label-behavior-change-bundle-2023-01-status).

The output of the [GET\_DDL](/sql-reference/functions/get_ddl) function now include any tag objects that are set on a stream, task,
or pipe. The tag associations are specified in the WITH clause of the CREATE OR REPLACE <object> command and allow creating or
replacing an object with tags already assigned to the object.
