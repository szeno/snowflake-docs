# ARRAY\_POSITION Function: Changes to Finding the Position of a NULL Value

Attention

This behavior change is in the 2023\_01 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_01_bundle#label-behavior-change-bundle-2023-01-status).

When you call the [ARRAY\_POSITION](/sql-reference/functions/array_position) function and pass in a value as the first argument, the
function returns the position of the first ARRAY element with that value.

The ARRAY\_POSITION function has changed when you specify NULL as the first argument:

Previously:
:   The function returned NULL. For example:

    Copy code

    ```
    SELECT ARRAY_POSITION(NULL, [10, NULL, 30]);

    +--------------------------------------+
    | ARRAY_POSITION(NULL, [10, NULL, 30]) |
    |--------------------------------------|
    |                                 NULL |
    +--------------------------------------+
    ```

Currently:
:   The function returns the position of the first NULL in the ARRAY. For example:

    Copy code

    ```
    SELECT ARRAY_POSITION(NULL, [10, NULL, 30]);
    +--------------------------------------+
    | ARRAY_POSITION(NULL, [10, NULL, 30]) |
    |--------------------------------------|
    |                                    1 |
    +--------------------------------------+
    ```

This change was implemented for consistency with the [ARRAY\_CONTAINS](/sql-reference/functions/array_contains) function. When you use the
ARRAY\_CONTAINS function to determine if an ARRAY contains NULL, the function returns TRUE.
