# STAGES View (ACCOUNT\_USAGE): New Column STORAGE\_INTEGRATION

Attention

This behavior change is in the 2024\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_04_bundle#label-behavior-change-bundle-2024-04-status).

When this behavior change bundle is enabled, the [ACCOUNT\_USAGE.STAGES view](/sql-reference/account-usage/stages) includes the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| STORAGE\_INTEGRATION | TEXT | The name of the [storage integration](/sql-reference/sql/create-storage-integration) associated with the stage; NULL for internal stages or stages that do not use a storage integration. |
