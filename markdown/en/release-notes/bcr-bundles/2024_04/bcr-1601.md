# LISTING\_CONSUMPTION\_DAILY view: New columns

Attention

This behavior change is in the 2024\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_04_bundle#label-behavior-change-bundle-2024-04-status).

When this behavior change bundle is enabled, the [LISTING\_CONSUMPTION\_DAILY view](/sql-reference/data-sharing-usage/listing-consumption-daily) includes the following new column(s):

| Column name | Data type | Description |
| --- | --- | --- |
| UNIQUE\_USERS\_1D | INT | Count of unique users in 1 day. |
| UNIQUE\_USERS\_7D | INT | Count of unique users in 7 days. |
| UNIQUE\_USERS\_28D | INT | Count of unique users in 28 days. |
