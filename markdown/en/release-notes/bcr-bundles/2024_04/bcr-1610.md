# Account Usage views: Add support for versioned schemas in Snowflake Native Apps

Attention

This behavior change is in the 2024\_04 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_04_bundle#label-behavior-change-bundle-2024-04-status).

This behavior change alters the output of [Account Usage views](/sql-reference/account-usage) to include information about versioned schemas.

Note

This behavior change is a follow-up to the following behavior changes:

- [Account Usage views: Add support for versioned schemas in Snowflake Native App](/release-notes/bcr-bundles/2024_03/bcr-1570)
- [Account Usage views: Additional rows added to support versioned schemas](/release-notes/bcr-bundles/2024_02/bcr-1544)
- [Account Usage views: Add support for versioned schemas in Snowflake Native Apps](/release-notes/bcr-bundles/2024_01/bcr-1463)

Before the change:
:   Some Account Usage views may not display information about versioned schemas.

After the change:
:   The Account Usage views contain information about versioned schemas as described.

**View affected by this change**

> This behavior change modifies the following views to include additional rows if the schema is a versioned schema:
>
> - [GRANTS\_TO\_ROLES view](/sql-reference/account-usage/grants_to_roles)

Ref: 1610
