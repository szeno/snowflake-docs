# Key-pair authentication for Google Cloud accounts in the us-central1 region

Attention

This behavior change is in the 2025\_05 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_05_bundle#label-behavior-change-bundle-2025-05-status).

When this behavior change bundle is enabled, key-pair authentication for Google Cloud accounts in the `us-central1` region
changes in the following way:

Before the change:
:   When you use key-pair authentication from a Snowflake account in the Google Cloud `us-central1` region, specifying the account
    by using an account locator with [additional segments](/user-guide/gen-conn-config#label-client-account-formats) is supported.

After the change:
:   When you use key-pair authentication across all cloud platforms and regions, you must specify the account by using *only* the
    account locator *without* additional segments.

    For information about constructing key-pair tokens, see the procedure for [generating a JWT](/developer-guide/snowflake-rest-api/authentication#label-sfrest-api-jwt-token).

Ref: 2055
