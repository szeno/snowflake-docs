# SHOW APPLICATIONS and SHOW APPLICATION PACKAGES commands: New column in output: TYPE

Attention

This behavior change is in the 2025\_05 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_05_bundle#label-behavior-change-bundle-2025-05-status).

When this behavior change bundle is enabled, the output of the [SHOW APPLICATIONS](/sql-reference/sql/show-applications) and [SHOW APPLICATION PACKAGES](/sql-reference/sql/show-application-packages) commands includes the following new column:

| Column name | Description |
| --- | --- |
| `type` | Shows whether the app is a standard Snowflake Native App or a Snowflake Declarative Native App. |
