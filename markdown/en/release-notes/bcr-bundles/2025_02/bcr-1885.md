# DATA\_CLASSIFICATION\_LATEST view (ACCOUNT\_USAGE): `schemaId` column name changed to `schema_id`

Attention

This behavior change is in the 2025\_02 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_02_bundle#label-behavior-change-bundle-2025-02-status).

With this behavior change, the name of the `schemaId` column in the ACCOUNT\_USAGE
[DATA\_CLASSIFICATION\_LATEST view](/sql-reference/account-usage/data_classification_latest) is changing to `schema_id`.

If you have SQL statements that refer to the column name `schemaId`, you must change those statements to use `schema_id` as
the column name.

Before the change:
:   Referring to the column name `schemaId` does not cause a SQL statement to fail. For example:

    Copy code

    ```
    SELECT schemaId FROM SNOWFLAKE.ACCOUNT_USAGE.DATA_CLASSIFICATION_LATEST LIMIT 1;
    ```

    ```
    +----------+
    | SCHEMAID |
    |----------|
    | ...      |
    +----------+
    ```

After the change:
:   Referring to the column name `schemaId` causes a SQL statement to fail. For example:

    Copy code

    ```
    SELECT schemaId FROM SNOWFLAKE.ACCOUNT_USAGE.DATA_CLASSIFICATION_LATEST LIMIT 1;
    ```

    ```
    000904 (42000): SQL compilation error: error line 1 at position 7
    invalid identifier 'SCHEMAID'
    ```
