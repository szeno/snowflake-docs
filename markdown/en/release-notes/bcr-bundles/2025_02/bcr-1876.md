# APPLICATION\_STATE view: New columns in output

Attention

This behavior change is in the 2025\_02 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_02_bundle#label-behavior-change-bundle-2025-02-status).

When this behavior change bundle is enabled, the output of the
[DATA\_SHARING\_USAGE.APPLICATION\_STATE](/sql-reference/data-sharing-usage/application-state-view)
view will contain the following new columns:

| Column name | Description |
| --- | --- |
| CURRENT\_RELEASE\_CHANNEL\_NAME | Displays the name of the current [release channel](/developer-guide/native-apps/release-channels) of the app. |
| LAST\_UPGRADED\_ON | Displays the date when the app was last upgraded. |
