# DESCRIBE SECRET command: New columns in output

Attention

This behavior change is in the 2025\_02 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_02_bundle#label-behavior-change-bundle-2025-02-status).

When this behavior change bundle is enabled, the output of the [DESCRIBE SECRET](/sql-reference/sql/desc-secret) command and
[SECRETS view](/sql-reference/account-usage/secrets) include the following new columns:

| Column name | Data type | Description |
| --- | --- | --- |
| algorithm | string | The algorithm used to generate the secret. |
| key\_length | number | The length of the key used to generate the secret. |
