# SHOW ICEBERG TABLES command: New column ICEBERG\_TABLE\_AUTO\_REFRESH\_STATUS in output

Attention

This behavior change is in the 2025\_02 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_02_bundle#label-behavior-change-bundle-2025-02-status).

When this behavior change bundle is enabled, the output of the SHOW ICEBERG TABLES command includes the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| AUTO\_REFRESH\_STATUS | String | The automated refresh status for an externally managed Apache Iceberg™ table.  The column displays the same results for the table as the [SYSTEM$AUTO\_REFRESH\_STATUS](/sql-reference/functions/system_auto_refresh_status) function. |
