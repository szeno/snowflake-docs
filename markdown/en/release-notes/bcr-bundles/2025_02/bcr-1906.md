# SHOW RELEASE DIRECTIVES command: New column in output

Attention

This behavior change is in the 2025\_02 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_02_bundle#label-behavior-change-bundle-2025-02-status).

When this behavior change bundle is enabled, the output of the [SHOW RELEASE DIRECTIVES](/sql-reference/sql/show-release-directives)
command will contain the following new column:

| Column name | Description |
| --- | --- |
| UPGRADE\_AFTER | Indicates the earliest date that the release directive is allowed to start an automatic upgrade. |
