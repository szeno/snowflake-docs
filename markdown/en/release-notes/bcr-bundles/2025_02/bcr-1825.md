# SHOW IMAGE REPOSITORIES command: New column in output and removal of image repositories from the SHOW STAGES command output

Attention

This behavior change is in the 2025\_02 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_02_bundle#label-behavior-change-bundle-2025-02-status).

## SHOW IMAGE REPOSITORIES command: New column in output

When this behavior change bundle is enabled, the output of the [SHOW IMAGE REPOSITORIES](/sql-reference/sql/show-image-repositories) command includes the following new column:

| Column name | Description |
| --- | --- |
| ENCRYPTION | Encryption type configured for the image repository. |

## SHOW STAGES command: Output changes

When this behavior change bundle is enabled, the output of the [SHOW STAGES](/sql-reference/sql/show-stages) command will not return image repositories in the Snowflake account. To list image repositories, use the [SHOW IMAGE REPOSITORIES](/sql-reference/sql/show-image-repositories) command instead.
