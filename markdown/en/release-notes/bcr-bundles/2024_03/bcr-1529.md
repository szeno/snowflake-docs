# SHOW OBJECTS command: New column and changes to output

Attention

This behavior change is in the 2024\_03 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_03_bundle#label-behavior-change-bundle-2024-03-status).

The [SHOW OBJECTS](/sql-reference/sql/show-objects) output behaves as follows:

Before the change:
:   The output of SHOW OBJECTS does not include the `is_dynamic` column, and the `kind`
    column returns DYNAMIC\_TABLE for dynamic tables.

After the change:
:   The output of SHOW OBJECTS includes the `is_dynamic` column, which is defined as follows:

    | Column Name | `is_dynamic` |
    | --- | --- |
    | Data Type | Text |
    | Description | Y if the table is a dynamic table; otherwise, N. |

    Show lessSee more

    The `kind` column in the output of SHOW OBJECTS displays TABLE for dynamic tables.
