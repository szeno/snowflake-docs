# SHOW TABLES command: New column `is_dynamic`

Attention

This behavior change is in the 2024\_03 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_03_bundle#label-behavior-change-bundle-2024-03-status).

The output of the [SHOW TABLES](/sql-reference/sql/show-tables) command, when displaying Dynamic tables, behaves as follows:

Before the change:
:   The output of SHOW TABLES does not include dynamic table rows and the `is_dynamic` column.

After the change:
:   The output of SHOW TABLES includes dynamic table rows and the `is_dynamic` column, defined
    as follows:

    | Column Name | `is_dynamic` |
    | --- | --- |
    | Data Type | Text |
    | Description | Y if the table is a dynamic table; otherwise, N. |

    Expand

    Show lessSee more

    The `kind` column in the output of SHOW TABLES displays TABLE for dynamic tables.
