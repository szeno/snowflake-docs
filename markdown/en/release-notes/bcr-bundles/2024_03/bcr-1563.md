# SHOW ENDPOINTS command: Output column name change

Attention

This behavior change is in the 2024\_03 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_03_bundle#label-behavior-change-bundle-2024-03-status).

The [SHOW ENDPOINTS](/sql-reference/sql/show-endpoints) command output behaves as follows:

Before the change:
:   Output includes the column `ingress_enabled`.

After the change:
:   Output includes the column `is_public`, which was previously named `ingress_enabled`.

Ref: 1563
