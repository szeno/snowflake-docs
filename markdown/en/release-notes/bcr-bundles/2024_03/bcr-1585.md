# QUERY\_ACCELERATION\_ELIGIBLE View (ACCOUNT\_USAGE): Changes to columns

Attention

This behavior change is temporarily unavailable in the 2024\_03 behavior change bundle.

Attention

This behavior change is in the 2024\_03 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_03_bundle#label-behavior-change-bundle-2024-03-status).

Prior to the 2024\_02 bundle, the Query Acceleration Service (QAS) only supported eligible INSERT statements that contained SELECT statements.
This change aligns the rows in the QUERY\_ACCELERATION\_ELIGIBLE view with the expanded INSERT support improvements for QAS. For more
information, see [Query Acceleration Service: Expanded support for INSERT statements](/release-notes/bcr-bundles/2024_02/bcr-1487)

The Account Usage [QUERY\_ACCELERATION\_ELIGIBLE view](/sql-reference/account-usage/query_acceleration_eligible) will change as follows:

Before the change:
:   QUERY\_ACCELERATION\_ELIGIBLE shows all eligible queries.

After the change:
:   QUERY\_ACCELERATION\_ELIGIBLE shows all eligible queries, including newly eligible INSERT statements.
