# Account Usage views: Add support for versioned schemas in Snowflake Native App

Attention

This behavior change is in the 2024\_03 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_03_bundle#label-behavior-change-bundle-2024-03-status).

The output of certain [Account Usage](/sql-reference/account-usage) views, with respect to versioned schemas, behaves as follows.

Before the change:
:   Some Account Usage views may not include additional rows if the schema is a versioned schema:

After the change:
:   The following views can include additional rows if the schema is a versioned schema:

    - [COMPLETE\_TASK\_GRAPHS view](/sql-reference/account-usage/complete_task_graphs)
    - [FUNCTIONS view](/sql-reference/account-usage/functions)
    - [TABLES view](/sql-reference/account-usage/tables)
    - [COLUMNS view](/sql-reference/account-usage/columns)
    - [TABLE\_STORAGE\_METRICS view](/sql-reference/account-usage/table_storage_metrics)
    - [TASK\_HISTORY view](/sql-reference/account-usage/task_history)
    - [OBJECT\_DEPENDENCIES view](/sql-reference/account-usage/object_dependencies)
    - [POLICY\_REFERENCES view](/sql-reference/account-usage/policy_references)

Note

This behavior change is a follow-up to the following behavior changes:

- [BCR-1544: Add support for versioned schemas in Snowflake Native Apps](/release-notes/bcr-bundles/2024_02/bcr-1544).
- [BCR-1463: Add support for versioned schemas in Snowflake Native Apps](/release-notes/bcr-bundles/2024_01/bcr-1463)
