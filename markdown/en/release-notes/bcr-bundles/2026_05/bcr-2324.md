# Listings: Change to resharing defaults (Pending)

Attention

This behavior change is in the 2026\_05 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_05_bundle#label-behavior-change-bundle-2026-05-status).

When this behavior change bundle is enabled, listings are enabled for
[resharing](/collaboration/resharing-as-provider) within the consumer’s organization
by default, unless resharing is explicitly disabled on the listing.

Before the change:
:   Resharing of a listing was disabled by default. Providers had to set `resharing.enabled` to `true` in the listing manifest to allow consumers to reshare.

After the change:
:   Listings are enabled for resharing within the consumer’s organization by default.
    The effective resharing configuration becomes:

    Copy code

    ```
    resharing:
      enabled: true
      only_within_organization: true
    ```

    To alter the default configuration, see the
    [`resharing` field](/progaccess/listing-manifest-reference#label-listing-api-manifest-resharing)
    in the listing manifest reference.
