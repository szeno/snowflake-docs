# SHOW TAGS command and TAGS view (Account Usage): New columns in output

Attention

This behavior change is in the 2026\_03 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_03_bundle#label-behavior-change-bundle-2026-03-status).

When this behavior change bundle is enabled, the output of the [SHOW TAGS](/sql-reference/sql/show-tags) command and the
[TAGS](/sql-reference/account-usage/tags) view in the [ACCOUNT\_USAGE](/sql-reference/account-usage) schema include new columns as described below.

## SHOW TAGS command

The output includes the following new columns:

| Column name | Data type | Description |
| --- | --- | --- |
| `ON_CONFLICT` | VARCHAR | When tag propagation is enabled for the tag, shows the configured `ON_CONFLICT` behavior for the tag. |
| `MULTI_VALUE` | BOOLEAN | Indicates whether the tag accepts multiple values at the time of association to an object. This property is reserved for a future capability; the column is present as a placeholder until that functionality is available. |
