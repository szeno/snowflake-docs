# TASK\_HISTORY views: New column in output

Attention

This behavior change is in the 2026\_02 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_02_bundle#label-behavior-change-bundle-2026-02-status).

When this behavior change bundle is enabled, the following TASK\_HISTORY views and table function
include a new column:

- [INFORMATION\_SCHEMA](/sql-reference/info-schema) table function:

  - [TASK\_HISTORY](/sql-reference/functions/task_history)
- [ACCOUNT\_USAGE](/sql-reference/account-usage) view:

  - [TASK\_HISTORY](/sql-reference/account-usage/task_history)
- [ORGANIZATION\_USAGE](/sql-reference/organization-usage) view:

  - [TASK\_HISTORY](/sql-reference/organization-usage/task_history)

| Column name | Data type | Description |
| --- | --- | --- |
| SPCS\_JOB\_ID | NUMBER | The identifier of the Snowpark Container Services job service that the task spawned in its root query, or NULL if the task’s root query did not spawn any job service. The identifier corresponds to the SERVICE\_ID column in [ACCOUNT\_USAGE.SERVICES](/sql-reference/account-usage/services). |
