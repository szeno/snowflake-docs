# USERS view (Account Usage / Organization Usage): New column

Attention

This behavior change is in the 2026\_02 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_02_bundle#label-behavior-change-bundle-2026-02-status).

When this behavior change bundle is enabled, the [ACCOUNT\_USAGE](/sql-reference/account-usage).[USERS](/sql-reference/account-usage/users) and [ORGANIZATION\_USAGE](/sql-reference/organization-usage).[USERS](/sql-reference/organization-usage/users) views include the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| `PROVISIONED_BY` | VARCHAR | Whether or not this user was provisioned by SCIM. Possible values:   - `SCIM`: The user was provisioned by SCIM. - `NULL`: The user was provisioned using another method, such as SQL or Snowsight. |
