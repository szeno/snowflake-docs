# DESCRIBE LISTING and DESCRIBE AVAILABLE LISTING commands: New column in output

Attention

This behavior change is in the 2026\_02 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_02_bundle#label-behavior-change-bundle-2026-02-status).

When this behavior change bundle is enabled, the output of the [DESCRIBE LISTING](/sql-reference/sql/desc-listing) and [DESCRIBE AVAILABLE LISTING](/sql-reference/sql/desc-available-listing) commands include the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| `resharing` | VARCHAR | This column indicates whether providers and consumers can reshare a listing. The output is one of:   - `{"enabled": true}` - `{"enabled": false}` |
