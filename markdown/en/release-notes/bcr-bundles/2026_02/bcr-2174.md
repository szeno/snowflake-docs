# SHOW ACCOUNTS command: New column tenant\_type in output

Attention

This behavior change is in the 2026\_02 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_02_bundle#label-behavior-change-bundle-2026-02-status).

When this behavior change bundle is enabled, the output of the [SHOW ACCOUNTS](/sql-reference/sql/show-accounts) command includes the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| `tenant_type` | VARCHAR | `INTERNAL`, `EXTERNAL`, or `NULL` (if unset). The GLOBALORGADMIN role in the [organization account](/user-guide/organization-accounts) or ORGADMIN role can set `tenant_type`. |
