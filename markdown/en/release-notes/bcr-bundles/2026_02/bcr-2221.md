# Fast listing auto-fulfillment enabled by default

Attention

This behavior change is in the 2026\_02 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_02_bundle#label-behavior-change-bundle-2026-02-status).

This behavior change applies to the [listing auto-fulfillment](/collaboration/provider-listings-auto-fulfillment)
setting for all existing and new application packages.

Listing auto-fulfillment behaves as follows:

Before the change:
:   `LISTING_AUTO_REFRESH` is not enabled by default. For more information, see [ALTER APPLICATION PACKAGE](/sql-reference/sql/alter-application-package).

After the change:
:   `LISTING_AUTO_REFRESH` is enabled by default.

Ref: 2221
