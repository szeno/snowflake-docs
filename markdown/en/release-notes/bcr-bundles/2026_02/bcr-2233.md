# DBT\_PROJECT\_EXECUTION\_HISTORY function: New columns in output

Attention

This behavior change is in the 2026\_02 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_02_bundle#label-behavior-change-bundle-2026-02-status).

When this behavior change bundle is enabled, the output of the [DBT\_PROJECT\_EXECUTION\_HISTORY](/sql-reference/functions/dbt_project_execution_history) table function
in the [Snowflake Information Schema](/sql-reference/info-schema) includes the following new columns:

| Column name | Data type | Description |
| --- | --- | --- |
| DBT\_VERSION | INTEGER | The DBT project version. |
| DBT\_SNOWFLAKE\_VERSION | INTEGER | The Snowflake dbt project version. |
