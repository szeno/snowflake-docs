# SHOW TASKS and DESCRIBE TASK commands: New column in output

Attention

This behavior change is in the 2026\_02 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_02_bundle#label-behavior-change-bundle-2026-02-status).

When this behavior change bundle is enabled, the output of the [SHOW TASKS](/sql-reference/sql/show-tasks) and
[DESCRIBE TASK](/sql-reference/sql/desc-task) commands includes the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| OVERLAP\_POLICY | VARCHAR | The overlap policy for the task. |
