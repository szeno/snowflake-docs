# SHOW CONTACTS command and CONTACTS view (Account Usage): New column in output

Attention

This behavior change is in the 2026\_02 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_02_bundle#label-behavior-change-bundle-2026-02-status).

When this behavior change bundle is enabled, the output of the [SHOW CONTACTS](/sql-reference/sql/show-contacts) command and the
[CONTACTS](/sql-reference/account-usage/contacts) [Account Usage](/sql-reference/account-usage) view include the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| EMAIL\_LIST | ARRAY | List of email addresses. |
