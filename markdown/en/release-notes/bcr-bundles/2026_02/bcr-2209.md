# LOGIN\_HISTORY view (Account Usage, Organization Usage): New column in output

Attention

This behavior change is in the 2026\_02 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_02_bundle#label-behavior-change-bundle-2026-02-status).

When this behavior change bundle is enabled, the LOGIN\_HISTORY views in the [Account Usage](/sql-reference/account-usage) and
[Organization Usage](/sql-reference/organization-usage) schemas include the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| AUTHORIZING\_INTEGRATION\_NAME | VARCHAR | Name of the integration that allowed the user to authenticate.  For user-defined security integrations like OAuth or SAML2, displays the user-specified name of the integration. For internal Snowflake integrations, displays the type of integration. |

The new column appears after the CLIENT\_IP column.
