# Task views, functions, and commands: New columns in output

Attention

This behavior change is in the 2026\_02 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_02_bundle#label-behavior-change-bundle-2026-02-status).

When this behavior change bundle is enabled, the following tasks related commands, views, and functions include new columns.

## SHOW TASKS and DESCRIBE TASK commands: New column

When this behavior change bundle is enabled, the output of the [SHOW TASKS](/sql-reference/sql/show-tasks) and
[DESCRIBE TASK](/sql-reference/sql/desc-task) commands includes the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| CREATED\_BY\_USER | VARCHAR | The name of the user who created the task. |

Note

- This column is populated for new tasks only and is not backfilled for existing tasks.
- For normal tasks, this is the user who directly created the task. For tasks created within other tasks
  or Snowpark Container Services (SPCS) that execute with system accounts, the behavior differs: for nested tasks, this is the
  user who created the outermost task; for SPCS-based jobs, this is the user who created the SPCS
  service or job.

## Task history and task graph views and functions: New column

When this behavior change bundle is enabled, the following views and functions include a new column:

- Account Usage views:

  - [TASK\_HISTORY](/sql-reference/account-usage/task_history)
  - [COMPLETE\_TASK\_GRAPHS](/sql-reference/account-usage/complete_task_graphs)
- Information Schema table functions:

  - [TASK\_HISTORY](/sql-reference/functions/task_history)
  - [CURRENT\_TASK\_GRAPHS](/sql-reference/functions/current_task_graphs)
  - [COMPLETE\_TASK\_GRAPHS](/sql-reference/functions/complete_task_graphs)

| Column name | Data type | Description |
| --- | --- | --- |
| SCHEDULED\_BY\_USER | VARCHAR | The name of the user triggering the task to run. |
