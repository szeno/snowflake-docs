# INFORMATION\_SCHEMA.DYNAMIC\_TABLES() table function: New column in output (Pending)

Attention

This behavior change is in the 2026\_06 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_06_bundle#label-behavior-change-bundle-2026-06-status).

When this behavior change bundle is enabled, the output of the [INFORMATION\_SCHEMA.DYNAMIC\_TABLES()](/sql-reference/functions/dynamic_tables) table function includes the following new column:

| Column name | Data type | Description |
| --- | --- | --- |
| RECOMMENDATIONS | OBJECT | Actionable, automated insights on how to optimize the performance, cost, or configuration of the dynamic table. |
