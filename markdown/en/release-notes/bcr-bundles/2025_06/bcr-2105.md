# USERS view: New column `is_from_organization_user`

Attention

This behavior change is in the 2025\_06 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_06_bundle#label-behavior-change-bundle-2025-06-status).

When this behavior change bundle is enabled, the USERS view in the [ACCOUNT\_USAGE](/sql-reference/account-usage) and [ORGANIZATION\_USAGE](/sql-reference/organization-usage) schemas includes the following new
column:

| Column name | Data type | Description |
| --- | --- | --- |
| `is_from_organization_user` | BOOLEAN | If TRUE, the user was imported from an [organization user](/user-guide/organization-users). |
