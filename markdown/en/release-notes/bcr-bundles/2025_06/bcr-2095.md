# SHOW ROLES command: New column in output

Attention

This behavior change is in the 2025\_06 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2025_06_bundle#label-behavior-change-bundle-2025-06-status).

When this behavior change bundle is enabled, the output of the [SHOW ROLES](/sql-reference/sql/show-roles) command and the SHOW TERSE ROLES command includes the following
new column:

| Column name | Data type | Description |
| --- | --- | --- |
| `is_from_organization_user_group` | BOOLEAN | If TRUE, the role was imported from an [organization user group](/user-guide/organization-users#label-org-users-groups). |
