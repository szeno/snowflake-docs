# DESCRIBE ICEBERG TABLE command: SOURCE ICEBERG TYPE column value change

Attention

This behavior change is in the 2024\_05 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2024_05_bundle#label-behavior-change-bundle-2024-05-status).

The [DESCRIBE ICEBERG TABLE](/sql-reference/sql/desc-iceberg-table) command returns the following in the SOURCE ICEBERG TYPE column:

Before the change:
:   For some table columns, the command output displays the Snowflake data type or NULL instead of the expected Iceberg data type.

After the change:
:   For all table columns, the command output contains the source Iceberg data type.

Ref: 1638
