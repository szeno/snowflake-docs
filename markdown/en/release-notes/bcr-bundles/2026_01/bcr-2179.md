# ACCESS\_HISTORY view (Account Usage and Organization Usage): Simpler format for values

Attention

This behavior change is in the 2026\_01 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_01_bundle#label-behavior-change-bundle-2026-01-status).

The format of values in the ACCOUNT\_USAGE.ACCESS\_HISTORY and
ORGANIZATION\_USAGE.ACCESS\_HISTORY views behaves as follows:

Before the change:
:   A value is specified as a JSON object with a `value` key. For example:

    Copy code

    ```
    {
      "columns": [
        {
          "objectName": "A",
          "objectId": {
            "value": 2
          },
          "subOperationType": "ADD"
        },
        {
          "objectName": "B",
          "objectId": {
            "value": 3
          },
          "subOperationType": "ADD"
        }
      ]
    }
    ```

After the change:
:   A key-value pair shows the value as a string, number, or Boolean directly. The `value` key is no longer needed. For example:

    Copy code

    ```
    {
      "columns": [
        {
          "objectName": "A",
          "objectId": 2,
          "subOperationType": "ADD"
        },
        {
          "objectName": "B",
          "objectId": 3,
          "subOperationType": "ADD"
        }
      ]
    }
    ```

This change simplifies the record structure and improves readability.

Ref: 2179
