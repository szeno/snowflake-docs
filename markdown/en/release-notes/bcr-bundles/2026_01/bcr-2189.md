# DATA\_CLASSIFICATION\_LATEST view (ACCOUNT\_USAGE): New columns

Attention

This behavior change is in the 2026\_01 bundle.

For the current status of the bundle, refer to [Bundle history](/release-notes/bcr-bundles/2026_01_bundle#label-behavior-change-bundle-2026-01-status).

When this behavior change bundle is enabled,
the [DATA\_CLASSIFICATION\_LATEST](/sql-reference/account-usage/data_classification_latest) view
in the [ACCOUNT\_USAGE](/sql-reference/account-usage) schema includes the
following new columns:

| Column name | Data type | Description |
| --- | --- | --- |
| `last_classification_attempt` | TIMESTAMP\_LTZ | Timestamp of the last sensitive data classification attempt. If greater than `last_classified_on`, the last attempt resulted in a failure. |
| `error_message` | VARCHAR | Error message from the last sensitive data classification attempt, if it resulted in a failure. |
