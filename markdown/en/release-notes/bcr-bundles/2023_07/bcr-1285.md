# DESC SHARE command: Specify “DATABASE ROLE” in the KIND column

Attention

This behavior change is in the 2023\_07 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_07_bundle#label-behavior-change-bundle-2023-07-status).

The [DESCRIBE SHARE](/sql-reference/sql/desc-share) command behaves as follows:

Before the change:
:   When a database role is granted to a share and you run a DESC SHARE command on the share, the KIND column specifies `ROLE` for the
    database role.

After the change:
:   When a database role is granted to a share and you run a DESC SHARE command on the share, the KIND column specifies `DATABASE ROLE` for
    the database role.

Ref: 1285
