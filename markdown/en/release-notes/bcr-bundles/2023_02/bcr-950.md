# REPLICATION\_GROUPS View (Information Schema): New Column in View

Attention

This behavior change is in the 2023\_02 bundle.

For the current status of the bundle, refer to [Bundle History](/release-notes/bcr-bundles/2023_02_bundle#label-behavior-change-bundle-2023-02-status).

The Information Schema [REPLICATION\_GROUPS](/sql-reference/info-schema/replication_groups) view now includes a REGION\_GROUP column:

| Column Name | Data Type | Description |
| --- | --- | --- |
| REGION\_GROUP | TEXT | Region group where the account that stores the replication or failover group is located. |

To maintain consistency with the Information Schema [REPLICATION\_DATABASES](/sql-reference/info-schema/replication_databases) view,
this column has been added as the first (leftmost) column of the view.
