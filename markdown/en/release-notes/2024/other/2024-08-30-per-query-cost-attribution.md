# August 30, 2024 — Query attribution costs

## Account Usage: New QUERY\_ATTRIBUTION\_HISTORY view

The new QUERY\_ATTRIBUTION\_HISTORY view in the ACCOUNT\_USAGE schema provides information about the warehouse cost for queries and
enables the attribution of query costs by tag, user, or query hash.

For more information, see [Viewing cost by tag in SQL](/user-guide/cost-attributing#label-cost-attribute-tag-sql) and
[QUERY\_ATTRIBUTION\_HISTORY](/sql-reference/account-usage/query_attribution_history) view.
