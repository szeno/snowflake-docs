# July 19, 2024 — CORTEX\_FUNCTIONS\_USAGE\_HISTORY view — *General Availability*

With this release, we are pleased to announce the general availability of the CORTEX\_FUNCTIONS\_USAGE\_HISTORY view in the
Account Usage schema, giving
you the ability to query the usage history for the [Cortex AI Large Language Model (LLM) Functions](/user-guide/snowflake-cortex/aisql).

This new view allows
you to track usage for all Cortex AI LLM Functions, individual models like `mistral-large` or `Llama3-70b` used in the
COMPLETE function, and task-specific functions like TRANSLATE or SUMMARIZE.

For more information, see [CORTEX\_FUNCTIONS\_USAGE\_HISTORY view](/sql-reference/account-usage/cortex_functions_usage_history).
