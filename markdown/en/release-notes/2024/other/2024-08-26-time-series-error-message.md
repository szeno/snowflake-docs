# August 26, 2024 — Time Series ML Functions — Error Message Improvements

We are pleased to announce improved error messages for the [Forecasting](/user-guide/ml-functions/forecasting) and
[Anomaly Detection](/user-guide/ml-functions/anomaly-detection) ML Functions. These error messages previously
included internal debug traces that were not relevant to end users. Error messages from these functions now contain only
actionable information.
