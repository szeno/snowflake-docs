# March 08, 2024 — Geospatial Functions Release Notes

## New Geospatial Functions Available

Two new functions for [GEOMETRY](/sql-reference/data-types-geospatial#label-data-types-geometry) objects are now available:

- [ST\_GEOMFROMGEOHASH](/sql-reference/functions/st_geomfromgeohash) - Returns a GEOMETRY object for the polygon that represents
  the boundaries of a [geohash](https://en.wikipedia.org/wiki/Geohash).
- [ST\_GEOMPOINTFROMGEOHASH](/sql-reference/functions/st_geompointfromgeohash) - Returns a GEOMETRY object for the point that
  represents center of a [geohash](https://en.wikipedia.org/wiki/Geohash).
