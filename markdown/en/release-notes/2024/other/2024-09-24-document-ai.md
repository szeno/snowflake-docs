# September 24, 2024 — DOCUMENT\_AI\_USAGE\_HISTORY view — *General Availability*

With this release, we are pleased to announce the general availability of the DOCUMENT\_AI\_USAGE\_HISTORY view in the
Account Usage schema, giving
you the ability to query the usage history for Document AI.

For more information, see [DOCUMENT\_AI\_USAGE\_HISTORY view](/sql-reference/account-usage/document_ai_usage_history).
