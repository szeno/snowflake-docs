# June 28, 2024 — New geospatial H3 functions — *General Availability*

H3 is a [hierarchical geospatial index](https://h3geo.org/docs/highlights/indexing) that partitions
the world into hexagonal cells in a [discrete global grid system](https://en.wikipedia.org/wiki/Discrete_global_grid).

The following H3 functions are now generally available:

- [H3\_COMPACT\_CELLS](/sql-reference/functions/h3_compact_cells)
- [H3\_COMPACT\_CELLS\_STRINGS](/sql-reference/functions/h3_compact_cells_strings)
- [H3\_IS\_PENTAGON](/sql-reference/functions/h3_is_pentagon)
- [H3\_IS\_VALID\_CELL](/sql-reference/functions/h3_is_valid_cell)
- [H3\_TRY\_COVERAGE](/sql-reference/functions/h3_try_coverage)
- [H3\_TRY\_COVERAGE\_STRINGS](/sql-reference/functions/h3_try_coverage_strings)
- [H3\_TRY\_GRID\_DISTANCE](/sql-reference/functions/h3_try_grid_distance)
- [H3\_TRY\_GRID\_PATH](/sql-reference/functions/h3_try_grid_path)
- [H3\_TRY\_POLYGON\_TO\_CELLS](/sql-reference/functions/h3_try_polygon_to_cells)
- [H3\_TRY\_POLYGON\_TO\_CELLS\_STRINGS](/sql-reference/functions/h3_try_polygon_to_cells_strings)
- [H3\_UNCOMPACT\_CELLS](/sql-reference/functions/h3_uncompact_cells)
- [H3\_UNCOMPACT\_CELLS\_STRINGS](/sql-reference/functions/h3_uncompact_cells_strings)

For more information, see [Geospatial data types](/sql-reference/data-types-geospatial) and
[Geospatial functions](/sql-reference/functions-geospatial).
