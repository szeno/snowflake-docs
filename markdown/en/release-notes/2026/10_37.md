# 10.37 Release Notes (with behavior changes) (Preview)

Attention

Content on this page is available in advance of the completion of the 10.37 release, which began on
October 8, 2026 and is currently *in progress*. The release is scheduled for completion on October 13,
2026 (subject to change).

Features, updates, or behavior changes described on this page might not be available in your accounts
until the release is complete.

For updates to these release notes, see [Release notes change log](#label-rel-notes-change-log-10-37).

## Behavior change bundles

This release contains the following behavior change bundles:

| Bundle name | Status in this release | Previous status |
| --- | --- | --- |
| [2026\_08](/release-notes/bcr-bundles/2026_08_bundle) | Disabled by default; admins can enable for testing | N/A (introduced in this release) |
| [2026\_07](/release-notes/bcr-bundles/2026_07_bundle) | Enabled by default; admins can disable for opt-out | Disabled by default |
| [2026\_06](/release-notes/bcr-bundles/2026_06_bundle) | Generally enabled; admins can no longer enable/disable | Enabled by default |
