# 10.22 Release Notes: June 20, 2026-June 25, 2026

This release has completed. For differences between the in-advance and final versions of these release

## New features

### Dynamic Tables supported on Delta Direct tables (*General availability*)

Dynamic Tables are now supported on Delta Direct tables. For more information, see [Supported queries for dynamic tables](/user-guide/dynamic-tables/supported-queries).

### Insert-only streams supported on Delta Direct tables (*General availability*)

Insert-only streams are now supported on Delta Direct tables. For more information, see [Introduction to streams](/user-guide/streams-intro).
