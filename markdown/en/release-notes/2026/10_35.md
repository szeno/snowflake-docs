## Account Usage updates

### New ACCOUNT\_USAGE.STREAMS view

The ACCOUNT\_USAGE schema now includes a new STREAMS view. The view displays a row for each stream in your account, including columns for the source object, base tables, mode, staleness, and other properties.

For more information, see [STREAMS view](/sql-reference/account-usage/streams).
