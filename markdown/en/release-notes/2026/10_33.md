## New features

### Dynamic Tables Insights

**Dynamic Tables Insights** is now generally available (GA). Dynamic Tables Insights proactively analyzes your dynamic table definitions and refresh execution metrics to surface actionable performance insights in Snowsight. When Snowflake detects a structural anti-pattern or a runtime condition that increases refresh latency or compute cost, it creates an insight for that table.

You can view insights from two places:

- **Snowsight**: Filter the Dynamic Tables list page by **Insights** to see all the dynamic tables across your account that have active recommendations.
- **Individual Dynamic Tables**: Open a dynamic table’s details or Overview page to view the **Insights** panel alongside refresh metrics.

The best way to understand, analyze, and proceed with these insights is to use the **Analyze with CoCo** button, which opens a CoCo session that explains the detected issue and generates ready-to-use DDL to apply the fix.

For a reference of all insight codes and recommended fixes, see [Dynamic Tables Insights](/user-guide/dynamic-tables/insights).
