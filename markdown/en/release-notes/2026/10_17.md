## Data integration updates

### Openflow BYOC: per-runtime cost attribution in Account Usage views

Openflow BYOC credit consumption is now attributable to individual runtimes. Two changes support this:

- The [OPENFLOW\_USAGE\_HISTORY view](/sql-reference/account-usage/openflow_usage_history) in the ACCOUNT\_USAGE schema now
  includes a `RUNTIME_NAME` column with the name of the runtime that incurred the credit usage.
- The [METERING\_HISTORY view](/sql-reference/account-usage/metering_history) in the ACCOUNT\_USAGE schema now populates
  `ENTITY_TYPE` and `NAME` for rows where `SERVICE_TYPE = 'OPENFLOW_COMPUTE_BYOC'`. `ENTITY_TYPE` returns
  `OPENFLOW_RUNTIME` for these rows, and `NAME` returns the runtime name. Previously, both columns returned NULL for all
  Openflow service types.
