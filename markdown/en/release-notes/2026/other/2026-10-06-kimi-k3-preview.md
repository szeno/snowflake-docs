# Oct 06, 2026: Kimi K3 model (*Preview*)

The `kimi-k3` model is now available in Public Preview in AI Functions and the Cortex REST API.

The model supports cross-region inference with `CORTEX_ENABLED_CROSS_REGION` set to `AWS_GLOBAL` or `ANY_REGION`.

For more information, see [Models and regional availability for Cortex AI Functions](/user-guide/snowflake-cortex/aisql-regional-availability) and
[Model availability](/user-guide/snowflake-cortex/cortex-rest-api#label-cortex-complete-llm-model-availability).
