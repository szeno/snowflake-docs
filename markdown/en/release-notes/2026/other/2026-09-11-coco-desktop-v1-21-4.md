# Sep 11, 2026: CoCo Desktop v1.21.4

CoCo Desktop v1.21.4 is a polish and reliability release on top of v1.21.3:

- **Windows installer matches macOS**: The Windows installer no longer shows a License Agreement
  click-through page.
- **Add highlighted conversation text to chat**: Select text in a conversation and use the
  **Add to Chat** pill or **⌘L** / **Ctrl+L** to attach it to your next message.
- **Cancel a pending steering message**: Remove an armed steering message without stopping the
  active turn.
- **dbt runs stay focused on Output**: After a Project Action Bar Run or Build, you remain on the
  Current Project Output panel.

This release also fixes a bug where a fresh Gemini session could fail with a `400` error because
the model’s thought signature was dropped between turns.

For more information, see [Cortex Code Desktop v1.21.4 release notes](/user-guide/cortex-code/cortex-code-desktop/release-notes/v1-21-4).
