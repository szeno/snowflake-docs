# Nov 5, 2026: CoCo Desktop v1.25.0

CoCo Desktop v1.25.0 makes dbt work faster and steadier:

- **Anchored dbt lineage**: The **Lineage** panel shows the whole active dbt project, or the neighborhood of a node that you anchor, instead of following the active editor.
- **Faster dbt Action Bar**: The Project Action Bar appears without waiting for every project’s manifest to load.
- **One timeout for dbt runs**: Local and Snowflake-managed dbt runs share the `dbt.executionTimeout` setting, which defaults to four hours. Local runs previously stopped after five minutes.
- **Fewer approvals**: Tools no longer ask you to approve their result after they have already run.
- **Update status in the app menu**: **Check for Updates** shows the state of the update, and CoCo Desktop checks for updates every four hours.
- **Windows updates**: An interrupted update no longer leaves CoCo Desktop unable to start.

For more information, see [CoCo Desktop v1.25.0 release notes](/user-guide/cortex-code/cortex-code-desktop/release-notes/v1-25-0).
