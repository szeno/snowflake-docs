# Jul 27, 2026: AI\_EXTRACT and AI\_PARSE\_DOCUMENT now available in GCP Middle East Central2 (Dammam)

AI\_EXTRACT and AI\_PARSE\_DOCUMENT are now available in the Google Cloud Platform Middle East Central2 (Dammam) region,
expanding regional support for customers with in-region requirements for document processing workloads.

This addition enables customers in the Dammam region to use these Cortex AI Functions for document extraction and
parsing capabilities without requiring cross-region inference.

For the full list of supported regions and more information, see the following topics:

- [AI\_EXTRACT regional availability](/sql-reference/functions/ai_extract#regional-availability)
- [AI\_PARSE\_DOCUMENT regional availability](/user-guide/snowflake-cortex/parse-document#label-parse-document-regional-availability)
