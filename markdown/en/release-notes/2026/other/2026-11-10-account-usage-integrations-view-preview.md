# Nov 10, 2026: INTEGRATIONS view in ACCOUNT\_USAGE (*Preview*)

With this preview release, the `ACCOUNT_USAGE` schema includes a new `INTEGRATIONS` view that returns a row for each integration in your
account. The view includes metadata for API, catalog, external access, notification, security, and storage integrations, such as the
integration type, category, enabled status, owner, lifecycle timestamps, and allowed or blocked locations and network rules.

For more information, see [ACCOUNT\_USAGE.INTEGRATIONS](/sql-reference/account-usage/integrations).
