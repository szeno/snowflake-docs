# Nov 19, 2026: Snowflake Data Clean Rooms updates

Enabling updates

- **Clean room UI users:** New updates are applied to the UI automatically when a user starts a new session after a new update is deployed. To ensure new updates are applied, make sure to log out and log back into the UI.
- **Clean room API users:** API updates are applied either manually or automatically to an account. [Learn how to manage updates for Data Clean Rooms.](/user-guide/cleanrooms/managing-updates)

  You can find your API environment version number by running the following SQL command:

  Copy code

  ```
  SELECT * FROM SAMOOHA_BY_SNOWFLAKE_LOCAL_DB.ADMIN.VERSION;
  ```

## Clean Rooms API Version: 19.5

The following updates are now available in Snowflake Data Clean Rooms:

- **Stricter validation for free-form SQL policies:** The
  [`freeform_sql_policies`](/user-guide/cleanrooms/spec-data-offering#label-dcr-freeform-sql-policies-field) section of a
  data offering specification must now name at least one policy. Previously, a section that named no policy could
  satisfy the `require_freeform_sql_policy` check without attaching any policy to the data. Specifications with a
  `freeform_sql_policies` section that doesn’t name a policy are now rejected with a validation error, so you can
  correct the specification before the data offering is shared.
- Security enhancements, including hardened input handling and updated third-party libraries.
- General performance improvements and bug fixes.
- Updates to private preview features.
