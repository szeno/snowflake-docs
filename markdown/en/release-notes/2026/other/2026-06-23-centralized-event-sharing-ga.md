# Jun 23, 2026: Centralized event sharing for Snowflake Native Apps (*General availability*)

Centralized event sharing for Snowflake Native Apps is now generally available. Providers can use event routing
tables to route application telemetry from multiple regions to centralized destination accounts.

For more information, see [Configure centralized event sharing for an app](/developer-guide/native-apps/event-central)
and [SYSTEM$MIGRATE\_LEGACY\_EVENT\_ROUTING\_CONFIGURATION](/sql-reference/functions/system_migrate_legacy_event_routing_configuration).
