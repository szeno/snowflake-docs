# Oct 22, 2026: Pipeline Builder (*Preview*)

Pipeline Builder is now available in public preview. Pipeline Builder is a visual designer in Workspaces for orchestrating Snowflake
Notebooks, Python files, ML Jobs, and SQL as task graphs. Each pipeline is a DCM project, so you can plan every change before you deploy
it and keep the pipeline in Git.

Key capabilities include:

- Drag-and-drop task creation from notebooks, Python files, and `.sql` files, with connections that set the order tasks run in
- Task graphs created automatically when you connect tasks, with a schedule, run policies, and task defaults for the whole graph
- Code Bundles created and managed for you when a task runs code from your project
- A deployment flow that plans the DCM project, shows the planned changes, and deploys them in one step
- Pipeline drafts and edits generated by CoCo (coming soon)

For more information, see [Pipeline Builder](/user-guide/pipeline-builder/pipeline-builder-overview).
