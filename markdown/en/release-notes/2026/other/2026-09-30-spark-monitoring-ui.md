# Sep 30, 2026: Spark Monitoring UI (*Preview*)

With this preview release, you can monitor and troubleshoot Snowpark Connect for Spark batch jobs and sessions in
Snowsight. The Spark Monitoring UI lists `snowpark-submit` and `EXECUTE CODE BUNDLE` runs under **Batch
Jobs**, and Snowpark Connect sessions under **Spark Sessions**.

For more information, see [Spark Monitoring UI](/developer-guide/snowpark-connect/spark-monitoring-ui).

Note

The Spark Monitoring UI is being rolled out slowly, so it might not be available in your account right away.
