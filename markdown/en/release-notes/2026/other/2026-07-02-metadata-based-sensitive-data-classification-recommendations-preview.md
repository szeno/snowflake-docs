# July 2, 2026: Metadata-based sensitive data classification recommendations (*Public Preview*)

Snowflake is rolling out metadata-based sensitive data classification recommendations in Snowsight to help you identify databases that are
likely to contain sensitive data and enable classification with one click.

When Snowflake determines that a database is likely to contain sensitive data, a recommendation appears on the database details page in
Snowsight. You can enable classification for that database from the recommendation banner and review results in Trust Center **Data
Security**.

For more information, see:

- [Sensitive data classification recommendations in Snowsight](/user-guide/classify-ui-trust-center#label-classify-trust-center-sensitive-data-banner)
