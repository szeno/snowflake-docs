# Nov 3, 2026: Access roles for Snowflake Postgres token authentication (*Preview*)

You can use access roles to control which Snowflake roles can generate short-lived tokens to log in as
a specific Postgres user. Enable an access role for the Postgres user, and then grant the corresponding
Postgres access role to Snowflake roles. This feature is in preview.

For more information, see [Grant access with access roles](/user-guide/snowflake-postgres/postgres-authentication#label-sfpg-token-auth-access-roles).
