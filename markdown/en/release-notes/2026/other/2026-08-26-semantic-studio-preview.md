# Aug 26, 2026: Semantic Studio (*Preview*)

Semantic Studio is now available in public preview for all accounts. Semantic Studio is the
authoring environment for semantic views in Workspaces, combining conversational authoring with
CoCo, direct YAML editing, and deployment to the live Snowflake object in a single surface.

Key capabilities include:

- Conversational authoring with CoCo to create, refine, and iterate on semantic views
- Deploy semantic views directly to live Snowflake objects
- Git-backed version control for collaboration and change tracking
- Request-ID debugging to trace an incorrect answer and apply the fix as an inline diff

For more information, see [Semantic Studio](/user-guide/views-semantic/semantic-studio).
