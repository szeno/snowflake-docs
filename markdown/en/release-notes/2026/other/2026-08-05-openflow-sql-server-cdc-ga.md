# Aug 5, 2026: Openflow Connector for SQL Server (CDC) (*General availability*)

The Openflow Connector for SQL Server (CDC) is now generally available. The connector captures every
row-level change from Microsoft SQL Server using Change Data Capture (CDC) and
replicates selected tables into Snowflake in near real-time or on a schedule.
It supports initial snapshot load, incremental sync, and schema evolution.

For more information, see
[About Openflow Connector for SQL Server (CDC)](/user-guide/data-integration/openflow/connectors/sql-server-cdc/about).
