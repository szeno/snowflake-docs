# Sep 8, 2026: CoCo Desktop v1.21.3

CoCo Desktop v1.21.3 isolates the Snowflake session that agent SQL runs in, adds full-text search
across past sessions, and makes the redesigned dbt workspace the standard dbt experience:

- **Isolated Snowflake sessions for agent SQL**: SQL the agent runs uses a separate Snowflake
  session for each chat, so its role, temporary tables, and session variables stay apart from the
  SQL you run yourself. In Plan mode, that session is read-only automatically.
- **Search your past sessions**: Press Cmd/Ctrl+K in Agent Manager to search previous sessions by
  title, project, or conversation text, then reopen a result in its workspace.
- **Choose how much reasoning a response needs**: Set thinking effort from the model picker to favor
  a quicker answer or deeper reasoning, without changing models.
- **The redesigned dbt workspace is now standard**: Run dbt from the Project Action Bar and review
  command output, query results, compiled SQL, and lineage in the main workbench. You can retry
  failed models from **Lineage** and pick a Python interpreter per local project.
- **Hardened PowerShell launching on Windows**: Cortex Code starts PowerShell only from trusted
  system locations, so an untrusted workspace can’t substitute its own executable.
- **Fixed: blank window after a catalog update**: A startup regression could leave Desktop opening
  to an empty workbench.

This release also discovers App Runtime v2 projects that use `app.yml` in the Apps panel, adds a
**New SQL File** action to the empty editor, keeps prompts sent during a tool run in their own
conversation turn, and reduces memory growth from long-running terminals.

For more information, see [Cortex Code Desktop v1.21.3 release notes](/user-guide/cortex-code/cortex-code-desktop/release-notes/v1-21-3).
