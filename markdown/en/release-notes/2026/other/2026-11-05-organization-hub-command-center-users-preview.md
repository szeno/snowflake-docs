# Nov 05, 2026: Organization users and user groups in Organization Command Center (*Preview*)

Organization users and user groups is now available in preview in Organization Command Center.

From the organization account, a user with the GLOBALORGADMIN role can open **Organization Hub** »
**Command center**, then the **Organization users and user groups** tile, to create organization users and organization
user groups, assign users to groups, and make those groups visible to member accounts. The Command Center landing tile
shows how many organization users, organization user groups, and accounts with group visibility you have.

Organization users and organization user groups themselves are generally available through SQL. This preview covers the
Command Center UI for managing them.

This Command Center page requires an [organization account](/user-guide/organization-accounts). Access is limited to the
GLOBALORGADMIN role.

For more information, see [Organization Command Center](/user-guide/organization-hub-command-center) and
[Organization users and user groups](/user-guide/organization-hub-command-center-users).
