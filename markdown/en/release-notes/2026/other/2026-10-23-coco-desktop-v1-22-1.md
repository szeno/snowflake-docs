# Oct 23, 2026: CoCo Desktop v1.22.1

CoCo Desktop v1.22.1 brings Defer to Production to Snowflake-managed dbt runs and makes sessions and apps easier to manage:

- **Defer to Production for Snowflake-managed dbt runs**: The dbt **Run** configuration lets you defer to a production dbt project object and choose which of its runs to compare to.
- **Agent-named chat sessions**: The agent can rename the current chat session, and you confirm each rename.
- **Snowflake object discovery for everyone**: The `snowflake-object-discovery` subagent is now on by default for all users.
- **All your chat sessions are kept**: Older chat sessions are no longer deleted once a project has more than 25.
- **Filter and sort apps**: The **Apps** panel adds **Type** and **Sort** menus.
- **Reliability fixes**: Fixes for SSH windows, file edits that got stuck while applying, **Stop** and queued messages, and large dbt workspaces.

For more information, see [CoCo Desktop v1.22.1 release notes](/user-guide/cortex-code/cortex-code-desktop/release-notes/v1-22-1).
