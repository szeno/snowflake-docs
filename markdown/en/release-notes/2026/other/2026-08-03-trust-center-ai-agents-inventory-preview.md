# Aug 03, 2026: AI Agents Inventory in the Trust Center AI Security tab (*Preview*)

With this preview release, the **AI Security** tab in the Trust Center includes an **AI Agents Inventory** section.
This section provides a consolidated inventory of the Cortex Agents in your account, filtered by one or more
categories, so that you can identify which agents to assess or investigate for better governance and security
posture.

For more information, see
[AI agents inventory](/user-guide/trust-center/using-the-trust-center#label-trust-center-ai-security-ai-agents).
