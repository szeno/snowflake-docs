# Jun 1, 2026: Snowflake storage for Apache Iceberg™ tables (*General availability*)

With this release, Snowflake storage for Apache Iceberg™ tables is now generally available.
This option lets Snowflake store and manage the Iceberg table files for you, so you don’t
need to set up access to external cloud storage.

Snowflake storage supports both permanent (Fail-safe protected) and transient Iceberg tables,
and works with the Snowflake Horizon Catalog so external query engines can access the same
tables. This feature is available in commercial AWS and Azure regions only.

For more information, see [Snowflake storage for Apache Iceberg™ tables](/user-guide/tables-iceberg-internal-storage).
