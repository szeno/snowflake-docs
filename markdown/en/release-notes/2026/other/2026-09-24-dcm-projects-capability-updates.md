# Sep 24, 2026: DCM Projects capability updates

This release updates the availability of several DCM Projects capabilities.

## Generally available capabilities

The following capabilities are now generally available:

- `CREATE OR ALTER PIPE`
- `CREATE OR ALTER STREAM`
- `DEFINE MASKING POLICY`
- `DEFINE PIPE`
- `DEFINE SHARE`
- `DEFINE STREAM`

## Capabilities in preview

The following capabilities are now available in preview:

- Project assets, which import source files declared in the DCM project manifest for use in definitions.
- `DEFINE CODE BUNDLE`, which manages Code Bundles and their source files declaratively.
- `DEFINE STREAMLIT`, which manages Streamlit apps, their infrastructure, and access control declaratively.

For more information, see [Supported object types in DCM Projects](/user-guide/dcm-projects/dcm-projects-supported-entities).
