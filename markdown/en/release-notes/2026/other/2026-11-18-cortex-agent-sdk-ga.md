# Nov 18, 2026: Cortex Agent SDK (*General availability*)

The Cortex Agent SDK is now generally available for Python and TypeScript with version 1.0.0.
Use the SDK to build applications that run Cortex Agents and Cortex Code, stream responses,
maintain conversations and threads, and reconnect to long-running work.

The Python SDK uses the `snowflake.cortex.agents` import namespace. Existing `cortex_agent_sdk`
imports remain available as deprecated aliases. The package names remain `snowflake-cortex-agent-sdk`
for Python and `@snowflake/cortex-agent-sdk` for TypeScript.

For more information, see [Cortex Agent SDK](/user-guide/snowflake-cortex/cortex-agent-sdk/cortex-agent-sdk).
