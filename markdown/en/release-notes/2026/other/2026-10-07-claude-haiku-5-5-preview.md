# Oct 07, 2026: Claude Haiku 5.5 model in the Cortex REST API (*Preview*)

The `claude-haiku-5-5` model is now available in Public Preview in the Cortex REST API.

The model supports cross-region inference with `CORTEX_ENABLED_CROSS_REGION` set to `ANY_REGION`, `AWS_GLOBAL`,
`AWS_US`, `AWS_EU`, `AWS_APJ`, `AWS_JP`, or `AWS_AU`.

For more information, see [Model availability](/user-guide/snowflake-cortex/cortex-rest-api#label-cortex-complete-llm-model-availability).
