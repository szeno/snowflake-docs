# Nov 18, 2026: Retrieve Cortex Search (*General availability*)

Retrieve Cortex Search is now generally available. The `CORTEX_SEARCH_RETRIEVE` table function lets you run low-latency Cortex Search queries directly from SQL, either one query at a time or one query per input row with a `LATERAL` join.

For more information, see [Retrieve Cortex Search](/user-guide/snowflake-cortex/cortex-search/cortex-search-retrieve).
