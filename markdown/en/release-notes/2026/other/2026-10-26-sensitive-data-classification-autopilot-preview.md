# Oct 26, 2026: Autopilot for sensitive data classification (*Public Preview*)

With this preview release, **Autopilot** is available for sensitive data classification. Autopilot lets Snowflake manage
classification timing, reclassification schedules, and minimum object age to optimize performance and cost.

For more information, see [Autopilot](/user-guide/classify-intro#label-classify-autopilot),
[Set up classification with advanced settings](/user-guide/classify-ui-trust-center#label-classify-trust-center-advanced), and
[<classification\_profile\_name>!ENABLE\_AUTO\_SCHEDULING\_MODE](/sql-reference/classes/classification_profile/methods/enable_auto_scheduling_mode).
