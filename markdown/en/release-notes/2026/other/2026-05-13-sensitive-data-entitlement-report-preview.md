# May 13, 2026: Sensitive Data Entitlement report (*Public Preview*)

You can now generate a Sensitive Data Entitlement report to view who can access sensitive data in your account. The report
creates a view that lists users who have access control roles with privileges on tables containing sensitive data.

For more information, see [Sensitive Data Entitlement report](/user-guide/classify-ui-trust-center#label-classify-trust-center-entitlement-report).
