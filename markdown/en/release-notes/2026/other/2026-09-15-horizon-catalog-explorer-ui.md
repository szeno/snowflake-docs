# Sep 15, 2026: Horizon Catalog Explorer UI (*Preview*)

With this release, the Horizon Catalog Explorer is the default experience for browsing Snowflake objects in Snowsight,
replacing Database Explorer. The Horizon Catalog Explorer provides consistent navigation and object detail pages while preserving
the tabs and actions that you already use.

This release includes the following changes:

- **Updated navigation**: Browse databases, schemas, and objects with a persistent navigation tree, breadcrumbs, and redesigned
  search results.
- **Unified object details**: Review descriptions, columns, tags, and contacts in a consistent layout.
- **Refreshed workflows**: Preview data, review access, and inspect copy history without leaving the explorer.

The Horizon Catalog Explorer is available in all Snowflake regions on AWS, Microsoft Azure, and Google Cloud, including government
and China regions. To open it, sign in to Snowsight and select **Catalog** » **Explorer**.

To go back to Database Explorer for the rest of your session, click ⓘ next to **Horizon Catalog**, and then turn off
**Show new catalog UI**.

This release updates the user interface for the previous Database Explorer. The release doesn’t include external metadata
integrations for Horizon Catalog.

For more information, see [Explore and manage database objects in Snowsight](/user-guide/ui-snowsight-data).
