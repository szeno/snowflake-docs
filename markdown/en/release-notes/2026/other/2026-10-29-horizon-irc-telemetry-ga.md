# Oct 29, 2026: Horizon Iceberg REST Catalog telemetry (*General availability*)

With this release, Horizon Iceberg REST Catalog telemetry is generally available. Snowflake can capture the HTTP requests that external query engines make against the Horizon Iceberg REST Catalog APIs and write them to your account event table. Use these events to monitor catalog traffic, troubleshoot integrations with external engines, and correlate catalog activity with access history.

For more information, see [Capture Horizon Iceberg REST Catalog events in the event table](/user-guide/tables-iceberg-access-using-external-query-engine-snowflake-horizon-telemetry).
