# Nov 2, 2026: CoCo automations (*General availability*)

CoCo automations are now generally available and are no longer in
[Preview](/release-notes/preview-features). Automations let you schedule recurring, unattended CoCo
runs that execute in a Snowflake-managed sandbox. Each run creates a Cortex thread that you can open
to inspect the agent’s messages, tool calls, and results.

The feature is available in all commercial regions on AWS, Azure, and Google Cloud. It isn’t
available in government, FedRAMP, DoD, VPS, or China deployments.

For more information, see [CoCo automations in CLI, Snowsight, and Desktop](/user-guide/cortex-code/cortex-code-automations).
