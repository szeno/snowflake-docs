# Oct 13, 2026: CoCo Desktop v1.21.7

CoCo Desktop v1.21.7 lets the agent manage your automations and makes MCP connections easier to control:

- **Manage automations from chat**: The agent can list, create, update, delete, and run local automations, and it asks for confirmation before every change.
- **Redesigned MCP connection controls**: Each MCP server has a single **Connect**/**Disconnect** button, and OAuth MCP servers ask you to sign in far less often.
- **Stop cancels multi-statement SQL runs**: Pressing **Stop** ends the whole run instead of continuing to the next statement.
- **dbt Docs from the editor**: A **View Docs** button on dbt models opens a Docs editor that follows the active model.
- **Reliability fixes**: Fixes for dropped-connection replies, restored sessions, agent SQL context after a token refresh, SSH tunnels, and memory use in long sessions.

For more information, see [Cortex Code Desktop v1.21.7 release notes](/user-guide/cortex-code/cortex-code-desktop/release-notes/v1-21-7).
