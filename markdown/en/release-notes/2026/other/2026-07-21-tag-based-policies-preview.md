# July 21, 2026: Tag-based data protection policies (*Public Preview*)

Tag-based policy support is now available in public preview for aggregation policies, row access policies, projection policies, and join
policies. This feature allows you to assign data protection policies to tags, automatically protecting any objects that have the tag
assigned to them.

For more information, see:

- [Attribute-based access control (ABAC) using tag-based policies](/user-guide/tag-based-policies)
- [Tag-based aggregation policies](/user-guide/tag-based-aggregation-policies)
- [Tag-based row access policies](/user-guide/tag-based-row-access-policies)
- [Tag-based projection policies](/user-guide/tag-based-projection-policies)
- [Tag-based join policies](/user-guide/tag-based-join-policies)
