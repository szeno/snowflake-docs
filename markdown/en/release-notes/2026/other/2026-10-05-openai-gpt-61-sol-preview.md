# Oct 05, 2026: OpenAI GPT-6.1 Sol model (*Preview*)

The `openai-gpt-6.1-sol` model is now available in Public Preview in Cortex AI.

The model supports cross-region inference with `CORTEX_ENABLED_CROSS_REGION` set to `AWS_US`, `AWS_GLOBAL`, or `ANY_REGION`.

For more information, see [Model availability](/user-guide/snowflake-cortex/cortex-rest-api#label-cortex-complete-llm-model-availability).
