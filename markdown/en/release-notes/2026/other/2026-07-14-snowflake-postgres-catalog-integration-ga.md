# Jul 14, 2026: Catalog integration for Snowflake Postgres (*General availability*)

Catalog integrations for Snowflake Postgres are now generally available. A Snowflake Postgres
catalog integration lets Snowflake automatically discover tables managed by a Snowflake Postgres
instance and access them as read-only Apache Iceberg™ tables, using vended credentials so you don’t
need to configure an external volume or manage storage credentials separately. This feature is
currently supported on AWS and Azure.

For more information, see
[Configure a catalog integration for Snowflake Postgres](/user-guide/tables-iceberg-configure-catalog-integration-snowflake-postgres).
