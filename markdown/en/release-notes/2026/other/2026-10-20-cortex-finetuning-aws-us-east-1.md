# Oct 20, 2026: Cortex Fine-tuning: New model training no longer available in AWS US East 1

Starting October 20, 2026, Cortex Fine-tuning will no longer support the creation of new fine-tuned models in AWS US East 1 (N. Virginia).

Existing fine-tuned models will continue to support inference. No changes are required to existing pipelines, schemas, or scheduled tasks.

Cortex Fine-tuning remains available in the following regions:

- AWS US West 2 (Oregon)
- AWS Europe Central 1 (Frankfurt)
- Azure East US 2 (Virginia)

For more information, see [Fine-tuning (Snowflake Cortex)](/user-guide/snowflake-cortex/cortex-finetuning).
