# Nov 23, 2026: Support for multiple tag-based row access policies (*Preview*)

Support for applying multiple tag-based row access policies to the same table or view is now available in preview. By default, the policies
are combined with `AND`. To combine them with `OR`, specify `PERMISSIVE` when you set the policy on the tag.

For more information, see [Combine multiple tag-based row access policies (\*Preview\*)](/user-guide/tag-based-row-access-policies#label-tag-based-rap-multiple).
