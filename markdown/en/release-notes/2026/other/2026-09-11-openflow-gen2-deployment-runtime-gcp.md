# Sep 11, 2026: Second generation Openflow deployments and runtimes now available on GCP

Second generation (gen 2) Openflow **deployment** and **runtime** SQL objects are now available on
Google Cloud Platform (GCP), in addition to AWS and Azure. Previously, gen 2 deployment and runtime
SQL objects were generally available only on AWS and Azure.

Gen 2 **connector** configuration — the setup wizard, SQL/stage-based configuration, and supported
connectors — remains in [Public Preview](/release-notes/preview-features).

For more information, see [Second generation Openflow objects and interfaces](/user-guide/data-integration/openflow/gen2/index).
