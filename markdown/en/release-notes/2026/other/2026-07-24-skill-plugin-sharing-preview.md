# July 24, 2026: Skill and plugin sharing in CoCo (*Public Preview*)

Skill and plugin sharing is now available in public preview. Share, discover, and govern CoCo skills
and plugins across your Snowflake account. Publish them as Cortex Extension objects that teammates can
find and install, with administrator certification, access control, and usage telemetry.

For more information, see [Share skills and plugins](/user-guide/cortex-code/cortex-code-skill-plugin-sharing).
