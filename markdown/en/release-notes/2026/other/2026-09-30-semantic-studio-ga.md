# Sep 30, 2026: Semantic Studio (*General availability*)

Semantic Studio is now generally available. Semantic Studio is the authoring environment for semantic views in
Workspaces, combining conversational authoring with CoCo, direct YAML editing, and deploying YAML files to Snowflake
objects. You can also use Git-backed version control to collaborate on semantic view definitions and track changes.

For more information, see [Semantic Studio](/user-guide/views-semantic/semantic-studio).
