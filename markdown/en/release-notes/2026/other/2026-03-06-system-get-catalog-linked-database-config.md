# Mar 06, 2026: SYSTEM$GET\_CATALOG\_LINKED\_DATABASE\_CONFIG function (*General availability*)

The SYSTEM$GET\_CATALOG\_LINKED\_DATABASE\_CONFIG function is now available. You can use this function to get the configuration for
catalog-linked databases.

For more information, see [SYSTEM$GET\_CATALOG\_LINKED\_DATABASE\_CONFIG](/sql-reference/functions/system_get_catalog_linked_database_config).
