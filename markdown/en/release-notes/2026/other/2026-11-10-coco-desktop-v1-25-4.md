# Nov 10, 2026: CoCo Desktop v1.25.4

CoCo Desktop v1.25.4 includes these changes:

- **Browser tools stay with their chat**: The agent’s browser tools act only on the browser panel of the chat that called them. Clicks, key presses, and screenshots need that chat’s browser panel to be on screen.
- **Artifacts open in the Files preview**: Selecting a Snowflake artifact in a chat opens a copy in the **Files** preview.
- **Project Action Bar is the only dbt view**: The previous dbt view and the `dbt.redesign` setting are removed.
- **Faster dbt project discovery**: CoCo Desktop finds dbt projects with a single ripgrep file search instead of scanning every folder, so the project list appears much sooner in large workspaces.
- **Signed Windows updates**: Windows updates install only when they’re signed by Snowflake Inc.

For more information, see [CoCo Desktop v1.25.4 release notes](/user-guide/cortex-code/cortex-code-desktop/release-notes/v1-25-4).
