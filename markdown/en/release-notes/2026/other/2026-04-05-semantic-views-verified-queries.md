# Apr 05, 2026: Support for verified queries in semantic views

When defining a [semantic view](/user-guide/views-semantic/overview), you can now provide
[verified queries](/user-guide/snowflake-cortex/cortex-analyst/verified-query-repository) to help improve the accuracy
and trustworthiness of results from Cortex Analyst.

In the [CREATE SEMANTIC VIEW](/sql-reference/sql/create-semantic-view) command, use the AI\_VERIFIED\_QUERIES clause to specify verified queries
for the semantic view.

For more information, see [Providing verified queries for the semantic view](/user-guide/views-semantic/sql#label-semantic-views-verified-queries).
