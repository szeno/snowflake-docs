# Sep 30, 2026: Organization Features in Organization Command Center (*General availability*)

Organization Features in Organization Command Center is now generally available and is no longer in
[Preview](/release-notes/preview-features).

From the organization account, a user with the GLOBALORGADMIN role can open **Organization Hub** » **Command
center**, then the **Organization Features** tile, to see which organization-level capabilities are enabled. The main
control is premium views for cross-account telemetry. Organizations that have a capacity contract have premium views
enabled by default. You can enable or disable premium views through Snowflake Support.

This Command Center page requires an [organization account](/user-guide/organization-accounts). Access is limited to the
GLOBALORGADMIN role.

For more information, see [Organization Command Center](/user-guide/organization-hub-command-center) and
[Organization Features](/user-guide/organization-hub-command-center-features).
