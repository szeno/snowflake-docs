# Sep 04, 2026: Prompt injection guardrails now available in AWS\_EU, AWS\_JP, and AWS\_APJ

Prompt injection guardrails in [Cortex AI Guardrails](/user-guide/snowflake-cortex/cortex-ai-guardrails)
are now available when the `CORTEX_ENABLED_CROSS_REGION` account parameter is set to `AWS_EU`,
`AWS_JP`, or `AWS_APJ`. Previously, prompt injection guardrails required `ANY_REGION`, `AWS_US`, or
`AWS_GLOBAL`.

For more information, see [Cortex AI Guardrails](/user-guide/snowflake-cortex/cortex-ai-guardrails).
