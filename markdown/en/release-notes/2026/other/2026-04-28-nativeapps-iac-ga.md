# Apr 28, 2026: Snowflake Native Apps: Inter-app communication (*General availability*)

With this release, inter-app communication is now generally available for Snowflake Native Apps. Inter-app
communication allows a Snowflake Native App to provide additional functionality to other apps in the same
consumer account by providing access to objects that other apps can use.
