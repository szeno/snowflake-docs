# Apr 24, 2026: Storage lifecycle policies: Google Cloud support

Storage lifecycle policies now support archival on Google Cloud:

- **Google Cloud COOL and COLD tiers**: You can now create archival policies that use either the
  COOL or COLD storage tier on accounts hosted on Google Cloud.

With this update, you can use archival policies on all three major cloud providers:

- **COOL tier**: Available for accounts hosted on AWS, Microsoft Azure, and Google Cloud.
- **COLD tier**: Available for accounts hosted on AWS and Google Cloud.

For more information, see [Storage lifecycle policies](/user-guide/storage-management/storage-lifecycle-policies).
