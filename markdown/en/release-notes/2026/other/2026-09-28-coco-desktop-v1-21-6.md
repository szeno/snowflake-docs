# Sep 28, 2026: CoCo Desktop v1.21.6

CoCo Desktop v1.21.6 refines everyday chat controls and shores up connectivity:

- **Grouped model picker with thinking effort**: The composer model picker is reorganized, and the thinking effort control now lives inside it as a nested row.
- **Agent-managed default model**: Unpinned or **Auto** selections defer to your agent profile’s default model; the picker shows **Auto (default)**.
- **Regex and fuzzy memory recall**: `cortex memory recall` accepts `--query-type=FUZZY|REGEX`.
- **Reliability fixes**: Connecting to a second SSH host no longer drops the first, SSH reconnects no longer fail on a busy port, agent SQL works behind an HTTP proxy, and Windows session-restore and catalog-install path issues are fixed.

For more information, see [Cortex Code Desktop v1.21.6 release notes](/user-guide/cortex-code/cortex-code-desktop/release-notes/v1-21-6).
