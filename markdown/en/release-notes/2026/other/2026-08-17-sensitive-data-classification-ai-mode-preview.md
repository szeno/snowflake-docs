# August 17, 2026: AI mode for sensitive data classification (*Public Preview*)

Sensitive data classification now supports **AI mode** in public preview. When you enable AI mode on a classification profile, Snowflake
uses the OpenAI GPT-5 Mini model to identify additional semantic categories beyond those detected by standard classification, which can
improve accuracy.

You can enable AI mode when you set up classification in the Trust Center **Data Security** tab or by using SQL to create or update a
classification profile.

For more information, see:

- [AI mode](/user-guide/classify-intro#label-classify-ai-mode)
- [Set up classification with advanced settings](/user-guide/classify-ui-trust-center#label-classify-trust-center-advanced)
- [Use AI mode in a classification profile](/user-guide/classify-auto#label-classify-auto-ai-mode)
