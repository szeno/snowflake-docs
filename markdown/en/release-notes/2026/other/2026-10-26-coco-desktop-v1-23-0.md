# Oct 26, 2026: CoCo Desktop v1.23.0

CoCo Desktop v1.23.0 makes sessions easier to organize and brings Snowflake Managed MCP servers to all accounts:

- **Organize the session list**: Group sessions by date or status, sort them by recent activity or status, and see which sections need your attention.
- **Copy a session’s ID or transcript**: Right-click a session to copy its ID or transcript.
- **Prompt history for each chat**: The Up and Down arrow keys in the message box step through the messages sent in the current chat.
- **Snowflake Managed MCP servers for all accounts**: MCP servers enabled by your administrator appear under **Agent Settings** > **MCP** > **Snowflake Managed**.
- **Notifications open their chat**: Approval and response notifications are titled with their chat and open it when clicked.
- **Reliability fixes**: Fixes for dbt Show with dbt Fusion and dbt State, Snowflake-managed dbt project sync, skill sharing errors, and background subagent edits.

For more information, see [CoCo Desktop v1.23.0 release notes](/user-guide/cortex-code/cortex-code-desktop/release-notes/v1-23-0).
