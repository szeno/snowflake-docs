# Oct 8, 2026: Snowflake Data Clean Rooms updates

Enabling updates

- **Clean room UI users:** New updates are applied to the UI automatically when a user starts a new session after a new update is deployed. To ensure new updates are applied, make sure to log out and log back into the UI.
- **Clean room API users:** API updates are applied either manually or automatically to an account. [Learn how to manage updates for Data Clean Rooms.](/user-guide/cleanrooms/managing-updates)

  You can find your API environment version number by running the following SQL command:

  Copy code

  ```
  SELECT * FROM SAMOOHA_BY_SNOWFLAKE_LOCAL_DB.ADMIN.VERSION;
  ```

## Clean Rooms API Version: 18.7

The following updates are now available in Snowflake Data Clean Rooms:

- **Updated registration validations for data offerings:**
  When you call
  [`REGISTER_DATA_OFFERING`](/user-guide/cleanrooms/collaboration-api-reference#label-dcr-collaboration-register-data-offering-reference),
  Snowflake validates that any hashed columns in the
  [data offering specification](/user-guide/cleanrooms/spec-data-offering#label-dcr-collaboration-data-yaml)
  are in the declared format by sampling rows from the source table or view. If the
  specification doesn’t declare any hashed `column_type` values, Snowflake skips
  the sampling step.
- **Fixed privileges for unregistering resources from custom registries:** For custom
  registries created after this release, a role that was granted the REGISTER privilege
  on a custom registry can now call
  [`UNREGISTER_TEMPLATE`](/user-guide/cleanrooms/collaboration-api-reference#label-dcr-collaboration-unregister-template-reference)
  and
  [`UNREGISTER_DATA_OFFERING`](/user-guide/cleanrooms/collaboration-api-reference#label-dcr-collaboration-unregister-data-offering-reference)
  on resources in that registry. Previously, the privilege let the role register resources but not
  remove them. For the full list of privileges that each procedure requires, see
  [DCR privilege requirements for Collaboration API procedures](/user-guide/cleanrooms/manage-access#label-dcr-collab-list-of-required-privileges).
- General performance improvements and bug fixes.
