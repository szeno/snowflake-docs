# Oct 20, 2026: Snowflake-provided tags (*General availability*)

With this release, Snowflake-provided tags are generally available. These out-of-the-box tags in the `SNOWFLAKE.TAGS`
schema give you a consistent vocabulary for common governance use cases, including cost center, certification status, sensitivity,
environment, and project, without creating and maintaining equivalent tags in each account.

`SKIP_TAG_PROPAGATION` requires [Enterprise Edition or higher](/user-guide/intro-editions).

For more information, see [Snowflake-provided tags](/user-guide/object-tagging/snowflake-provided-tags).
