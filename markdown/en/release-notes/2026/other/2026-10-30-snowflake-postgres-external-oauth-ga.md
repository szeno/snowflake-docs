# Oct 30, 2026: External OAuth for Snowflake Postgres (*General availability*)

External OAuth for Snowflake Postgres is now generally available. You can authenticate connections to a Snowflake Postgres instance with access tokens from an external identity provider.

`ACCEPTED_TOKENS` is now required when you set External OAuth. Previously, it could be omitted.

For more information, see [Configure authentication for Snowflake Postgres](/user-guide/snowflake-postgres/postgres-authentication).
