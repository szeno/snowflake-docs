# Aug 24, 2026: Improved data freshness for ORGANIZATION\_USAGE premium views

With this release, Snowflake has improved data freshness for most
[premium views](/user-guide/organization-accounts-premium-views) in the
[ORGANIZATION\_USAGE](/sql-reference/organization-usage) schema. Typical data latency is now under 3 hours. Many of these
views previously had a latency of up to 24 hours.

Some views still have a longer latency. For the latency of each view, see
[Organization Usage](/sql-reference/organization-usage).

For more information about premium views, see [Premium views in the organization account](/user-guide/organization-accounts-premium-views).
