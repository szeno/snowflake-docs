# Sep 25, 2026: OpenAI GPT-5.6 and GPT-6 Astra models (*General availability*)

The following OpenAI models are now generally available in Cortex Inference:

- `openai-gpt-5.6-luna`
- `openai-gpt-5.6-sol`
- `openai-gpt-5.6-terra`
- `openai-gpt-6-astra`

These models support cross-region inference with `CORTEX_ENABLED_CROSS_REGION` set to `AWS_US`, `AWS_GLOBAL`, or `ANY_REGION`.

For more information, see [Model availability](/user-guide/snowflake-cortex/cortex-rest-api#label-cortex-complete-llm-model-availability).

## OpenAI GPT-6 Sol and Luna models (Preview)

The `openai-gpt-6-sol` and `openai-gpt-6-luna` models are now available in Public Preview in Cortex Inference.
Both models support cross-region inference with `CORTEX_ENABLED_CROSS_REGION` set to
`AWS_US`, `AWS_GLOBAL`, or `ANY_REGION`.
