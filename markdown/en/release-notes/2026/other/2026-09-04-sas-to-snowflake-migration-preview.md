# Sep 4, 2026: SAS to Snowflake migration (Preview)

The Snowflake AIM Agent for Data Warehouses now supports migrating SAS workloads to Snowflake. This capability covers AI-assisted assessment of SAS codebases and AI-based code conversion of SAS programs to Snowflake SQL, including loading SAS dataset files (`.sas7bdat`) into Snowflake tables.

For more information, see [Snowflake AIM Agent for Data Warehouses - SAS Migration](/migrations/aim-for-datawarehouses/sas-migration).
