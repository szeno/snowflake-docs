# Nov 3, 2026: CoCo Desktop v1.24.0

CoCo Desktop v1.24.0 brings Artifacts and Cloud automations to preview:

- **Artifacts (preview)**: Publish the HTML and Markdown files the agent writes to your Snowflake account, and find them on the **Artifacts** page. Favorites follow you to every device and to Snowsight. Available in accounts where artifacts are available in Snowsight.
- **Share artifacts and work on them together**: Give roles or users **Can view** or **Can publish** access from the **Share** dialog. Anyone with **Can publish** access can edit the artifact in a session and publish the changes.
- **Cloud automations (preview)**: Run automations in Snowflake on a schedule, even while your computer is off, from the **Cloud** tab of the **Automations** page. Available in accounts where CoCo automations are enabled.
- **Simpler automations**: **New** offers **Create with CoCo** or **Set up manually**, and a dot and a sidebar count show when a new run has finished.

For more information, see [CoCo Desktop v1.24.0 release notes](/user-guide/cortex-code/cortex-code-desktop/release-notes/v1-24-0).
