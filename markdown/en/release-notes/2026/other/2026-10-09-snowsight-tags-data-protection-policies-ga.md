# Oct 9, 2026: Snowsight interface for tags and data protection policies (*General availability*)

With this release, the Snowsight interface for tags and data protection policies is generally available. These areas require
[Enterprise Edition or higher](/user-guide/intro-editions).

You can create tags in Snowsight from **Governance & security** » **Tags & policies** by opening the **Tags** tab and
selecting **+ Create tag**. The **Dashboard** summarizes tagging coverage across supported object types.

You can also create and manage data protection policies from **Governance & security** » **Data protection policies**. Use the
**Dashboard** to review policy posture, the **Policies** tab to list and manage policies, and the **Objects with policies** tab to see
protected tables, views, and columns.

For more information, see [Work with object tags](/user-guide/object-tagging/work) and [Manage data protection policies in Snowsight](/user-guide/data-protection-policies-snowsight).
