# Jul 23, 2026: Snowflake Data Clean Rooms updates

Enabling updates

- **Clean room UI users:** New updates are applied to the UI automatically when a user starts a new session after a new update is deployed. To ensure new updates are applied, make sure to log out and log back into the UI.
- **Clean room API users:** API updates are applied either manually or automatically to an account. [Learn how to manage updates for Data Clean Rooms.](/user-guide/cleanrooms/managing-updates)

  You can find your API environment version number by running the following SQL command:

  Copy code

  ```
  SELECT * FROM SAMOOHA_BY_SNOWFLAKE_LOCAL_DB.ADMIN.VERSION;
  ```

## Clean Rooms API Version: 17.0

The following updates are now available in Snowflake Data Clean Rooms:

- **End-of-life notice for legacy Provider and Consumer Data Clean Rooms:** The legacy [Provider and Consumer Data Clean Rooms](/user-guide/cleanrooms/getting-started) are being discontinued. Migrate to the [Collaboration API](/user-guide/cleanrooms/overview) using the [migration tool](/user-guide/cleanrooms/migration-tool) before the following dates:
  - **2026-10-01:** New legacy clean rooms can no longer be created through the [web application](/user-guide/cleanrooms/v1/web-app-introduction).
  - **2027-02-01:** The web application becomes inaccessible, and new legacy clean rooms can no longer be created through the [Provider and Consumer API](/user-guide/cleanrooms/getting-started).
  - **2027-06-01:** Existing legacy clean rooms become inaccessible.
- **Internal data offerings hidden from [`VIEW_DATA_OFFERINGS`](/user-guide/cleanrooms/collaboration-api-reference#label-dcr-collaboration-view-data-offerings-reference):** Internal infrastructure-only offerings were previously visible in the response of `VIEW_DATA_OFFERINGS`. These internal entries are now filtered out so you only see relevant data offerings available for use in the collaboration.
- General performance improvements and bug fixes.
- Updates to private preview features.
