# Oct 22, 2026: Snowflake Data Clean Rooms updates

Enabling updates

- **Clean room UI users:** New updates are applied to the UI automatically when a user starts a new session after a new update is deployed. To ensure new updates are applied, make sure to log out and log back into the UI.
- **Clean room API users:** API updates are applied either manually or automatically to an account. [Learn how to manage updates for Data Clean Rooms.](/user-guide/cleanrooms/managing-updates)

  You can find your API environment version number by running the following SQL command:

  Copy code

  ```
  SELECT * FROM SAMOOHA_BY_SNOWFLAKE_LOCAL_DB.ADMIN.VERSION;
  ```

## Clean Rooms API Version: 19.0

The following updates are now available in Snowflake Data Clean Rooms:

- **Collaboration edits are generally available:** Collaboration owners can add, remove,
  or update collaborator roles. Each change takes effect only after
  the required collaborators approve it based on the type of update being made.
  [Learn more](/user-guide/cleanrooms/collaboration-api-reference#label-dcr-collaboration-edit-reference).
- **Fixed security scan timeouts after removing templates:** Previously, when you removed a template
  from a collaboration by calling
  [`REMOVE_TEMPLATE`](/user-guide/cleanrooms/collaboration-api-reference#label-dcr-collaboration-remove-template-reference),
  the template’s associated code specs were left behind, which could cause
  security scans to time out. `REMOVE_TEMPLATE` now also removes code specs that are no longer
  used by any remaining template in the collaboration.
- **Upgraded Clean Rooms Python runtime:** The Snowflake Data Clean Rooms native app now runs
  on Python 3.13 (previously 3.10), which brings performance and security improvements.
- General performance improvements and bug fixes.
