# Oct 1, 2026: Snowflake Data Clean Rooms updates

Enabling updates

- **Clean room UI users:** New updates are applied to the UI automatically when a user starts a new session after a new update is deployed. To ensure new updates are applied, make sure to log out and log back into the UI.
- **Clean room API users:** API updates are applied either manually or automatically to an account. [Learn how to manage updates for Data Clean Rooms.](/user-guide/cleanrooms/managing-updates)

  You can find your API environment version number by running the following SQL command:

  Copy code

  ```
  SELECT * FROM SAMOOHA_BY_SNOWFLAKE_LOCAL_DB.ADMIN.VERSION;
  ```

## Clean Rooms API Version: 18.6

The following updates are now available in Snowflake Data Clean Rooms:

- **Faster setup and iteration for same-organization collaborations:** For collaborations created
  after this update, if every collaborator belongs to the same organization, Snowflake skips the
  automated security scan, so the collaboration and its updates become available sooner. Existing
  collaborations aren’t affected, and cross-organization collaborations always have to pass the
  scan. To run the scan for same-organization collaborations, set the new optional
  [`distribution: external`](/user-guide/cleanrooms/spec-collaboration#label-dcr-collaboration-distribution)
  field in the collaboration’s specification. For more information, see
  [iterating quickly in a same-organization collaboration](/user-guide/cleanrooms/developer-guide#label-dcr-collab-single-org-development).
- **Clean room creation disabled in the legacy web application:** As part of the ongoing
  [deprecation of the legacy Data Clean Rooms web application](/user-guide/cleanrooms/v1/web-app-introduction),
  you can no longer create new clean rooms through the legacy web interface. Existing legacy clean
  rooms aren’t affected, and the clean room list page now shows a banner with the remaining
  retirement dates. Use the [Collaboration API](/user-guide/cleanrooms/overview) and
  the [Snowsight Data Clean Rooms UI](/user-guide/cleanrooms/collab-ui-overview)
  to create new clean rooms moving forward. For the full timeline and migration guidance, see the
  [end-of-life page for legacy Provider and Consumer clean rooms](/user-guide/cleanrooms/pc-eol).
- General performance improvements and bug fixes.
- Updates to private preview features.
