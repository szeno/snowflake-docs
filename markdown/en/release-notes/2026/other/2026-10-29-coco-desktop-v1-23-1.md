# Oct 29, 2026: CoCo Desktop v1.23.1

CoCo Desktop v1.23.1 gives agent settings their own page and reduces approval prompts:

- **Customize page for agent settings**: MCP servers, skills, agents, hooks, rules, and plugins have their own **Customize** page in the Agent view sidebar. The settings button opens **App Settings**.
- **Fewer approval prompts for file edits**: With Default Approvals, ordinary file edits no longer ask for approval. Edits to sensitive files still do.
- **Upload any file type**: The **Upload file** option in the chat accepts any file type, up to 30 MB.
- **Reliability fixes**: **Stop** cancels SQL Playground queries in Snowflake, and there are fixes for retried and reverted prompts, large SQL result cells, cached SSO connections, and file downloads through an HTTPS proxy.

For more information, see [CoCo Desktop v1.23.1 release notes](/user-guide/cortex-code/cortex-code-desktop/release-notes/v1-23-1).
