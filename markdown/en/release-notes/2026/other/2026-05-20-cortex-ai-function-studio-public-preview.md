# May 20, 2026: Create, evaluate, and optimize Cortex AI Functions with Cortex AI Function Studio (*Public Preview*)

Cortex AI Function Studio is now available in public preview, enabling organizations to easily
create, evaluate, and optimize production-ready Cortex AI Functions for unstructured and
multimodal data workflows. AI Function Studio automates prompt engineering, model selection,
benchmarking, and optimization, helping teams accelerate AI application development while
improving quality and reducing experimentation overhead.

Key capabilities include:

- **Natural-language AI Function creation:** Build Cortex AI Functions by describing the task in
  natural language through Cortex Code CLI or Snowsight AI Studio.
- **Task-specific optimization:** Automatically benchmark and optimize prompts, model selection,
  and workflow strategies to achieve the highest possible quality for your specific task and
  data, rather than relying on generic, one-size-fits-all AI configurations.
- **Built-in automated evaluation and optimization:** Benchmark prompts, models, and workflow
  strategies using configurable evaluation metrics and managed optimization workflows.
- **Flexible development experiences:** Support both AI engineers through Cortex Code CLI and
  analysts through guided no-code experiences in Snowsight AI Studio.
- **Multimodal workflow support:** Build AI Functions for text, documents, images, audio, and
  video workloads based on supported model capabilities.

AI Function Studio is designed for enterprise AI workloads such as document extraction,
summarization, sentiment analysis, classification, structured generation, compliance workflows,
and reasoning pipelines.

For more information, see [Cortex AI Function Studio](/user-guide/snowflake-cortex/ai-function-studio).
