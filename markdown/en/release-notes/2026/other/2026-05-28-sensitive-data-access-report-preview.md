# May 28, 2026: Sensitive Data Access report (*Public Preview*)

You can now generate a Sensitive Data Access report to view which users accessed sensitive data in your account during a specified lookback
period. The report creates a view that lists user-table-role combinations identified in query and access history for classified tables.

For more information, see [Sensitive Data Access report](/user-guide/classify-ui-trust-center#label-classify-trust-center-access-report).
