# July 23, 2026: SHOW CORTEX BASE MODELS command (*General availability*)

With this release, we are pleased to announce the general availability of the SHOW CORTEX BASE
MODELS command. Use this command to list the Cortex Base Models available in your account, along
with each model’s lifecycle status, regional availability, legacy date, and end-of-life date. The
output is filtered based on your model role-based access control (RBAC) grants, so you can quickly
determine which models your current role can use.

With SHOW CORTEX BASE MODELS, you can:

- See which Cortex Base Models are currently usable in your account.
- Check a model’s lifecycle status before you adopt or migrate to it.
- Inspect the regions where each model is available, directly from SQL.

For more information, see the [SHOW CORTEX BASE MODELS](/sql-reference/sql/show-cortex-base-models) command.
