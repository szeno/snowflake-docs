# Nov 18, 2026: Spark Monitoring UI (*General availability*)

The Spark Monitoring UI is now generally available. You can monitor and troubleshoot Snowpark Connect for Spark batch jobs and sessions in Snowsight. The Spark Monitoring UI lists `snowpark-submit` and `EXECUTE CODE BUNDLE` runs under **Batch Jobs**, and Snowpark Connect sessions under **Spark Sessions**.

For more information, see [Spark Monitoring UI](/developer-guide/snowpark-connect/spark-monitoring-ui).
