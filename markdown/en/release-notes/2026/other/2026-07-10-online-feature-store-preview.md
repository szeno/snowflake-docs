# July 10, 2026: Online Feature Store (*Public Preview*)

Online Feature Store is now available in public preview. Serve the latest feature values with
low-latency online retrieval backed by Snowflake Postgres for real-time ML applications such as
fraud detection, recommendations, and personalization. Use batch, stream, and real-time feature
views; ingest events through REST APIs; and integrate with real-time model inference.

Documentation in the developer guide covers online serving workflows, [feature groups](/developer-guide/snowflake-ml/feature-store/feature-groups) for bundled training and serving, [feature development lifecycle](/developer-guide/snowflake-ml/feature-store/feature-development-lifecycle) for declarative plan-and-apply workflows with the `snow feature` CLI, and [Snowsight monitoring](/developer-guide/snowflake-ml/feature-store/monitoring) for offline refresh, stream ingest, and online serving metrics.

For more information, see [Serving online features](/developer-guide/snowflake-ml/feature-store/online-feature-store).
