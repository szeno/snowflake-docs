# Jun 1, 2026: Organization Hub (*Public Preview*)

Organization Hub is now in Public Preview.

Organization Hub is a dashboard for organization accounts that consolidates key metrics across all accounts in your organization. Use it to monitor security posture, manage costs, analyze query health, and track storage growth from a single view.

Organization Hub requires an [organization account](/user-guide/organization-accounts) with [premium views](/user-guide/organization-accounts-premium-views) enabled. Access is limited to users with the GLOBALORGADMIN role.

For more information, see [Organization Hub](/user-guide/organization-hub).
