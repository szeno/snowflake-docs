# May 21, 2026: Dynamic tables documentation rewritten

The [dynamic tables documentation](/user-guide/dynamic-tables/overview) now includes 30 new and updated pages covering the full lifecycle of building, optimizing, monitoring, and troubleshooting dynamic table pipelines.

Key improvements include:

- **Best practices and design patterns**: New [quick-start best practices](/user-guide/dynamic-tables/best-practices) for production deployments and [design patterns](/user-guide/dynamic-tables/design-patterns) covering multi-table pipelines, controller tables, and SCD Type 1 deduplication.
- **New pages**: [Migration from streams and tasks](/user-guide/dynamic-tables/migrate-streams-tasks), [dbt integration](/user-guide/dynamic-tables/dbt), [design patterns](/user-guide/dynamic-tables/design-patterns), [pipeline boundaries and data consistency](/user-guide/dynamic-tables/data-consistency), [error code reference](/user-guide/dynamic-tables/error-codes), and [replication behavior](/user-guide/dynamic-tables/replication).
- **Expanded troubleshooting**: Three dedicated troubleshooting pages covering [creation issues](/user-guide/dynamic-tables/troubleshoot-creation), [permission issues](/user-guide/dynamic-tables/troubleshoot-permissions), and [refresh issues](/user-guide/dynamic-tables/troubleshoot-refreshes) with symptom-based navigation and diagnostic SQL.
- **Optimization guidance**: Detailed coverage of [refresh optimization](/user-guide/dynamic-tables/refresh-optimization), [primary keys and input data](/user-guide/dynamic-tables/input-data-optimization), [warehouse selection](/user-guide/dynamic-tables/warehouse-selection), and [cost management](/user-guide/dynamic-tables/cost).
- **Runnable examples**: Every page includes complete, copy-pasteable SQL examples with expected output.

For a guided introduction, start with [Tutorial: Create a dynamic table pipeline](/user-guide/dynamic-tables/create).
