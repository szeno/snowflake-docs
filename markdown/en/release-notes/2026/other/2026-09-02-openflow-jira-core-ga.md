# Sep 02, 2026: Openflow Connector for Jira Cloud: Core flow (*General availability*)

The Atlassian Jira Cloud (Core) flow is now generally available. The flow ingests Jira Cloud issues,
projects, users, and related data into dedicated Snowflake tables with explicit schemas.
It supports optional deletion tracking and parallel ingestion across projects.

The Atlassian Jira Cloud (Agile) flow remains in [Public Preview](/release-notes/preview-features).

For more information, see
[About Openflow Connector for Jira Cloud](/user-guide/data-integration/openflow/connectors/jira-cloud/about).
