# Apr 24, 2026: Data Security in the Trust Center (*General availability*)

With this release, the **Data Security** experience in the Trust Center is generally available in Snowsight.

Data Security enables automatic sensitive data classification across your databases and identifies regulated and high-risk categories
such as personally identifiable information (PII), payment card industry (PCI) data, and protected health information (PHI), without writing SQL.
You get a consolidated view of where sensitive data lives, how it may map to compliance obligations, and whether masking policies already protect it.

- For step-by-step instructions, see [Use the Trust Center to set up sensitive data classification](/user-guide/classify-ui-trust-center).
- On the **Data Security** **Dashboard** tab, [Review classification results](/user-guide/classify-ui-trust-center#label-classify-trust-center-review-results) walks you through tables that need a decision before tags apply.
- [Classification errors](/user-guide/classify-ui-trust-center#label-classify-trust-center-classification-errors) shows which objects failed classification and the error details.

If you’re new to sensitive data classification, see [Introduction to sensitive data classification](/user-guide/classify-intro).
If you’re currently using sensitive data classification and want to see your results in the Trust Center, see [Use the Trust Center to view classification results](/user-guide/classify-results#label-classify-trust-center-review).
