# Aug 12, 2026: New POSTGRES\_COMPUTE\_USAGE\_HISTORY view

The ACCOUNT\_USAGE and ORGANIZATION\_USAGE schemas now include a new POSTGRES\_COMPUTE\_USAGE\_HISTORY
view that provides visibility into the hourly compute credit usage for Postgres instances.

For more information, see:

- [POSTGRES\_COMPUTE\_USAGE\_HISTORY (Account Usage)](/sql-reference/account-usage/postgres_compute_usage_history)
- [POSTGRES\_COMPUTE\_USAGE\_HISTORY (Organization Usage)](/sql-reference/organization-usage/postgres_compute_usage_history)
