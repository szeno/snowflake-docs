# Oct 13, 2026: Cortex Agent SDK (*Public Preview*)

The Cortex Agent SDK is now available in Public Preview for Python and TypeScript. Use the SDK to build applications
that run Cortex Agents and Cortex Code, maintain conversations and threads, observe durable turns, and reconnect to
long-running work.

For more information, see [Cortex Agent SDK](/user-guide/snowflake-cortex/cortex-agent-sdk/cortex-agent-sdk).
