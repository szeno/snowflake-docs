# May 01, 2026: New authentication methods for SCIM requests (*General availability*)

You can now authenticate SCIM API requests with the following types of tokens:

- Programmatic access tokens (PATs)
- OAuth tokens obtained from a third-party identity provider (External OAuth)

These tokens provide enhanced authentication options beyond the existing SCIM access tokens.

If you use one of these new authentication methods, the base URL of your SCIM requests changes. For more information,
see [Authenticating SCIM API requests](/user-guide/scim-authentication).
