# Nov 17, 2026: CoCo Desktop v2.0.0

CoCo Desktop v2.0.0 includes these changes:

- **Redesigned interface**: CoCo Desktop has a redesigned look across the app, including onboarding, the sidebar, the chat input, and the changed files panel.
- **Agent Window**: Agent view opens in its own window, separate from the editor window.
- **Split panes**: Drag sessions from the sidebar to work in several sessions side by side in a resizable grid.
- **Session search palette**: Press **⌘K** (**Ctrl+K** on Windows) to search your sessions by title, project, or conversation content.
- **Updated Agentic Browser**: The browser shows what CoCo is doing, lets you leave comments on page elements, supports up to 10 tabs, and adds find in page. For more information, see [What’s new in v2.0.0](/user-guide/cortex-code/cortex-code-desktop/agentic-browser#label-cortex-code-desktop-agentic-browser-whats-new).
- **Pull request status in chat**: Links to GitHub pull requests show whether each pull request is open, merged, or closed.
- **Snowflake object discovery without CoCo CLI**: The `snowflake-object-discovery` subagent no longer needs a local CoCo CLI installation.

For more information, see [CoCo Desktop v2.0.0 release notes](/user-guide/cortex-code/cortex-code-desktop/release-notes/v2-0-0).
