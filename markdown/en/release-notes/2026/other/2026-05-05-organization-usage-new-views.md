# May 05, 2026: New ORGANIZATION\_USAGE premium views

The ORGANIZATION\_USAGE schema now includes three new [premium views](/user-guide/organization-accounts-premium-views)
that are available in the [organization account](/user-guide/organization-accounts). These views provide
visibility into network policies and network rules across all accounts in your organization.

The new views are:

- [NETWORK\_POLICIES](/sql-reference/organization-usage/network_policies): Returns one row for each network policy in an account.
- [NETWORK\_RULE\_REFERENCES](/sql-reference/organization-usage/network_rule_references): Returns one row for each network rule associated with an external access integration or network policy.
- [NETWORK\_RULES](/sql-reference/organization-usage/network_rules): Returns one row for each network rule in an account.

For more information about accessing premium views in the organization account, see [Access schema in the organization account](/sql-reference/organization-usage#label-org-usage-access-org-account).
