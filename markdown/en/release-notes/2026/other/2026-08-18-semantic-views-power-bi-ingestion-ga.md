# Aug 18, 2026: Power BI ingestion for Semantic View Autopilot (*General availability*)

Power BI ingestion for Semantic View Autopilot is now generally available. You can upload a `.pbit` or `.pbix` file
to Semantic View Autopilot and have a semantic view created automatically from your existing data model, preserving
the DAX measures, table relationships, and column descriptions you’ve already built in Power BI and making them
available to Cortex Analyst.

Report-level measures and time intelligence functions (such as PREVIOUSMONTH, SAMEPERIODLASTYEAR, and TOTALYTD) are
not yet fully supported.

For more information, see [Power BI ingestion feature support](/user-guide/views-semantic/power-bi-ingestion) and
[Option 2: Upload Power BI file](/user-guide/views-semantic/autopilot#label-semantic-view-autopilot-option-2-upload-power-bi-file).
