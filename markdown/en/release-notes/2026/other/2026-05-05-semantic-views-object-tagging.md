# May 05, 2026: Support for object tagging in semantic views

You can now assign [tags](/user-guide/object-tagging/introduction) to semantic views and the attributes within them,
including logical tables, dimensions, facts, and metrics. You can use tags to track sensitive data, manage governance policies,
and organize your semantic view objects.

For more information, see:

- [CREATE SEMANTIC VIEW](/sql-reference/sql/create-semantic-view) (TAG parameter)
- [ALTER SEMANTIC VIEW](/sql-reference/sql/alter-semantic-view) (SET TAG / UNSET TAG)
- [YAML specification for semantic views](/user-guide/views-semantic/semantic-view-yaml-spec) (tags in YAML)
- [Introduction to object tagging](/user-guide/object-tagging/introduction)
