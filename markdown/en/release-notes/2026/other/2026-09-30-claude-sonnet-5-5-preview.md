# Sep 30, 2026: Anthropic Claude Sonnet 5.5 model (*Preview*)

The `claude-sonnet-5-5` model is now available in Public Preview in Cortex AI Functions and the Cortex REST API.

The model supports cross-region inference with `CORTEX_ENABLED_CROSS_REGION` set to `AWS_US`, `AWS_GLOBAL`, or `ANY_REGION`.

For more information, see [Model availability](/user-guide/snowflake-cortex/cortex-rest-api#label-cortex-complete-llm-model-availability)
and [Models and regional availability for Cortex AI Functions](/user-guide/snowflake-cortex/aisql-regional-availability).
