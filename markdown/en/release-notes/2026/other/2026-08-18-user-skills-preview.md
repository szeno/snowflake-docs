# August 18, 2026: User skills in Snowflake CoWork (*Preview*)

User skills are now available in public preview in Snowflake CoWork. Business users can create reusable
workflows conversationally, from the UI (**+** menu > **Skills** > **Create new**), or by uploading a skill
folder on **Capabilities** > **Skills**, then run them explicitly with `/` or from the Skills menus, or
implicitly when a conversation matches the skill.

Creating a skill through chat or **Create new**, and running skills that execute scripts or assemble files,
require the Cortex Agent
[code execution tool](/user-guide/snowflake-cortex/cortex-agents-code-execution-tool).

For more information, see [User skills in Snowflake CoWork](/user-guide/snowflake-cortex/snowflake-cowork/user-skills).
