# May 15, 2026: Snowpark Container Services ARM instances (*General availability*)

With this release, the GEN\_ARM\_G1 instance family is generally available for Snowpark Container Services on AWS.

GEN\_ARM\_G1 provides ARM-based general-purpose compute in five sizes, from 1 vCPU to 28 vCPU, for workloads with `linux/arm64` container images.

To use ARM instances, specify a GEN\_ARM\_G1 instance family when creating a compute pool.

For pricing information, see the [Snowflake Service Consumption Table](https://www.snowflake.com/legal-files/CreditConsumptionTable.pdf).

For a complete list of available instance families and specifications, see
[Snowpark Container Services: Understanding Instance families](/developer-guide/snowpark-container-services/instance-families).
