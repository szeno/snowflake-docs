# Oct 15, 2026: Data mirroring for Snowflake Postgres (*General availability*)

Data mirroring for Snowflake Postgres is now generally available. Data mirroring continuously
replicates tables from a Snowflake Postgres instance into a Snowflake database with minimal lag.
Inserts, updates, deletes, and schema changes on the source appear on the target automatically,
without ETL pipelines, batch jobs, or third-party connectors. This feature is currently supported
on AWS and Azure.

For more information, see [Data mirroring](/user-guide/snowflake-postgres/postgres-data-mirroring).
