# Oct 27, 2026: DCM Projects DEFINE TASK GRAPH (*Preview*)

With this Public Preview release, you can use `DEFINE TASK GRAPH` in DCM Projects definition files to declaratively manage a task graph and its member tasks. A task graph provides one place for graph-wide settings, including the schedule, overlap policy, retry behavior, and member-task defaults. DCM Projects manages the task graph throughout its deployment lifecycle.

For more information, see [Task graph](/user-guide/dcm-projects/dcm-projects-supported-entities#label-dcm-projects-object-type-task-graph) and [DEFINE TASK GRAPH](/sql-reference/sql/create-task-graph#label-define-task-graph-syntax).
