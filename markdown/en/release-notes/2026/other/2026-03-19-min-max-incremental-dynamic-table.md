# March 19, 2026: MIN\_BY and MAX\_BY functions are supported with dynamic table incremental refresh (*General availability*)

The [MIN\_BY](/sql-reference/functions/min_by) and [MAX\_BY](/sql-reference/functions/max_by) aggregate and window functions are now supported
with dynamic table incremental refresh.

For a complete list of supported queries and functions, see [Supported queries for dynamic tables](/user-guide/dynamic-tables/supported-queries).
