# Nov 09, 2026: Skill recommendations and suggestions to create and share skills in CoCo

CoCo now helps you find, create, and share skills as you work. These capabilities are rolling out gradually, so you might
not see them in your CoCo sessions yet. They include the following:

- **Skill recommendations in your sessions**: While you work, CoCo searches the catalog in the background for shared
  skills related to your task and recommends one when it finds a good match. Nothing is installed unless you accept the
  recommendation. Recommendations are limited to skills that are discoverable, that your role can access, and that
  passed security scanning. Plugins aren’t recommended. For details, see
  [Skill recommendations in your sessions](/user-guide/cortex-code/cortex-code-skill-plugin-sharing#label-cortex-code-skill-sharing-recommendations).
- **Suggestions to create a skill**: After a session in which you work through a multi-step procedure, CoCo might suggest
  creating a skill from it so you can run the procedure faster next time. For details, see
  [Create a skill from a session](/user-guide/cortex-code/cortex-code-skill-plugin-sharing#label-cortex-code-skill-sharing-create-suggestions).
- **Suggestions to share a skill**: When you keep using a skill you wrote yourself across several sessions, CoCo might
  suggest sharing it to the catalog. This suggestion is rolling out across CoCo surfaces. Nothing is shared unless you
  accept the suggestion. For details, see
  [Share a skill you use often](/user-guide/cortex-code/cortex-code-skill-plugin-sharing#label-cortex-code-skill-sharing-share-suggestions).

For more information, see [Share skills and plugins](/user-guide/cortex-code/cortex-code-skill-plugin-sharing).
