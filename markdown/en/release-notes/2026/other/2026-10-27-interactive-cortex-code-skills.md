# October 27, 2026: Cortex Code skills for interactive analytics

Two Cortex Code skills now help you work with [interactive analytics](/user-guide/interactive):

- `snowflake-interactive`: Helps you start using interactive warehouses, evaluate whether a query is a good fit, choose clustering keys, manage warehouses, and troubleshoot issues. The skill is available in Cortex Code CLI, Cortex Code Desktop, and Snowsight.
- `interactive-benchmark`: Load tests a query on an interactive warehouse to check whether it meets a latency goal, such as a P95 target, under concurrency. The skill is available in Cortex Code CLI and Cortex Code Desktop.

For more information, see [Cortex Code skills for Snowflake interactive analytics](/user-guide/interactive-skills).
