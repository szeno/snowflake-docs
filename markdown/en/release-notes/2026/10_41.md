## Native App Framework updates

### Larger application package versions on AWS and Azure

With this release, the maximum size of a file in an application package version increases from 5 GB to 150 GiB, and the maximum size of an application package version stage increases from 5 GiB to 150 GiB. These limits apply to accounts on AWS and Azure, including government regions and AWS China regions.

Google Cloud deployments keep the existing limits of 5 GB per file and 5 GiB per version stage. Application package versions that exceed these limits aren’t supported in Google Cloud deployments. Snowflake doesn’t block you from creating such a version on AWS or Azure, but replicating it to a Google Cloud deployment might be slow or fail intermittently. If you distribute your app to Google Cloud deployments, keep each file under 5 GB and the version stage under 5 GiB.

For more information, see [Understand limitations in the Snowflake Native App Framework](/developer-guide/native-apps/limitations).
