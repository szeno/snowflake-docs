# 10.36 Release Notes: Oct 3, 2026 - Oct 7, 2026

Attention

This release has completed. For differences between the in-advance and final versions of these release

## Native App Framework updates

### Give users a direct link to an installed Snowflake Native App

Consumers can now give business users a direct link that opens a Streamlit app or service endpoint in an
installed Snowflake Native App as a standalone web page, without the rest of Snowsight. In the app toolbar,
select **Share** to copy the link. Recipients must be Snowflake users in the
consumer account with a role that has access to the app.

Optionally, set the `ALLOWED_INTERFACES` user property to give users access to Streamlit apps only, or
set the `LOGIN_IDP_REDIRECT` account property to sign users in through your identity provider (IdP).

For more information, see [Give users a direct link to an app](/developer-guide/native-apps/ui-consumer-managing-applications#label-nativeapps-consumer-share-url).

## Data governance updates

### Schema-level data metric functions: exclude transient tables

You can now set `EXCLUDE_TABLE_TYPES = ('TRANSIENT')` on a schema-level data metric function (DMF)
association so Snowflake does not associate the DMF with transient tables in the schema.

`'TRANSIENT'` matches the table type that `SHOW TABLES` reports as `kind`. That includes tables created
with `CREATE TRANSIENT TABLE` and tables created in a transient schema or database. Session temporary
tables are not treated as `'TRANSIENT'`.

For more information, see [Monitor the data quality of a schema](/user-guide/data-quality-schema-level).

## Non-bundled behavior changes

The following changes aren’t part of a bundle, and therefore can’t be enabled in advance:

- Schema-level data metric functions skip session temporary tables. Snowflake no longer associates a
  schema-level DMF with session temporary tables (`CREATE TEMPORARY TABLE`). You don’t need to list
  `'TEMPORARY'` in `EXCLUDE_TABLE_TYPES`.

For more information, see [Schema-level data metric functions skip session temporary tables (Pending)](/release-notes/bcr-bundles/un-bundled/bcr-snow-4184064).
