## SQL updates

### IPADDRESS data type (*General availability*)

With this release, Snowflake is pleased to announce the general availability of the `IPADDRESS` data type. An
`IPADDRESS` value stores an IPv4 or IPv6 address as a native 128-bit value. Snowflake validates each address,
stores it in a canonical form, and compares values in numeric address order. Use `TO_IPADDRESS` and
`TRY_TO_IPADDRESS` to convert strings to `IPADDRESS` values, and use `IPADDRESS_TRUNC` to group or match
addresses by network.

With general availability, user-defined functions (UDFs), user-defined table functions (UDTFs), and stored
procedures can accept and return `IPADDRESS` values in every handler language. Java and Scala handlers use
`java.net.InetAddress` or `String`, Python handlers use `ipaddress.IPv6Address`, and JavaScript handlers use
`string`.
