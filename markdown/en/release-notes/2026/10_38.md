## SQL updates

### IPADDRESS data type (*Preview*)

With this release, Snowflake is pleased to announce the preview of the `IPADDRESS` data type. An `IPADDRESS`
value stores an IPv4 or IPv6 address as a native 128-bit value. Snowflake validates each address when you
insert or load it, stores it in a canonical form, and compares values in numeric address order. As a result,
a subnet is a contiguous range of values that you can filter and join on by using `BETWEEN`.

The preview includes the following functions:

- `TO_IPADDRESS` and `TRY_TO_IPADDRESS` convert strings to `IPADDRESS` values.
- `IPADDRESS_TRUNC` returns the network address of an `IPADDRESS` value for a given prefix length. Use it to
  group addresses by subnet, mask the host bits of addresses, and match addresses against networks that are
  stored as a network address and a prefix length.
