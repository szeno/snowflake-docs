# 10.24 Release Notes: Jul 9, 2026 - Jul 15, 2026

Attention

This release has completed. For differences between the in-advance and final versions of these release
notes, see [Release notes change log](#label-rel-notes-change-log-10-24).

## New features

### Per-user quotas (*Preview*)

With this release, you can use per-user quotas to enforce spending limits at a per-user granularity,
preventing individual users from generating unwanted costs on AI features (AI functions, Cortex
Agents, Snowflake CoWork, and Snowflake CoCo). You can define monthly and daily per-user credit
limits, automatically block users when they reach a limit, configure notifications, and monitor
per-user spending via SQL, Snowsight, and the Cost Intelligence skill in Snowflake CoCo.

For more information, see [Per-user quotas](/user-guide/budgets/per-user-quotas).

### Semantic view materializations (*Public preview*)

You can now materialize frequently queried dimensions and metrics in a semantic view to pre-aggregate
data and improve query performance. Materializations are refreshed automatically based on the
`MAX_STALENESS` property and support incremental refresh for additive metrics.

For more information, see [Materializing dimensions and metrics in semantic views](/user-guide/views-semantic/materializations).
