# SnowConvert AI - Windows

## Windows Installation

1. Click on the [downloaded](../../../getting-started/download-and-access) .exe file.
2. That will start the installation process on your computer.

[![SnowConvert AI Installation on Windows](/static/images/migrations/sc-assets/image(27).png "image")](/static/images/migrations/sc-assets/image(27).png)

3. Once the process is finished you can open SnowConvert AI from your applications menu.

[![Open SnowConvert AI tool](/static/images/migrations/sc-assets/image(349).png "image")](/static/images/migrations/sc-assets/image(349).png)

4. After you start the application you can create a new assessment or conversion project or open an existing one.

[![image](/static/images/migrations/sc-assets/image(463).png "image")](/static/images/migrations/sc-assets/image(463).png)
