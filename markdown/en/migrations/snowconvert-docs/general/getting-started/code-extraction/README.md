# SnowConvert AI - Code Extraction

Code extraction is the first step in a migration. It collects the source database objects you plan to convert. Use the [Snowflake AIM for Data Warehouses App](/migrations/aim-for-datawarehouses/quick-start) to connect to the source database and pull those definitions into the project.

- [Extract code from the source database, or import SQL files you already have](/migrations/aim-for-datawarehouses/overview#register-code-units)
- [See which source systems support code extraction](/migrations/aim-for-datawarehouses/overview#supported-source-systems)
