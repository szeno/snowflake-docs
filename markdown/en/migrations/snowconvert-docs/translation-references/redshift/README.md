# Redshift

Translation specification for Redshift grammar syntax

This page provides a comprehensive reference for how [Redshift grammar elements](https://docs.aws.amazon.com/redshift/latest/dg/cm_chap_SQLCommandRef.html) are translated to Snowflake equivalents. In this translation reference, you will find, code examples, functional equivalence results, key differences, recommendations, known issues, and descriptions of each transformation.
