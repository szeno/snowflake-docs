# Snowflake AIM

**Snowflake AIM** (AI-driven Modernization and Virtualization) automates the full journey of moving your data ecosystem to Snowflake. It covers three modernization paths — Teradata virtualization, data warehouse migration, and Spark workload modernization — powered by Snowflake AIM migration agents in Snowflake CoCo.

---

## Virtualization

### Run Teradata on Snowflake without rewriting

- Escape renewal pressure without a risky rewrite
- Eliminate rewrite risk — keep applications running
- Protect mission-critical operations with zero downtime
- Modernize faster and turn migration into AI-driven value

---

## Modernization

### Migrate data warehouses to Snowflake

- Convert code and database objects from leading data warehouses
- Support tables, views, stored procedures and more
- Deploy to Snowflake native tables or managed Iceberg tables
- Automatic translation of legacy ETL workflows into dbt in Snowflake

### Migrate and modernize Spark workloads

- Analyze Python, Java, or Scala-based Spark code to identify APIs and patterns
- Assess compatibility with Snowpark and Snowpark Connect
- Generate automated conversions to Snowpark equivalents

---

## Virtualization vs. Modernization

|  | Virtualization | Modernization |
| --- | --- | --- |
| **What it means** | Run existing workloads on Snowflake without rewriting | Fully convert code, data, and pipelines to run natively on Snowflake |
| **Best for** | Escaping renewal pressure fast, or when decoupling applications is not immediately possible | Net-new migrations where teams want Snowflake-native SQL and pipelines |
| **Rewrite required** | No | Yes — AI-assisted |
| **Downtime** | Zero downtime | Phased cutover |
