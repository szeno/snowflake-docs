## Quick start for Snowflake AIM Agent for Data Warehouses

### Prerequisites

Ensure the following are installed on your platform:

1. [Python](https://www.python.org/downloads)
2. [Git](https://git-scm.com/install)
3. [Snowflake CoCo CLI](/user-guide/cortex-code/cortex-code-cli)

### Start a migration

1. Create a new directory or folder for your migration project
2. Open a terminal, go to your project directory, and run the following command:

Copy code

```
cortex
```

3. When Snowflake CoCo is loaded, run the following prompt:

Copy code

```
start a database migration
```

The first time you run this prompt, the Snowflake AIM Agent for Data Warehouses will check and ask for your permission to install any necessary components and skills to your platform. Once everything is in place, the Snowflake AIM Agent for Data Warehouses will guide you through your migration.
