The fastest migration path to Snowflake is through the use of the [Snowflake AIM Agent for Data Warehouses](/migrations/aim-for-datawarehouses/overview). Powered by [Snowflake CoCo](/user-guide/cortex-code/cortex-code), it is an AI assisted orchestrator that guides a migration team (whether one or multiple individuals) through the many stages of a migration project

[Watch a quick demo](https://www.youtube.com/watch?v=wC2T0e-QVgw)

Note

If you have advanced use cases that require directly invoking SnowConvert capabilities, you can use the [SnowConvert AI CLI](/migrations/aim-for-datawarehouses/manual-migration/README)
