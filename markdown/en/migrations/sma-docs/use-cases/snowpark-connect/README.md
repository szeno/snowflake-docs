# Snowpark Migration Accelerator: Snowpark Connect

[Snowpark Connect for Spark](/developer-guide/snowpark-connect/snowpark-connect-apache-spark) allows you to run some Spark workflows in Snowflake with minimal changes.

For a step-by-step walkthrough of migrating a PySpark codebase with the Snowflake CoCo **spark-migration** skill, see [Migrating to Snowpark Connect walkthrough](/migrations/sma-docs/use-cases/migrating-to-snowpark-connect-walkthrough).
