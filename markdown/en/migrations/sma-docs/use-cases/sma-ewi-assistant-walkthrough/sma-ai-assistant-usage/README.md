# SMA AI Assistant Usage

To ensure correct usage of the SMA AI Assistant, please follow these steps:

1. Open VS Code.
2. Follow the steps in the [AI Assistant Setup](/migrations/sma-docs/use-cases/sma-ewi-assistant-walkthrough/sma-ai-assistant-usage/ai-assistant-setup) section.
3. Open the migration output folder in VS Code.
   [![](/static/images/migrations/sma-assets/output-folder.png)](/static/images/migrations/sma-assets/output-folder.png)
4. Open the Snowflake Extension by using the sidebar at the left.

   1. Clicking on an EWI line will directly navigate you to its corresponding source line.
      [![](/static/images/migrations/sma-assets/source-line.png)](/static/images/migrations/sma-assets/source-line.png)
5. Log into your Snowflake account to get explanations and responses.
6. View the SMA EWI Assistant code lens.

   1. Click the SMA AI Assistant code lens to open a window providing explanations and resolutions for the EWI.
      [![](/static/images/migrations/sma-assets/explanations-resolutions.png)](/static/images/migrations/sma-assets/explanations-resolutions.png)
7. Log into your Snowflake account to unlock detailed explanations and helpful responses.
8. View the EWI explanation and responses.
   [![](/static/images/migrations/sma-assets/explanations-responses-view.png)](/static/images/migrations/sma-assets/explanations-responses-view.png)
9. Follow the assistant responses.
   [![](/static/images/migrations/sma-assets/assistant-responses.png)](/static/images/migrations/sma-assets/assistant-responses.png)
