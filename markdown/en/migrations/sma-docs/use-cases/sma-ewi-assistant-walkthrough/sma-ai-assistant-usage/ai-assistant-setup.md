# AI Assistant setup

1. Install the Snowflake VS Code extension.
   [![Install extension](/static/images/migrations/sma-assets/install-snowflake-extension.png)](/static/images/migrations/sma-assets/install-snowflake-extension.png)
2. Open the extension’s settings.
   [![Open settings](/static/images/migrations/sma-assets/open-extension-settings.png)](/static/images/migrations/sma-assets/open-extension-settings.png)
3. Search for and enable the **Snowpark Migration Accelerator AI Assistant**.
   [![Enable accelerator AI assistant](/static/images/migrations/sma-assets/enable-assistant.png)](/static/images/migrations/sma-assets/enable-assistant.png)
