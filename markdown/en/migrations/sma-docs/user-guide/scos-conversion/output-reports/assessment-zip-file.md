# Snowpark Migration Accelerator: Assessment zip file

The assessment results are stored in a zip file named “AssessmentFiles.zip” located in the output directory.

[![Output Directory Example, including the AssessmentFiles.zip](/static/images/migrations/sma-assets/image(530).png)](/static/images/migrations/sma-assets/image(530).png)

If you run SMA without an internet connection, you can email the zip file to [sma-info@snowflake.com](mailto:sma-info@snowflake.com). We will process the file and simulate an offline execution for you.
