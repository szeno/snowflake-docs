# Using semantic views

After a [semantic view](/user-guide/views-semantic/overview) is defined, query it, put it to work in a Cortex Agent,
share it with others, and monitor how it’s used.

- Run queries against a semantic view. See [Querying semantic views](/user-guide/views-semantic/querying).
- Configure a Cortex Agent to answer questions using the semantic view. See
  [Create and manage agents](/user-guide/snowflake-cortex/cortex-agents-manage).
- Share a semantic view with other accounts. See [Sharing semantic views](/user-guide/views-semantic/sharing-semantic-views).
- Audit the semantic views in your account by querying system metadata. See
  [Auditing semantic views with ACCOUNT\_USAGE and INFORMATION\_SCHEMA](/user-guide/views-semantic/views).
