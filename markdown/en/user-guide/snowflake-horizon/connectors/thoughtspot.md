# ThoughtSpot

## Before you start

To connect ThoughtSpot to Horizon Catalog, you need the following:

- Administrator access to your ThoughtSpot instance. Horizon Catalog authenticates as a user with the
  **Administration** privilege, and enabling trusted authentication requires an administrator.

Complete the following steps to enable metadata, lineage, and popularity of your ThoughtSpot
Liveboards, Answers, and Worksheets in Horizon Catalog.

1. [Identify your ThoughtSpot base URL](#1-identify-your-thoughtspot-base-url).
2. [Enable trusted authentication and copy the secret key](#2-enable-trusted-authentication-and-copy-the-secret-key).
3. [Create the ThoughtSpot connection](#3-create-the-thoughtspot-connection).

## 1. Identify your ThoughtSpot base URL

The base URL is the URL Horizon Catalog uses to reach your ThoughtSpot instance. It is the address you
use to sign in to ThoughtSpot, for example `https://my2.thoughtspot.cloud`. Keep this information for
the next steps.

## 2. Enable trusted authentication and copy the secret key

Horizon Catalog authenticates with a ThoughtSpot user and a **secret key** generated by trusted
authentication. You must be a ThoughtSpot administrator to enable it.

1. Sign in to ThoughtSpot as an administrator.
2. Open the **Develop** tab and select **Security settings**, listed under the **Customizations**
   section of the sidebar.
3. Select **Edit**.
4. Turn on the **Trusted authentication** toggle, then select **Save changes**. A secret key is
   generated.
5. To copy the secret key, select **Edit** again, go to **Trusted authentication**, and select the
   copy-to-clipboard icon.
6. Securely store the secret key for the next step.

For details, see [Trusted authentication](https://developers.thoughtspot.com/docs/trusted-auth) in the
ThoughtSpot documentation.

Note

Disabling trusted authentication invalidates the existing secret key. If you regenerate the key, you
must update the ThoughtSpot connection in Horizon Catalog with the new value.

## 3. Create the ThoughtSpot connection

1. In Snowflake, open **Catalog > Connections** and select **ThoughtSpot** from the Metadata
   connections section.
2. Fill out the setup form with the following information:

   - **Display Name:** The default is `ThoughtSpot`, but you can override it.
   - **Username:** The ThoughtSpot username or email address of a user with the **Administration**
     privilege.
   - **Secret Key:** The secret key from [Step 2](#2-enable-trusted-authentication-and-copy-the-secret-key).
   - **Base URL:** Your ThoughtSpot instance URL from
     [Step 1](#1-identify-your-thoughtspot-base-url), for example `https://my2.thoughtspot.cloud`.
   - **Snowflake Database** and **Snowflake Schema:** The database and schema in your Snowflake
     account where Horizon Catalog stores the connector metadata. The defaults are `CONNECTORS` and
     `METADATA`.
3. Select **Next**. Horizon Catalog creates the connection and continues to the **Load data** step,
   where the first sync starts.
4. When the wizard confirms that the connection is ready, select **Done**. The sync continues to run
   in the background.

## Connection security

All communication between Horizon Catalog and ThoughtSpot uses HTTPS (TLS 1.2 or higher).
Authentication uses trusted authentication with a ThoughtSpot username and secret key, which are
stored as encrypted secrets. No additional encryption configuration is required.

For more details, see [Security and data protection](/user-guide/snowflake-horizon/connectors/security).
