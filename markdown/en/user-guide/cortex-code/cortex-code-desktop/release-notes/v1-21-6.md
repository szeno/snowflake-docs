# Cortex Code Desktop v1.21.6 release notes

v1.21.6 refines everyday chat controls and shores up connectivity. The composer model picker is reorganized and now holds the thinking effort control, and model selection defers to your agent profile when you haven’t pinned one. Alongside these, this release fixes several SSH, proxy, and Windows issues.

## What’s new

- **Grouped model picker with thinking effort**: The composer model picker is reorganized into automatic options first, then a row per model family, with the remaining versions behind an **Other models** row. The thinking effort control now lives inside the picker as a nested row instead of a separate control, and its trailing value shows the effort level that will actually run.
- **Agent-managed default model**: When you haven’t pinned a model, or you select **Auto**, Cortex Code no longer forces a client-side model: the request defers to your agent profile’s default. The picker shows **Auto (default)**, and pinning a specific model still overrides the profile.
- **Regex and fuzzy memory recall**: `cortex memory recall` accepts a `--query-type` option (`FUZZY` or `REGEX`), so you can match stored memories by regular expression in addition to the default fuzzy search.
- **Clearer local automation list and details**: The Automations list shows humanized weekday schedules and sorts local automations newest-first within Active and Inactive groups, and the local automation detail view is restyled with a clearer heading, labeled actions, and run history.
- **Find Cortex Code from Spotlight**: On macOS, searching Spotlight for “CoCo” now finds the app.
- **Command hook arguments**: Command hooks defined in `.claude/settings.json` now honor their `args` array and receive correctly-cased tool names, so an installed command hook evaluates the tool call instead of only printing usage.

## Reliability and fixes

- **Connecting to a second SSH host no longer drops the first**: SSH connections are now tracked per host, so opening a second remote no longer tears down a connection that had already succeeded.
- **SSH reconnects no longer fail on a busy port**: Tunnel ports are released when a window closes, fixing `Address already in use` and `ECONNREFUSED` errors when reconnecting to a remote.
- **Agent SQL works behind an HTTP proxy**: Agent requests that mint a child Snowflake session now honor `HTTP_PROXY`, `HTTPS_PROXY`, and `NO_PROXY`, so agent SQL works in proxy-only environments where manual SQL already did.
- **Windows: saved sessions with a cross-workspace target open again**: Restoring a saved agent session on Windows no longer fails with a path error when the session targets another workspace.
- **Windows: catalog installs work with short-name temp paths**: Installing a shared skill or plugin no longer fails when the local destination path contains a `~` (8.3 short name).
- **Cortex Sense feedback no longer reports a false failure**: Submitting Cortex Sense feedback that actually succeeded no longer surfaces a spurious “tool not found” error.
- **App sharing dialog no longer hangs on large accounts**: The Streamlit share dialog in the Apps gallery no longer hangs while loading roles on accounts with many roles.
- **Failed SQL keeps its query ID**: Failed and cancelled SQL statements now retain their submitted Snowflake query ID, making failures easier to trace.
