# CoCo Desktop v2.0.0 release notes

CoCo Desktop v2.0.0 brings a redesigned interface to every installation. Agent view opens in its own Agent Window, you can work in several sessions side by side with split panes, and a new search palette finds any session by its title or its conversation. This release also shows the status of GitHub pull requests in chat, removes the CoCo CLI requirement for Snowflake object discovery, and fixes sign-in hangs and several dbt issues.

## What’s new

- **Redesigned interface**: CoCo Desktop has a redesigned look across the app, including onboarding, the sidebar, the chat input, and the panel that lists the files the agent changed. The sidebar is keyboard accessible: press **Tab** to move focus to a session, and press **Enter** or **Space** to open it. To return to the previous interface, disable the `snowflake.consumerGradeUI.enabled` setting and reload the window.
- **Agent Window**: Agent view opens in its own **Agent Window**, separate from the editor window, so you can keep your agent sessions and your code side by side. To run Agent view in the editor window instead, disable the `chat.agentManager.separateWindow` setting.
- **Split panes**: Drag a session from the sidebar into the main area to open it next to the current session. Sessions in a group appear in a resizable grid, each with its own live conversation, and the group is restored when you restart CoCo Desktop. To turn off split panes, disable the `chat.agentManager.splitPanes.enabled` setting.
- **Session search palette**: Press **⌘K** (**Ctrl+K** on Windows) in the Agent Window, or select **Search** in the sidebar, to open the redesigned search palette. It searches session titles, project names, and the content of your conversations on this computer. Nothing is sent to Snowflake. Type `>` to search commands as well.
- **Updated Agentic Browser**: The [Agentic Browser](/user-guide/cortex-code/cortex-code-desktop/agentic-browser) shows what CoCo is doing and has a **Stop** button, lets you leave comments on page elements for CoCo to address, supports up to 10 tabs, and adds find in page and a home page on new tabs. You can turn it off with the `agentBrowser.enabled` setting. For details, see [What’s new in v2.0.0](/user-guide/cortex-code/cortex-code-desktop/agentic-browser#label-cortex-code-desktop-agentic-browser-whats-new).
- **Pull request status in chat**: Links to GitHub pull requests in chat start with an icon that shows the pull request’s state: green for open, purple for merged, red for closed, and gray for a draft or an unknown state. CoCo Desktop reads the state with your GitHub sign-in or, if you aren’t signed in, the GitHub CLI (`gh`). A bare pull request URL is shortened to `repo#N`. To turn off these icons, disable the `chat.pullRequestLinks.enabled` setting.
- **What’s New**: A **What’s New** dialog introduces the features in v2.0.0 that are available to you.
- **Snowflake object discovery without CoCo CLI**: The `snowflake-object-discovery` subagent no longer needs a local CoCo CLI installation, so it’s always available in CoCo Desktop.
- **Search for dbt projects in the project picker**: When your workspace has six or more dbt projects, the Project Action Bar’s project picker opens with a **Search projects** field. It matches a project’s name or its path in the workspace, and ignores case.
- **Plugin caution messages before download**: When you install or update a plugin from the catalog, including from an install link, CoCo Desktop shows the plugin version’s caution message, such as the MCP servers that the plugin connects to, before it downloads any files. Select **Cancel** to stop the installation.
- **`suggest-sv-materializations` skill for every account**: Now that [semantic view materializations](/user-guide/views-semantic/materializations) are generally available, the bundled [`suggest-sv-materializations`](/user-guide/cortex-code/bundled-skills#label-bundled-skill-suggest-sv-materializations) skill is available in CoCo Desktop for every account.
- **Renaming a session doesn’t ask for approval**: When the agent renames the current session, it no longer shows an approval prompt.
- **Private mode and skill suggestions**: When private mode is on, CoCo Desktop doesn’t send your sessions for review to suggest creating a skill, and your skill use doesn’t count toward a suggestion to share a skill.

## Reliability and fixes

- **No more sign-in hangs after an interrupted sign-in**: If CoCo Desktop quit during a browser sign-in, the next sign-in could hang for three to five minutes. CoCo Desktop now recovers right away.
- **Sign-in confirmation page**: After you sign in with SSO or OAuth, the browser tab shows **You’re signed in to CoCo**, or **Sign-in didn’t complete** with the error, instead of a generic driver page.
- **Context usage stays at or below 100%**: The context usage meter could read above 100% after a turn with many tool calls. It now reflects the context that the model used in its last call.
- **Managed policies**: For organizations that use [managed settings](/user-guide/cortex-code/cortex-code-desktop/managed-settings), skill source patterns such as `skill(user:*)` and `skill(remote:*)` apply to every way that CoCo Desktop loads skills. Stage skills count as remote. MCP server patterns are checked when a server starts, local servers are matched by their command, and URL and command patterns no longer hide an allowed server’s tools. Snowflake-managed MCP servers are exempt.
- **Search palette feedback**: The session search palette shows a spinner while a search runs, instead of **No results found**, and shows **No matches** when a search finds nothing.
- **Split panes in narrow windows**: Narrow panes stay usable, and the chat input’s **Send** button stays visible in a narrow pane. A group can have up to four columns while the side panel is open.
- **dbt Run menu stays open**: The **Run** menu in the editor title bar no longer closes right after it opens when the editor has focus.
- **Stopping a Snowflake-managed dbt run**: When you stop a Snowflake-managed dbt run that Snowflake has already canceled, CoCo Desktop no longer warns that the query might still be running.
- **Auto Fix from Lineage keeps the file**: When you select **Auto Fix** in the **Lineage** panel after a run completes, the chat now includes the file of the model that failed.
- **Artifacts**: The menus for an artifact offer **Copy link** instead of separate **Open in CoWork** and **Open in Snowsight** items. The **More** menu on an artifact’s detail page offers the same actions as its tile in the library: **Start session**, **Rename**, **Share**, and **Delete**. When the agent publishes a report without sharing it with any roles, the report is published privately to you, instead of failing.
- **Automations page on narrow windows**: On a narrow **Automations** page, the **+ New** button becomes an icon that opens the same menu, and the **Preview** badge moves below the title.
