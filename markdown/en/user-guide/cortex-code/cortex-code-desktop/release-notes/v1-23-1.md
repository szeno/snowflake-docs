# CoCo Desktop v1.23.1 release notes

v1.23.1 gives agent settings their own **Customize** page, stops asking for approval before ordinary file edits, and lets you upload any file type to the chat. It also makes **Stop** cancel SQL Playground queries in Snowflake and keeps retried and reverted prompts out of what the model sees.

## What’s new

- **Customize page for agent settings**: Agent settings, including MCP servers, skills, agents, hooks, rules, and plugins, now have their own **Customize** page in the Agent view sidebar, directly after **Automations**. **Customize** opens on **MCP**. The settings (gear) button now opens **App Settings** as a separate page, which shows a notice that MCP servers and skills moved to **Customize**. Commands and links that opened Agent Settings now open the matching page.
- **Fewer approval prompts for file edits**: With **Default Approvals**, the agent’s file edits no longer ask for approval, including edits to files outside the current workspace, such as scratch files in `/tmp`. Edits to sensitive files, such as shell startup files, SSH configuration, Git configuration and hooks, and agent and MCP settings files, still ask for approval every time.
- **Upload any file type**: The **Upload file** option in the chat now accepts any file type, such as `.html` and `.mp4`, as drag and drop already did. The 30 MB limit per file is unchanged.

## Reliability and fixes

- **Stop cancels SQL Playground queries**: SQL Playground now runs queries asynchronously. Clicking **Stop** cancels the running query in Snowflake.
- **Retried and reverted prompts are removed from the conversation**: When you retry your last prompt, or revert changes to an earlier message and send again, the model no longer sees the prompts and responses you replaced or reverted.
- **Full values for large SQL result cells**: When a single cell in a SQL result is larger than 4 KB, for example the output of `DESCRIBE AGENT`, the full result is now saved to a file the agent can read. Previously the agent received a truncated value and ran extra queries to try to recover it.
- **Cached SSO connections**: Switching back to a cached SSO connection no longer makes SQL fail with “Master token not available in the current session.”
- **File downloads through an HTTPS proxy**: The bundled Snowflake Node.js driver is updated to 3.4.1, which fixes file downloads from Amazon S3 through an HTTPS proxy.
- **No interrupted-thinking marker with Gemini models**: Responses from Gemini models no longer show `[Prior thinking from interrupted response]` after tool calls.
- **Fewer accidental rewinds on macOS**: Pressing Cmd+Backspace while a chat message is focused no longer restores a checkpoint and removes that message and the ones after it. The message’s toolbar buttons still do this.
- **MCP sign-in card removed from chat**: The “MCP sign-in needed” card no longer appears in chat responses. Servers that need you to sign in are still marked on the **MCP** page.
- **Platform updates**: CoCo Desktop now runs on Electron 43.8.1, and the SSH remote server bundles Node.js 22.23.4.
