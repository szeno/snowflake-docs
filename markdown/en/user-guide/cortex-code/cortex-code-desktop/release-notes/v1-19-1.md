# Cortex Code Desktop v1.19.1 release notes

v1.19.1 makes Cortex Code faster and lighter to install and update, refreshes the update
experience on Mac and Windows, and adds a few handy features.

## What’s new

- **Faster, smaller, more reliable updates**: The app is about 20% smaller to download, updates now
  take seconds instead of minutes, and installs and updates are more reliable on both Mac and
  Windows.
- **Refreshed update experience**: Installing an update now shows a clean, branded splash screen
  with a progress bar on both Mac and Windows.
- **Subagent model `inherit`**: Set a subagent’s model to `inherit` and it uses your main chat’s
  selected model. The bundled subagents now default to `inherit`.
- **Clone a repo from the start page**: A new “Clone repo” option when adding a project.
- **Better Windows and WSL support**: Opening projects through WSL now works smoothly across file
  tools.
- **Smarter Stop**: Stopping one query no longer cancels your other running queries.

## Security and trust

- Hardened protections against untrusted project files running code unexpectedly.
- “Don’t trust” is fully respected: Restricted Mode honors your choice when you add folders.
