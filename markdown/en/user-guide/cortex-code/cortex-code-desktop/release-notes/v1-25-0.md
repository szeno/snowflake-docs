# CoCo Desktop v1.25.0 release notes

v1.25.0 makes dbt work faster and steadier: the **Lineage** panel stays on your project, the Project Action Bar appears sooner on large workspaces, and local dbt runs no longer stop after five minutes. It also removes a second approval after tools run, and fixes Windows updates that were interrupted.

## What’s new

- **Anchored dbt lineage**: The **Lineage** panel shows the whole active dbt project, or the neighborhood of a node that you anchor, instead of following the active editor. To anchor a node, double-click it, or select **Show in Lineage** on an open file. To have the panel follow the active editor again, disable the `dbt.lineage.anchored` setting.
- **Faster dbt Action Bar**: The Project Action Bar appears as soon as CoCo Desktop finds your dbt projects, without waiting for every project’s `manifest.json` to load. On workspaces with several large manifests, it appears in about two seconds instead of more than ten.
- **One timeout for dbt runs**: Local dbt runs from the Project Action Bar and Snowflake-managed runs share the `dbt.executionTimeout` setting, which defaults to four hours. Local runs previously stopped after five minutes. When a run reaches the limit, CoCo Desktop cancels it and shows **Execution timed out after N s and was cancelled.** in the output. If you set `dbt.snowflakeManaged.executionTimeout`, your value moves to the new setting.
- **No result approval after a tool runs**: MCP tools that reach outside your account, such as most Google Workspace tools, and the `fetch_page` tool no longer ask you to approve their result after they have already run. Tools that need approval still ask before they run.
- **Deleting a session deletes its Cortex thread**: When you delete a session from the sidebar or from the chat history, CoCo Desktop also deletes the session’s Cortex thread in your Snowflake account.
- **Update status in the app menu**: **Check for Updates** in the app menu shows the state of the update: **Checking for Updates…**, **Downloading Update…**, **Update Now**, or **Updating…**. Select **Update Now** to install a downloaded update. CoCo Desktop now checks for updates every four hours, and at startup.
- **Artifacts library matches Snowsight**: The **Artifacts** page lists your artifacts and the ones shared with you in the same order as the Artifacts page in Snowsight, and loads more as you scroll. Artifacts is available in accounts where artifacts are available in Snowsight.

## Reliability and fixes

- **Interrupted Windows updates**: If a Windows update was interrupted, for example at shutdown, CoCo Desktop could fail to start with an `ENOENT` error and had to be reinstalled. Updates now leave a working installation even when they’re interrupted. Installations that are already affected still need a reinstall.
- **Security update**: CoCo Desktop now runs on Electron 43.8.7 with Node.js 24.22.1, which fixes CVE-2026-111497.
- **dbt projects in the picker and Run**: The project picker and **Run** find the same dbt projects. Previously, a project under a folder that starts with a dot, such as a git worktree, could appear in the picker but fail to run with **the selected project was not found**.
- **dbt Action Bar when the side panel is maximized**: When you maximize the secondary side bar, the Project Action Bar stays visible beneath it, instead of leaving an empty editor column.
- **Unread counts**: Project folder counts in the Agent view sidebar update when you read a session. The **Automations** count shows the number of automations with new runs, rather than the number of runs, and clears when you open the **Automations** page.
- **New projects are selected**: When you add a folder with the **+** button next to **Projects** in the sidebar, CoCo Desktop selects it and starts a new session in it.
- **Close button on settings pages**: The **Customize** and **App Settings** pages have a **Close** button, which returns to the view that you came from.
- **Faster + menu**: The **+** menu in the chat input opens right away. Its **Skills** and **Artifacts** lists load when you point to them.
