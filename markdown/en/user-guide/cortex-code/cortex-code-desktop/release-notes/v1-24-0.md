# CoCo Desktop v1.24.0 release notes

v1.24.0 brings two features to preview: **Artifacts**, to publish and share the HTML reports and Markdown files the agent writes, and **Cloud automations**, which run in Snowflake on a schedule even while your computer is off. It also makes automations easier to create and shows when a new run has finished.

## What’s new

- **Artifacts (preview)**: Publish the HTML and Markdown files the agent writes to your Snowflake account, then find them again on the **Artifacts** page in the Agent view sidebar. **All** lists your artifacts and the ones shared with you, with an owner column and filter. **Favorites** are stored in Snowflake, so they appear on every device and in Snowsight. In the chat, a files card lists the HTML and Markdown files the agent wrote, each with a **Publish artifact** button. Artifacts is available in accounts where artifacts are available in Snowsight. To turn it off, disable the `chat.artifacts.enabled` setting. See [Create and share an artifact from CoCo Desktop](/user-guide/snowflake-artifacts-create-share#label-snowflake-artifacts-create-coco).
- **Share artifacts and work on them together**: In the **Share** dialog, add roles or users with **Can view** or **Can publish** access, remove them, or delete the artifact if you own it. Changes apply when you select **Save**. Anyone with **Can publish** access can open the artifact from **Artifacts**, edit it in a session, and select **Publish changes** to update the same artifact. See [Create and share a dashboard or HTML report](/user-guide/snowflake-artifacts-create-share).
- **Snowflake CoWork and Snowsight links**: **Copy link** offers **Copy CoWork link** and **Copy Snowsight link**, and artifact menus include **Open in CoWork** and **Open in Snowsight**. When Snowflake CoWork isn’t available in your account, **Copy link** copies the Snowsight link.
- **Charts in the HTML preview**: HTML reports that use Chart.js, Vega, Mermaid, KaTeX, or the other chart and math libraries that Snowflake CoWork provides now draw their charts in the CoCo Desktop preview.
- **Cloud automations (preview)**: Create automations that run in Snowflake as agent tasks on a schedule, even while your computer is off, from the **Cloud** tab of the **Automations** page. Start from a template, and get each run’s report by email. A **Cloud Preview** badge appears beside the **Automations** title while Cloud automations are on. They’re available in accounts where CoCo automations are enabled. To turn them off, set `chat.automations.cloud.enabled` to `false`. See [CoCo automations in CLI, Snowsight, and Desktop](/user-guide/cortex-code/cortex-code-automations).
- **Simpler automation creation**: The **New** button on the **Automations** page offers **Create with CoCo** or **Set up manually**, for local or cloud automations.
- **Redesigned automation details**: When Cloud automations are on, a local automation’s page shows a sortable run history, a preview of the latest output, and an empty state when it hasn’t run yet. Cloud automation pages match: **Edit**, **Run now**, and **Delete** work the same way, you suspend or resume an automation from its status pill, and a **Details** section shows the model, task name, GitHub access, MCP servers, and hooks.
- **Run status at a glance**: A dot on each automation shows its newest run that you haven’t viewed, with failures taking precedence, and the sidebar shows a count of new runs. Opening an automation clears them.

## Reliability and fixes

- **Recovery from a missing Cortex thread**: A chat whose Cortex thread no longer exists keeps working, instead of failing every turn with an internal error.
- **Prompt history without added context**: Prompts that you recall with the Up arrow key no longer include context that CoCo Desktop added when you sent them.
- **Pending changes on rendered Markdown**: When a Markdown file with pending agent changes is open in the rendered preview, it shows **N pending changes**, which reopens the file in the text editor. Previously, it showed **Keep** and **Undo** buttons that did nothing.
- **Web pages open beside the chat**: When you chat in an editor tab, web pages that the agent opens appear beside the chat instead of covering it.
- **Cloud automation run history**: Run history shows only the current automation’s runs, even when an earlier automation used the same name. Runs whose sandbox started late now link to their conversation. Editing an automation that’s bound to an agent no longer removes the agent.
- **Spread-out cloud schedules**: When the agent creates or reschedules a cloud automation for the top or bottom of the hour, the schedule moves to a nearby minute so that runs don’t all start at once.
- **dbt fixes**: The **Run** button in the editor title is unavailable when **Defer to Production** is on but no target is selected, as the **Run** button in the Action Bar already was. The dbt Charts extension (`dbtLabsInc.dbtcharts`) can now be installed.
