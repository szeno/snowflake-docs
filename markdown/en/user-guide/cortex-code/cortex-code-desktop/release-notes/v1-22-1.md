# CoCo Desktop v1.22.1 release notes

v1.22.1 brings Defer to Production to Snowflake-managed dbt runs, lets the agent name your chat sessions, and turns on Snowflake object discovery for everyone. It also fixes crashes in SSH windows, edits that got stuck while applying, and how **Stop** handles your prompt and queued messages.

## What’s new

- **Defer to Production for Snowflake-managed dbt runs**: The **Run** configuration for Snowflake-managed dbt projects now includes Defer to Production controls. Turn on Defer for a project, then pick a production dbt project object and a **Compare to** mode: the last run, the last successful run, or the last failed run. Database and schema lists in the picker load once and filter as you type.
- **The agent can name your chat sessions**: The agent can rename the current chat session, either on its own once the task is clear or when you ask it to. You confirm each rename in an **Allow session rename?** prompt that shows the proposed title. Auto-approve and bypass approval modes apply to this prompt like any other tool call.
- **Snowflake object discovery for everyone**: The `snowflake-object-discovery` subagent, which finds the tables, views, semantic views, and other objects that answer your question, is now on by default for all users. It needs a local CoCo CLI installation and doesn’t run in remote (SSH) windows.
- **All your chat sessions are kept**: CoCo Desktop no longer deletes older chat sessions once a project has more than 25.
- **Filter and sort apps**: The **Apps** panel adds a **Type** menu (**All types**, **Snowflake App**, or **Streamlit**) and a **Sort** menu (**Last updated** or **Name**) next to the existing **Status** menu.
- **App actions without an open folder**: Local app cards in the **Apps** panel now offer **Run locally**, **Deploy**, and **Modify app** even when no folder is open, instead of only **Open Folder**.
- **The Agent window has a clear title**: The separate Agent window now appears as **Agent Window** in your operating system’s window lists, such as the **Window** menu, app switcher, and screen-sharing pickers.

## Reliability and fixes

- **SSH windows no longer lose their extensions**: Remote (SSH) windows no longer show “Remote Extension host terminated unexpectedly” or stop running remote extensions, such as Markdown previews. This issue started in v1.21.7.
- **Edits no longer get stuck**: When a file edit fails, the chat no longer stays at “Applying N edits” with a spinning tab. The agent gets the error and can recover. This mainly affected Windows.
- **Stop keeps you in control**: After you press **Stop**, your prompt is put back in the message box only when the turn is removed from the conversation, so it no longer appears in both places. **Stop** also pauses queued messages, so nothing you queued starts on its own. **Send now** on a queued message now sends it after the current turn stops, instead of putting your previous prompt back in the message box.
- **Large dbt workspaces stay responsive**: Opening a folder that contains thousands of dbt projects no longer makes the window unresponsive for minutes.
- **Fresher External Access Integration list**: For Snowflake-managed dbt projects, the External Access Integration list refreshes within 5 minutes instead of up to an hour.
- **Faster chats**: Scrolling long conversations, switching between sessions, and typing in the message box are faster, and long thinking sections render more smoothly while the agent works.
- **Clearer idle-session cost notice**: When a session has been idle long enough for its cached context to expire, the notice now explains why your next message may cost more and suggests starting a new session for new work.

## Security and trust

- **Updated Snowflake Node.js driver**: CoCo Desktop now uses version 3.4.0 of the Snowflake Node.js driver, which resolves a Trust Center finding reported against the previous driver version.
