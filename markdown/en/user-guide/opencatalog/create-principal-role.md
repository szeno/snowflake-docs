# Create a principal role

You can create principal roles to logically group service principals together. For more information about principal roles, including examples, see [Principal role](./access-control#principal-role).

1. Sign in to Open Catalog.
2. In the menu on the left, select **Connections**.
3. Select the **Roles** tab.
4. Select **+ Principal role**.
5. Enter a name for the principal role, and then select **Create**.
