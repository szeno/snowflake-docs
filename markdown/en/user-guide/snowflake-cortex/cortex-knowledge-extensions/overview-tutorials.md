# Tutorials

These tutorials provide step-by-step instructions for you to explore how to use Cortex Knowledge Extensions.

[Tutorial 1: Providers set up and test a CKE](/user-guide/snowflake-cortex/cortex-knowledge-extensions/tutorials/setup-test-cke-tutorial)
:   Walks through the process that Providers follow to create, test, and list a Cortex Knowledge Extension on the Marketplace.

[Tutorial 2: Consumer interfaces with a CKE in a Streamlit chatbot](/user-guide/snowflake-cortex/cortex-knowledge-extensions/tutorials/query-cortex-search-service-tutorial)
:   Walks through the process that Consumers follow to test Cortex Knowledge Extension that was shared by a provider. This tutorial is intended for users who are familiar with the Cortex Search Service and want to learn how to use it with a CKE.

[Tutorial 3: Add a CKE to Snowflake CoWork](/user-guide/snowflake-cortex/cortex-knowledge-extensions/tutorials/add-cke-to-snowflake-cowork-tutorial)
:   Walks through the process that Consumers follow to add a Cortex Knowledge Extension to Snowflake CoWork. This tutorial is intended for users who are familiar with Snowflake CoWork and want to learn how to use it with a CKE.
