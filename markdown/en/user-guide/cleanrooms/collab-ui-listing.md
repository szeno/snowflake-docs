# View collaborations in Snowsight

[Preview Feature](/release-notes/preview-features) — Open

Currently available in [these regions](/user-guide/cleanrooms/installing-dcr#label-dcr-supported-regions).

Not available in government and VPS deployments.

The collaborations listing page displays all collaborations that you have access to with the
currently selected role. Collaborations are organized into two tabs:

## **Joined** tab

The **Joined** tab shows collaborations that you have created or joined. For each
collaboration, the listing shows:

- The collaboration name.
- A description of the collaboration.
- The list of collaborators and their status.
- The last updated timestamp.
- A **Run** button to run analysis templates (if you have execute access).

Hover over a collaboration card to access Cortex Code actions: select **Add to Chat** to
open Cortex Code with the collaboration context, or **Explain** to get an AI-generated
summary of the collaboration.

## **Invited** tab

The **Invited** tab shows collaborations that have been shared with your account but that
you haven’t joined yet. This tab is split into two sections:

- **Ready to join**: Collaborations that are ready for you to join. Select **Join** to
  start the join flow.
- **Pending review**: Collaborations that require you to review before joining. Select
  **Start Review** to start the review flow.

Hover over a collaboration card to access Cortex Code actions: select **Add to Chat** to
open Cortex Code with the collaboration context, or **Explain** to get an AI-generated
summary of the collaboration.

For more information, see [Review and join a collaboration in Snowsight](/user-guide/cleanrooms/collab-ui-join).

## Filter, search, and sort

You can filter, search, and sort the collaborations list:

- **Filter by collaborator**: Select a collaborator from the collaborator filter to show only
  collaborations that include that collaborator. This filter is available on the
  **Joined** tab only.
- **Filter by creator**: Select an account from the **Created by** filter to show only
  collaborations created by that account.
- **Search**: Use the search bar to search for collaborations by name, owner, or description.
- **Sort**: Sort collaborations by name or by the most recently updated.

## Create a collaboration

To create a new collaboration, select **Create Collaboration** at the top of the listing page.
For more information, see [Create a collaboration in Snowsight](/user-guide/cleanrooms/collab-ui-create).
