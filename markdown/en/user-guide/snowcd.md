# SnowCD (Connectivity Diagnostic Tool)

SnowCD (i.e. Snowflake Connectivity Diagnostic Tool) helped users diagnose and troubleshoot their network connection to Snowflake.

Warning

SnowCD has reached End of Life and will no longer receive updates. To test connectivity to Snowflake,
use the [snow connection test](/developer-guide/snowflake-cli/connecting/configure-connections#test-and-diagnose-a-connection) command
in Snowflake CLI instead.
