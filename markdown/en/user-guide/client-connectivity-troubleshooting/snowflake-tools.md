# Use Snowflake troubleshooting tools

Snowflake provides the following tools to test client connectivity by simplifying tests for a client’s ability to access Snowflake URLs:

- Snowflake CLI

  Use the [snow connection test](/developer-guide/snowflake-cli/connecting/configure-connections#test-and-diagnose-a-connection) command
  to test connectivity to Snowflake.
- Snowflake Connector for Python diagnostics

  Use the connector’s diagnostic feature for comprehensive testing. For more information and detailed steps,
  see [Running connectivity tests and diagnostics](/developer-guide/python-connector/python-connector-connect#label-python-diagnostics).

If you cannot use or install these tools in your system, you can follow the [alternate steps](/user-guide/client-connectivity-troubleshooting/alternate-steps), based on your platform.

If you successfully verified connectivity, proceed to [follow-up actions](/user-guide/client-connectivity-troubleshooting/followup-actions).
