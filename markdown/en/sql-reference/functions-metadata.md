# Metadata functions

Snowflake provides functions that return metadata information, such as descriptions of the statements used to create database
objects (e.g. tables).

| Function Name | Notes |
| --- | --- |
| [GENERATE\_COLUMN\_DESCRIPTION](/sql-reference/functions/generate_column_description) | Generate a list of columns from a set of staged files that contain [semi-structured data](/user-guide/semistructured-intro). |
| [GET\_DDL](/sql-reference/functions/get_ddl) | Get DDL to [re-]create a database object. |
