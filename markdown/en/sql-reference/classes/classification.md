# CLASSIFICATION (SNOWFLAKE.ML)

[Preview Feature](/release-notes/preview-features) — Open

Available to all accounts.

Classification commands enable you to manage [classification](/user-guide/ml-functions/classification)
models in your account. Classification uses machine learning algorithms to sort data into different classes using patterns
detected in training data.

## Classification commands

- [ALTER SNOWFLAKE.ML.CLASSIFICATION](/sql-reference/classes/classification/commands/alter-classification)
- [CREATE SNOWFLAKE.ML.CLASSIFICATION](/sql-reference/classes/classification/commands/create-classification)
- [DROP SNOWFLAKE.ML.CLASSIFICATION](/sql-reference/classes/classification/commands/drop-classification)
- [SHOW SNOWFLAKE.ML.CLASSIFICATION](/sql-reference/classes/classification/commands/show-classification)
