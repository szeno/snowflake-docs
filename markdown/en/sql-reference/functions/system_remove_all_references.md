# SYSTEM$REMOVE\_ALL\_REFERENCES

Deletes all associations to the reference.

## Syntax

Copy code

```
SYSTEM$REMOVE_ALL_REFERENCES('<reference_name>')
```

## Arguments

**Required**

`'reference_name'`
:   The name of the reference as specified in the `manifest.yml` file of the app.
