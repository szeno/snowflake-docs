# SYSTEM$GET\_DEBUG\_STATUS

[Preview Feature](/release-notes/preview-features) — Open

Available to all accounts.

Returns the [session debug mode](/developer-guide/native-apps/installing-testing-application#label-native-apps-session-debug-mode) status of the current session.

## Syntax

Copy code

```
SYSTEM$GET_DEBUG_STATUS()
```
