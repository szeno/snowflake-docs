# SYSTEM$END\_DEBUG\_APPLICATION

[Preview Feature](/release-notes/preview-features) — Open

Available to all accounts.

Disables [session debug mode](/developer-guide/native-apps/installing-testing-application#label-native-apps-session-debug-mode) for a Snowflake Native App.

## Syntax

Copy code

```
SYSTEM$END_DEBUG_APPLICATION()
```
