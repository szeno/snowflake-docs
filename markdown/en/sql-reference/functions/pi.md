# PI

Returns the value of pi as a floating-point value.

## Syntax

Copy code

```
PI()
```

## Returns

This function returns a value of type FLOAT.

## Examples

Copy code

```
SELECT PI();
```

```
+-------------+
|        PI() |
|-------------|
| 3.141592654 |
+-------------+
```
