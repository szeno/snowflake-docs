# UNDROP *<object>*

Restores the specified object to the system. This command is part of the [Time Travel](/user-guide/data-time-travel) feature.

See also:
:   [CREATE <object>](/sql-reference/sql/create) , [DROP <object>](/sql-reference/sql/drop) , [SHOW <objects>](/sql-reference/sql/show)
