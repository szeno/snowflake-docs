# ALTER APPLICATION DROP CONFIGURATION DEFINITION

Deletes the [app configuration definition](/developer-guide/native-apps/inter-app-communication) for a Snowflake Native App.

Note

This command can only be used by a Snowflake Native App.

See also:
:   [ALTER APPLICATION SET CONFIGURATION DEFINITION](/sql-reference/sql/alter-application-set-configuration-definition)

## Syntax

Copy code

```
ALTER APPLICATION DROP CONFIGURATION DEFINITION {config};
```

## Parameters

`config`
:   Identifier for the app configuration definition.
