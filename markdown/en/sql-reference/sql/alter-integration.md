# ALTER INTEGRATION

Modifies the properties for an existing integration.

See also:
:   [CREATE INTEGRATION](/sql-reference/sql/create-integration), [DROP INTEGRATION](/sql-reference/sql/drop-integration), [SHOW INTEGRATIONS](/sql-reference/sql/show-integrations) , [DESCRIBE INTEGRATION](/sql-reference/sql/desc-integration)

## Syntax

Copy code

```
ALTER <integration_type> INTEGRATION <object_name> <actions>
```

Where `actions` are specific to the object type.
