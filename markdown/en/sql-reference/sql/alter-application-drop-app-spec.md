# ALTER APPLICATION DROP SPECIFICATION

Drops an app specification from an app.

Note

This command can only be used by a Snowflake Native App.

See also:
:   [ALTER APPLICATION SET SPECIFICATION](/sql-reference/sql/alter-application-set-app-spec), [ALTER APPLICATION … { APPROVE | DECLINE} SPECIFICATION](/sql-reference/sql/alter-application-sequence-number)

## Syntax

Copy code

```
ALTER APPLICATION DROP SPECIFICATION <app_spec_name>;
```

## Parameters

`app_spec_name`
:   The name of the app specification.
