# IPADDRESS functions

[Preview Feature](/release-notes/preview-features) — Open

Available to all accounts.

Snowflake provides scalar functions for converting values to the
[IPADDRESS](/sql-reference/data-types-ipaddress) data type and for working with the network that an
address belongs to.

Unless noted otherwise, a `NULL` input produces a `NULL` result.

## Conversion functions

> - [TO\_IPADDRESS](/sql-reference/functions/to_ipaddress)
> - [TRY\_TO\_IPADDRESS](/sql-reference/functions/try_to_ipaddress)

## Network functions

> - [IPADDRESS\_TRUNC](/sql-reference/functions/ipaddress_trunc)
