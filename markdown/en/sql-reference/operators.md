# Query operators

Snowflake supports most of the standard operators defined in SQL:1999.

These operators include arithmetic operators (such as `+` and `-`),
set operators (such as UNION), subquery operators (such as ANY), and so on.

| Category | Operators |
| --- | --- |
| [Arithmetic operators](/sql-reference/operators-arithmetic) | `+` , `-` , `*` , `/` , `%` |
| [Comparison operators](/sql-reference/operators-comparison) | `=` , `!=` , `<>` , `<` , `<=` , `>` , `>=` |
| [Expansion operators](/sql-reference/operators-expansion) | `**` |
| [Flow operators](/sql-reference/operators-flow) | `->>` |
| [Logical operators](/sql-reference/operators-logical) | AND , NOT , OR |
| [Set operators](/sql-reference/operators-query) | INTERSECT, MINUS, EXCEPT, UNION |
| [Subquery operators](/sql-reference/operators-subquery) | [NOT] EXISTS, ANY / ALL, [NOT] IN |
