# Use Cortex Embed

Feature — Generally Available

Not available in government regions.

The Snowflake REST [Cortex Embed API](/developer-guide/snowflake-rest-api/reference/cortex-embed.html) provides the following Snowflake endpoints:

**Snowflake Cortex Embed API endpoints**

| Endpoint | Description |
| --- | --- |
| `POST /api/v2/cortex/inference:embed` | Perform LLM embedding for input text, similar to the Snowflake Cortex *EMBED\_TEXT* functions. |
