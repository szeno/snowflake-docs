# Install the Snowflake Extension for Snowpark Checkpoints

## Prerequisites

Before you use the Checkpoints feature in the Snowflake Extension, you must [install the Snowpark Checkpoints library](/developer-guide/snowpark/python/checkpoints-installation).

## Install the extension

- To use Snowpark Checkpoints from the Snowflake Extension for Visual Studio Code, install the extension from the Visual Studio Code Marketplace:
