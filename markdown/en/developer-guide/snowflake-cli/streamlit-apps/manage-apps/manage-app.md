# Managing Streamlit apps

After you have created a Streamlit app, you can use the following commands to manage the app:

- To retrieve the URL of your Streamlit app, use the `snow streamlit get-url NAME` command. See [snow streamlit get-url](/developer-guide/snowflake-cli/command-reference/streamlit-commands/get-url) for more information.
- To share your app to other roles, use the snow `streamlit share NAME TO_ROLE` command. See [snow streamlit share](/developer-guide/snowflake-cli/command-reference/streamlit-commands/share) for more information.
- To list the Streamlit apps for which you have access, use the `snow streamlit list` command. See [snow streamlit list](/developer-guide/snowflake-cli/command-reference/streamlit-commands/list) for more information.
- To display details about a Streamlit app, use the `snow streamlit describe NAME` command. See [snow streamlit describe](/developer-guide/snowflake-cli/command-reference/streamlit-commands/describe) for more information.
- To delete a Streamlit app, use the `snow streamlit drop NAME` command. See [snow streamlit drop](/developer-guide/snowflake-cli/command-reference/streamlit-commands/drop) for more information.
