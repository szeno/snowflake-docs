# Managing Streamlit apps with Snowflake CLI

For Streamlit developers who currently use a local IDE development flow and a Git-backed continuous integration and deployment (CI/CD) collaboration workflow, switching to in-browser editing for [Streamlit in Snowflake](/developer-guide/streamlit/about-streamlit) can be difficult. Snowflake CLI gives developers critical and familiar tooling to integrate SiS into their current development flow.

Using Snowflake CLI, developers can now easily deploy apps from a CLI and perform operations efficiently without requiring any SQL knowledge. Without Snowflake CLI, Streamlit app developers had to deploy locally developed apps to the Snowflake infrastructure by executing SQL commands and copying local files to a stage. Now, these app developers can use whichever method they prefer.

You can perform the following operations when managing Streamlit apps:

- [Creating a Streamlit app](/developer-guide/snowflake-cli/streamlit-apps/manage-apps/initialize-app)
- [Deploying a Streamlit app](/developer-guide/snowflake-cli/streamlit-apps/manage-apps/deploy-app)
- [Retrieving the URL for a Streamlit app](/developer-guide/snowflake-cli/streamlit-apps/manage-apps/get-url)
- [Share a Streamlit app](/developer-guide/snowflake-cli/streamlit-apps/manage-apps/share-app)
- [Managing Streamlit apps](/developer-guide/snowflake-cli/streamlit-apps/manage-apps/manage-app)

For more information about Streamlit apps in Native Apps, see [Add a Streamlit app](/developer-guide/native-apps/adding-streamlit).
