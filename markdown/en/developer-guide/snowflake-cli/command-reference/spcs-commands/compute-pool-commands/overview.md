# snow spcs compute-pool commands

Note

You can use Snowpark Container Services from Snowflake CLI only if you have the necessary permissions to use Snowpark Container Services.

Snowflake CLI supports the following commands to support compute pools:

- [snow spcs compute-pool create](/developer-guide/snowflake-cli/command-reference/spcs-commands/compute-pool-commands/create)
- [snow spcs compute-pool deploy](/developer-guide/snowflake-cli/command-reference/spcs-commands/compute-pool-commands/deploy)
- [snow spcs compute-pool describe](/developer-guide/snowflake-cli/command-reference/spcs-commands/compute-pool-commands/describe)
- [snow spcs compute-pool drop](/developer-guide/snowflake-cli/command-reference/spcs-commands/compute-pool-commands/drop)
- [snow spcs compute-pool resume](/developer-guide/snowflake-cli/command-reference/spcs-commands/compute-pool-commands/resume)
- [snow spcs compute-pool set](/developer-guide/snowflake-cli/command-reference/spcs-commands/compute-pool-commands/set)
- [snow spcs compute-pool status](/developer-guide/snowflake-cli/command-reference/spcs-commands/compute-pool-commands/status)
- [snow spcs compute-pool stop-all](/developer-guide/snowflake-cli/command-reference/spcs-commands/compute-pool-commands/stop-all)
- [snow spcs compute-pool suspend](/developer-guide/snowflake-cli/command-reference/spcs-commands/compute-pool-commands/suspend)
- [snow spcs compute-pool unset](/developer-guide/snowflake-cli/command-reference/spcs-commands/compute-pool-commands/unset)
