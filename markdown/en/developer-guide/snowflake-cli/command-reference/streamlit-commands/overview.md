# snow streamlit commands

Snowflake CLI supports the following commands for managing Streamlit apps:

- [snow streamlit deploy](/developer-guide/snowflake-cli/command-reference/streamlit-commands/deploy)
- [snow streamlit describe](/developer-guide/snowflake-cli/command-reference/streamlit-commands/describe)
- [snow streamlit drop](/developer-guide/snowflake-cli/command-reference/streamlit-commands/drop)
- [snow streamlit execute](/developer-guide/snowflake-cli/command-reference/streamlit-commands/execute)
- [snow streamlit get-url](/developer-guide/snowflake-cli/command-reference/streamlit-commands/get-url)
- [snow streamlit list](/developer-guide/snowflake-cli/command-reference/streamlit-commands/list)
- [snow streamlit logs](/developer-guide/snowflake-cli/command-reference/streamlit-commands/logs)
- [snow streamlit share](/developer-guide/snowflake-cli/command-reference/streamlit-commands/share)

For more information about Streamlit apps, refer to [About Streamlit in Snowflake](/developer-guide/streamlit/about-streamlit) and [Add a Streamlit app](/developer-guide/native-apps/adding-streamlit).
