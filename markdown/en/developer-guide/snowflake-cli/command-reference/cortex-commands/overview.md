- [snow cortex complete](/developer-guide/snowflake-cli/command-reference/cortex-commands/complete)
- [snow cortex extract-answer](/developer-guide/snowflake-cli/command-reference/cortex-commands/extract-answer)
- [snow cortex sentiment](/developer-guide/snowflake-cli/command-reference/cortex-commands/sentiment)
- [snow cortex summarize](/developer-guide/snowflake-cli/command-reference/cortex-commands/summarize)
- [snow cortex translate](/developer-guide/snowflake-cli/command-reference/cortex-commands/translate)
