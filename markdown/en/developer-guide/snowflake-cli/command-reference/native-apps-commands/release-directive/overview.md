# snow app release-directive commands

For more information about release channels and release directives, see the [Publishing a Snowflake Native App to customers](/developer-guide/snowflake-cli/native-apps/publish-app) page.

Snowflake CLI supports the following commands for managing release directives of native apps:

> - [snow app release-directive add-accounts](/developer-guide/snowflake-cli/command-reference/native-apps-commands/release-directive/add-accounts)
> - [snow app release-directive list](/developer-guide/snowflake-cli/command-reference/native-apps-commands/release-directive/list)
> - [snow app release-directive remove-accounts](/developer-guide/snowflake-cli/command-reference/native-apps-commands/release-directive/remove-accounts)
> - [snow app release-directive set](/developer-guide/snowflake-cli/command-reference/native-apps-commands/release-directive/set)
> - [snow app release-directive unset](/developer-guide/snowflake-cli/command-reference/native-apps-commands/release-directive/unset)
