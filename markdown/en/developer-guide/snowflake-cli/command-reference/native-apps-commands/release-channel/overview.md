# snow app release-channel commands

Preview Feature — Open

In preview in Amazon Web Services (AWS), Microsoft Azure, and Google Cloud commercial regions.

Note

The release channels feature might not be available in all regions. Please contact Snowflake Support for more information.

Release channels help manage releases.
These commands fail if the feature is not enabled.
To enable release channels, contact your Snowflake representative.

For more information on release channels and release directives, see [Publishing a Snowflake Native App to customers](/developer-guide/snowflake-cli/native-apps/publish-app).

Snowflake CLI supports the following commands for managing release channels in Snowflake Native Apps:

> - [snow app release-channel list](/developer-guide/snowflake-cli/command-reference/native-apps-commands/release-channel/list)
> - [snow app release-channel add-version](/developer-guide/snowflake-cli/command-reference/native-apps-commands/release-channel/add-version)
> - [snow app release-channel remove-version](/developer-guide/snowflake-cli/command-reference/native-apps-commands/release-channel/remove-version)
> - [snow app release-channel add-accounts](/developer-guide/snowflake-cli/command-reference/native-apps-commands/release-channel/add-accounts)
> - [snow app release-channel remove-accounts](/developer-guide/snowflake-cli/command-reference/native-apps-commands/release-channel/remove-accounts)
> - [snow app release-channel set-accounts](/developer-guide/snowflake-cli/command-reference/native-apps-commands/release-channel/set-accounts)
