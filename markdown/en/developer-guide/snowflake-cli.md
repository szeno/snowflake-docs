# Snowflake CLI

## What is Snowflake CLI?

Snowflake CLI is the preferred command-line client for new installs and new work. It is an open-source command-line tool
explicitly designed for developer-centric workloads in addition to SQL operations. It is a flexible and extensible tool
that can accommodate modern development practices and technologies.

SnowSQL is a legacy command-line client. Snowflake will only add new features and enhancements to Snowflake CLI. Snowflake
supports SnowSQL 1.5.x through April 16, 2028. If you already use SnowSQL, see [Migrating from SnowSQL to Snowflake CLI](/user-guide/snowsql-migrate).

With Snowflake CLI, developers can create, manage, update, and view apps running on Snowflake across workloads such as
Streamlit in Snowflake, the Snowflake Native App Framework, Snowpark Container Services, and Snowpark. It supports a range of Snowflake features,
including user-defined functions, stored procedures, Streamlit in Snowflake, and SQL execution.
