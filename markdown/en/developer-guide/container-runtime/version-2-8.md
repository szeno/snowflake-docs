# Container Runtime 2.8

Container Runtime 2.8 was released on July 27, 2026. It continues to receive patches
for known exploitable critical vulnerabilities until March 1, 2027. Snowflake
recommends upgrading workloads to Stable version 2.10 or to Latest. To change
the runtime on an existing service, see [Using a runtime](/developer-guide/container-runtime/using-runtime).

For other Version 2 releases from 2.2 through 2.9, see [Archived Container Runtime releases](/developer-guide/container-runtime/archived-releases).

## Changes

**Added**

- Stage sharding for reading many small files from a stage.
- Optional disk cache for repeated stage and table reads. Off by default.

**Changed**

- Training widgets are on by default in Workspace notebooks.
- Distributed PyTorch training always uses the Ray Train path. Checkpoints are written
  to the stage, not local `/tmp`.
- `TunerConfig(uses_snowflake_trainer=...)` is now required. Omitting it raises at
  construction.
- Hyperparameter tuning can run on the driver instead of as a Ray Job when
  `TUNE_DISABLE_RAY_JOB=true`. The Ray Job path remains the default.
- Operating system updates
- System library upgrades
- Python package upgrades

**Deprecated**

- `get_context().get_model_dir()` and `get_context().get_artifact_manager()`. Persist
  models with Ray Train checkpointing instead.

**Fixed**

- Named-stage `artifact_stage_location` values without a leading `@` no longer fail
  Ray Train storage.
