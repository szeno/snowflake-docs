# Snowflake Container Runtime release notes

These release notes cover Container Runtime 3 (Latest) and Container Runtime 2.10
(Stable). They include changes in analytics, data engineering, and machine
learning packages, as well as
[Notebooks in Workspaces](/user-guide/ui-snowsight/notebooks-in-workspaces/notebooks-in-workspaces-overview)
behaviors. For historical Version 2 releases from before the Stable phase, see
[Archived Container Runtime releases](/developer-guide/container-runtime/archived-releases).

For details on Snowpark changes, see the [Snowpark Library for Python release notes](/release-notes/clients-drivers/snowpark-python).
For details on Snowflake ML API changes, see the [Snowflake ML Python release notes](/release-notes/clients-drivers/snowpark-ml).

Note

Releases are staged. Your Snowflake account might not update for a few days after the initial release date.
