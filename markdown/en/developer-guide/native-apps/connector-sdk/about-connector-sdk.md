# Snowflake Native SDK for Connectors (Deprecated)

Deprecated Feature

Snowflake Native SDK for Connectors is discontinued and is no longer available.

- To build a Snowflake Native App that connects to external sources, use the Native App Framework directly.
  See [About the Snowflake Native App Framework](/developer-guide/native-apps/native-apps-about) and [Request external access](/developer-guide/native-apps/requesting-app-specs-eai).
- To move data from an external source into Snowflake without building an app, see [About Openflow](/user-guide/data-integration/openflow/about).
