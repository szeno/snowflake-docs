# Snowpark Connect for Spark reference

This section provides reference documentation for Snowpark Connect for Spark, covering configuration, API
compatibility, and client library details.

- [Parameters](/developer-guide/snowpark-connect/snowpark-connect-parameters) lists Spark and
  custom configuration properties that control session behavior, file I/O, and UDF execution.
- [DataFrame support](/developer-guide/snowpark-connect/snowpark-connect-dataframe-support)
  details which Spark DataFrame API methods are supported, partially supported, or unsupported.
- [Dataset support](/developer-guide/snowpark-connect/snowpark-connect-dataset-support) covers
  the typed `Dataset` API for Java and Scala applications.
- [Snowpark Connect (Python)](/developer-guide/snowpark-connect/snowpark-connect-reference)
  documents the Python `snowpark-connect` package.
- [Java/Scala client](/developer-guide/snowpark-connect/snowpark-connect-jvm-reference)
  documents the `com.snowflake:snowpark-connect-java-client` library.
- [execute-jar CLI](/developer-guide/snowpark-connect/snowpark-connect-execute-jar-reference)
  documents the `snowpark-connect-execute-jar` command-line tool for running a packaged JAR.
- [Snowpark Submit](/developer-guide/snowpark-connect/snowpark-connect-submit-reference)
  covers the CLI flags, configuration options, and output formats.
