# Snowpark Connect for Spark samples

This section provides end-to-end code examples for common Snowpark Connect for Spark scenarios. Use them as
starting points for your own workloads.

- [External data sources](/developer-guide/snowpark-connect/snowpark-connect-samples-external-data)
  shows how to read from and write to cloud storage, JDBC databases, and Iceberg tables.
- [File transformation](/developer-guide/snowpark-connect/snowpark-connect-samples-file-transformation)
  shows how to use a UDF to transform files on a Snowflake stage and copy the results back.
- [Snowpark Submit](/developer-guide/snowpark-connect/snowpark-connect-submit-cookbook) shows
  how to package and run batch workloads using the Snowpark Submit CLI.
