# AI Governance in Snowflake

Snowflake provides features that help you govern, audit, and protect AI usage in your account, including Cortex Code,
[Snowflake CoWork](/user-guide/snowflake-cortex/snowflake-cowork), and Cortex Agents.

## Monitor and protect AI usage

[AI Governance dashboard](/user-guide/ai-governance)
:   Govern and audit Cortex Code and Cortex Agent usage from a single Snowsight page, including AI usage metrics, agent data exposure, and agent configuration changes.

[Cortex AI Guardrails](/user-guide/snowflake-cortex/cortex-ai-guardrails)
:   Protect Cortex Code, Snowflake CoWork, and Cortex Agents at run time against prompt injection and jailbreak attacks.

[Cortex AI Gateway](/user-guide/snowflake-cortex/cortex-ai-gateway)
:   Govern how AI clients in your organization reach models and other systems.

## Control access to AI

[Model access control](/user-guide/snowflake-cortex/governance-and-availability/model-access-control)
:   Control which models users and roles can use, with an account-level allowlist or role-based access control.

[Privileges and model access for Cortex AI Functions](/user-guide/snowflake-cortex/aisql-privileges-and-access)
:   Grant or revoke access to Cortex AI Functions at the account, role, or function level.

[Enable and manage Cortex Code for your account](/user-guide/cortex-code/cortex-code-admin)
:   Enable Cortex Code for your account and manage user and model access from Snowsight.

[Managed settings (organization policy)](/user-guide/cortex-code/managed-settings)
:   Enforce Cortex Code behavior across your organization with settings that users can’t change.

[Opt out of Snowflake AI features](/user-guide/snowflake-cortex/opting-out)
:   Revoke access to Snowflake AI features that are available to users by default.

[Cross-region inference](/user-guide/snowflake-cortex/cross-region-inference)
:   Control whether AI requests can be processed outside your account’s region.

## Manage AI costs

[AI cost management and governance](/user-guide/snowflake-cortex/governance-and-availability/ai-cost-management-and-governance)
:   Monitor and manage AI consumption with account usage and organization usage views.

[Cost controls for CoCo](/user-guide/cortex-code/cost-controls)
:   Manage and limit Cortex Code credit consumption.

[Daily credit usage limits for CoCo](/user-guide/cortex-code/credit-usage-limit)
:   Set per-user daily credit limits for Cortex Code.
